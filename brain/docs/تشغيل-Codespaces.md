# التشغيل من أي جهاز عبر GitHub Codespaces

**الغرض:** فتح النظام وتشغيله على بيئة سحابية مؤقتة من أي جهاز في العالم، بلا تثبيت شيء محليًا وبلا حاجة إلى معرفة المسارات. البيئة تُبنى من المستودع نفسه، وتُطفأ عند عدم الحاجة.

**الملف الذي يجهّز البيئة:** `.devcontainer/devcontainer.json` في جذر المستودع.
**الملف الذي يثبّت المتطلبات:** `brain/bootstrap.sh` (يعمل تلقائيًا عند إنشاء البيئة).

---

## ١. التشغيل خطوة بخطوة

1. افتح المستودع `mda-marine-system` على GitHub (خاص).
2. زر **Code** الأخضر ← تبويب **Codespaces** ← **Create codespace on main**.
3. انتظر التهيئة الأولى **٥–٨ دقائق** (تشمل LibreOffice وpoppler وخطوط عربية ومتصفح Chromium). راقب السجل في الطرفية.
4. تأكد أن التهيئة نجحت:

```bash
bash brain/bootstrap.sh --verify-only
```

النتيجة الصحيحة: `✔ كل حزم بايثون المطلوبة موجودة` و`✔ خطوط عربية متاحة`. وإن ظهر `✘` فأعد تشغيل التهيئة الكاملة:

```bash
bash brain/bootstrap.sh
```

## ٢. الأوامر الجاهزة داخل البيئة

```bash
# بناء الموقع كاملًا من البيانات (19 صفحة)
python3 site/generator/build_site.py

# توليد PDF الشكل المعتمد ليوم محدد + صورة الخريطة
python3 brain/tools/export_report_assets.py --date 2026-10-19

# نسخة Word طبق الأصل من PDF المعتمد
python3 brain/tools/build_report_docx_exact.py --date 2026-10-19

# بوابة التسليم النهائية على إصدار يوم (فشل مغلق)
bash brain/tools/final_gate.sh 2026-10-19

# الخط اليومي الكامل ليوم جديد
bash brain/tools/daily_pipeline.sh 2026-10-20

# معاينة الموقع محليًا داخل البيئة (منفذ 3000 مُهيَّأ في الإعدادات)
bash brain/tools/ensure_devserver.sh 3000
```

مخرجات PDF وWord تُكتب داخل `site/dist/reports/` — تُنزَّل من مستكشف الملفات في المحرّر.

## ٣. الأسرار والقنوات

- **لا سر في المستودع.** رمز بوت تلغرام يُقرأ من متغيّر البيئة `TELEGRAM_BOT_TOKEN`، ويمكن وضعه في ملف `brain/.env` غير المرفوع:

```bash
printf 'TELEGRAM_BOT_TOKEN=%s\n' '<الرمز من BotFather>' > brain/.env
chmod 600 brain/.env
```

  الأدوات تقرأ `brain/.env` تلقائيًا عند غياب المتغيّر من البيئة. ومعرّف المحادثة في `brain/appendices/telegram-chat.json`.
- **كلمة سر الويب هوك** (`brain/state/webhook-secret.txt`) مستثناة من المستودع بحكم التصميم.

## ٤. ما يعمل في البيئة وما لا يعمل

| العمل | في Codespaces |
|---|---|
| بناء الموقع · PDF المعتمد · Word · كل البوابات · الخط اليومي | ✔ يعمل كاملًا |
| تعديل القواعد والأدوات والتقارير ثم رفعها إلى GitHub | ✔ |
| إرسال تلغرام | ✔ بشرط وضع الرمز في `brain/.env` |
| **نشر الموقع على المنصة** | ✘ لا — النشر خطوة على Manus وحدها |
| **خدمة الويب هوك للبوت** | ✘ لا — تعمل على خدمة Manus المنشورة |
| **المهام المجدولة (٠٦:٤٠ و٠٧:٠٠ البحرين)** | ✘ لا — الجدولة على Manus |

الخلاصة: Codespaces بيئة **تشغيل وتحرير** عند الحاجة، وليست بديلًا عن الجدولة والنشر.

## ٥. اقتصاد التشغيل

- البيئة تُحسب بالساعات وتُطفأ عند عدم الاستخدام: أوقفها من قائمة **Codespaces** ← Stop، واحذفها (**Delete**) إذا لم تعد تحتاجها.
- لا تُشغّلها لأعمال لا تحتاجها؛ تحرير نصّي بسيط يكفيه التحرير على GitHub مباشرة.
- الحدود الشهرية للساعات تختلف بحسب حسابك — راجع صفحة الاستخدام في GitHub.

## ٦. فحص ذاتي عند أي إعداد جديد

```bash
python3 brain/validators/check_portable_paths.py     # لا مسار مطلق في الشيفرة
python3 brain/validators/check_sources_count.py      # عدد المصادر 40 من مصدر واحد
bash brain/bootstrap.sh --verify-only                # كل المتطلبات حاضرة
```

## ٧. ملاحظة فنية معروفة

خطوط الواجهة تُحمَّل من Google Fonts؛ لذلك **توليد PDF يحتاج إنترنت**. إن أردت استقلالًا تامًا عن الشبكة، الخطوة التالية هي تجميع ملفات الخطوط داخل المستودع (`site/assets/fonts/`) وتغيير مرجع الخطوط محليًا — تُنفَّذ عند الطلب.
