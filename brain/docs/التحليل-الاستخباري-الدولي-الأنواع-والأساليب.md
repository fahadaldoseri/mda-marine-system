## ٢) الغرض

1. **إعطاء صورة كاملة** لأنواع التحليل الاستخباري وطرقه الدولية، بلا اختصار مخلّ.
2. **تمكين الاختيار**: أيّ الأساليب يُعتمد في تقريرنا اليومي، وأيّها يحتاج جهدًا مؤسسيًا أكبر.
3. **توحيد اللغة**: اعتماد لغة واحدة للتعبير عن عدم اليقين ودرجات الثقة، بدل العبارات المبهمة.
4. **إغلاق الفجوة الحالية**: تقريرنا يجمع ويصنّف، لكنه لا يقدّم تقديرًا مربوطًا ولا مؤشرات متابعة.

## ٤) المبحث الثاني: المرجعيات والمؤسسات الدولية

### ٤-١ الولايات المتحدة — ICD 203

**المعايير الخمسة الكبرى:**

1. **الموضوعية** — إدراك الافتراضات والانحيازات ومواجهتها، والنظر في الروايات المعارضة.
2. **الاستقلال عن الاعتبارات السياسية** — لا يُشكَّل التحليل لخدمة أجندة أو رأي.
3. **التوقيت** — يُنشر في وقت يسمح بالعمل عليه.
4. **الاعتماد على كل المصادر المتاحة** — مع تحديد الفجوات المعلوماتية.
5. **تطبيق معايير الحرفة التحليلية التسعة وإظهارها.**

**معايير الحرفة التحليلية التسعة (المختصرة):**

| # | المعيار | المعنى العملي |
|---:|---|---|
| ١ | وصف جودة المصادر ومصداقيتها | يُذكر المصدر وطبيعته وأثره على الحكم |
| ٢ | التعبير عن عدم اليقين وشرحه | الاحتمال + درجة الثقة، بعبارات موحدة |
| ٣ | التمييز بين المعلومة والافتراض والحكم | لا خلط بين ما رُصد وما استُنتج |
| ٤ | إدماج تحليل البدائل | فرضيات بديلة تُطرح وتُقيَّم |
| ٥ | الصلة بالمستخدم ومعالجة الآثار | «وماذا يعني ذلك؟» لا سرد مجرد |
| ٦ | حجج واضحة ومنطقية | الرسالة الأساسية في المقدمة، ودعم متسق |
| ٧ | شرح تغيّر الحكم أو ثباته | «ما تغيّر عن الأمس ولماذا» |
| ٨ | أحكام دقيقة | لا تحاشي للأحكام الصعبة، ولا غموض |
| ٩ | إدماج المعلومات البصرية | جداول ومخططات وخرائط عند الحاجة |

**ملاحظة مؤسسية مهمة:** أنشأت الولايات المتحدة **أمين مظالم تحليليًا (Analytic Ombuds)** مستقلًا، يفحص شكاوى الموضوعية والانحياز والتسييس — أي أن الحرفة صارت **مُقاسة ومُدقّقة**، لا مسألة خبرة شخصية.

### ٤-٢ بريطانيا — PHIA

- **معايير تحليلية مشتركة** تُلزم كل المحللين في الحكومة.
- **مسطرة الاحتمال (Probability Yardstick)** + **إطار درجة الثقة (Analytical Confidence Rating)**: فصل صريح بين **احتمال وقوع الحدث** و**ثقتنا في أساس الحكم**.
- **المراجعة النظيرة (Peer Review)** إلزامية، مع تغذية راجعة بنّاءة.
- اللغة: **إنجليزية بسيطة وواضحة** (Plain English) — بلا حشو.

### ٤-٣ الناتو — التحليل البديل (AltA)

**٢١ تقنية في أربع عائلات:**

| العائلة | وظيفتها |
|---|---|
| **الهيكلة (Structuring)** | تفكيك الموضوع إلى أجزائه وتنظيمه وتمثيله بصريًا |
| **الإبداع (Creative)** | توليد أفكار جديدة والخروج من الإطار الذهني |
| **التشخيص (Diagnostic)** | اختبار الفرضيات وفحص الأدلة وتقييم البدائل |
| **التحدي (Challenge)** | نقد ذاتي ونقد الآخرين وتحدي النماذج الذهنية القائمة |

### ٤-٤ كود الأدميرالية / الناتو (المعتمد لدينا)

| الموثوقية | المعنى | | المصداقية | المعنى |
|---|---|---|---|---|
| **A** | موثوق تمامًا | | **1** | مؤكد من مصادر مستقلة |
| **B** | موثوق عادةً | | **2** | يُرجَّح صدقه |
| **C** | موثوق نوعًا ما | | **3** | يُحتمل صدقه |
| **D** | غير موثوق عادةً | | **4** | مشكوك فيه |
| **E** | غير موثوق | | **5** | غير مُرجَّح |
| **F** | لا يمكن الحكم على الموثوقية | | **6** | لا يمكن الحكم على الصحة |

**قاعدة ذهبية:** تُقيَّم **الموثوقية والمصداقية كلٌّ على حدة**، حتى لا تُرفع مصداقية المعلومة بسبب موثوقية مصدرها.

## ٥) المبحث الثالث: الأساليب التحليلية المنظمة (SATs)

**العائلات الثلاث في الدليل الأمريكي (2009):**

### ٥-١ الأساليب التشخيصية (Diagnostic)

| الأسلوب | ماذا يفعل | متى يُستخدم |
|---|---|---|
| **فحص الافتراضات الأساسية** (Key Assumptions Check) | يُخرج الافتراضات الخفيّة ويجعلها معلنة | بداية كل عمل تحليلي وقبل إقفال الحكم |
| **فحص جودة المعلومة** (Quality of Information Check) | يقيس اكتمال وصحة وحداثة قاعدة المعلومات | عند الشك في كفاية الأدلة |
| **مؤشرات التغيّر** (Indicators / Signposts of Change) | يبني قائمة مؤشرات تُراقب لاحقًا | لمتابعة الاتجاهات والتحذير المبكر |
| **تحليل الفرضيات المتنافسة** (ACH) | مصفوفة أدلة × فرضيات لدحض الفرضيات الضعيفة | عند تعدد التفسيرات المحتملة |
| **كشف الخداع** (Deception Detection) | يفترض أن الخصم قد يُنتج معلومات مضلِّلة | في بيئات الاستهداف والتضليل |

### ٥-٢ الأساليب المعارضة (Contrarian)

| الأسلوب | ماذا يفعل |
|---|---|
| **محامي الشيطان** (Devil's Advocacy) | يبني أفضل حجة مضادة للخط التحليلي السائد |
| **فريق أ / فريق ب** (Team A/Team B) | فريقان يحللان المسألة نفسها بمنهجين مستقلين |
| **عالي الأثر منخفض الاحتمال** | يدرس حدثًا مستبعدًا لكنه كارثي إن وقع |
| **تحليل «ماذا لو؟»** (What If?) | يفترض تحقّق سيناريو مزعج ويسأل: هل نحن جاهزون؟ |
| **الفريق الأحمر** (Red Team) | يلعب دور الخصم بمثقله الثقافي والعملياتي |

### ٥-٣ أساليب التفكير الإبداعي

| الأسلوب | ماذا يفعل |
|---|---|
| **العصف الذهني المنظم** | توليد فرضيات وأفكار بلا حكم مسبق |
| **التفكير من الخارج للداخل** | يبدأ من البيئة والضغوط الكبرى ثم يصل إلى الفاعل |
| **تحليل القبعة الحمراء** (Red Hat) | يحلّل تصرّفات الخصم كما لو كان هو مَن يقرّر |
| **السيناريوهات والبدائل المستقبلية** | يبني ٣–٤ مستقبلات محتملة بمؤشرات لكل منها |
| **المحاكاة والتمارين** (Gaming) | اختبار القرار في بيئة تنافسية |

**ملاحظة عملية من الدليل:** لا تُستخدم كل الأساليب في كل مرة؛ يُختار الأسلوب بحسب **سؤال التحليل** و**مرحلته الزمنية** (بداية العمل ← أثناءه ← قبل الإقفال).

## ٦) المبحث الرابع: التعبير عن عدم اليقين (لغة التقدير)

### ٦-١ سلّم Sherman Kent (1964) — الأصل

| العبارة | النسبة |
|---|---|
| مؤكد | 100% |
| شبه مؤكد | ~93% (±6%) |
| مُرجَّح | ~75–78% (±10–12%) |
| احتمالات متكافئة | ~50% |
| غير مُرجَّح | ~30% (±10%) |
| شبه مستبعد | ~7% (±5%) |
| مستحيل | 0% |

### ٦-٢ سلّم ICD 203 المعاصر (سبع درجات)

| العبارة | النسبة |
|---|---|
| فرصة تكاد تكون معدومة | 1–5% |
| مستبعد جدًا / ضعيف الاحتمال | 5–20% |
| غير مُرجَّح / يُرجَّح ألّا | 20–45% |
| فرصة متكافئة تقريبًا | 45–55% |
| يُرجَّح / مُرجَّح | 55–80% |
| يُرجَّح جدًا / عالي الاحتمال | 80–95% |
| شبه مؤكد | 95–99% |

**قاعدتان إلزاميتان في ICD 203:**

1. **لا تُخلط** عبارات من صفوف مختلفة في المنتج الواحد؛ ومن خلطها فعليه تنبيه صريح.
2. **لا تُجمع** «درجة ثقة» (high confidence) مع «درجة احتمال» في الجملة نفسها — لأن الأولى عن **جودة الدليل**، والثانية عن **احتمال وقوع الحدث**.

**ومحظورات لغوية:** «قد»، «ربما»، «يحتمل أن»، «يشير إلى» — عبارات لا تعطي المستخدم أي معلومة عن الاحتمال، وقد صُنّفت في الأدبيات كـ«غموض غير مُكمَّم» (Fallacy of Unquantified Ambiguity).

## ٧) المبحث الخامس: تحليل الفرضيات المتنافسة (ACH)

طوّره **Richards Heuer** داخل وكالة الاستخبارات المركزية في سبعينيات القرن الماضي، وخطواته:

| # | الخطوة | المضمون |
|---:|---|---|
| ١ | **توليد الفرضيات** | كل التفسيرات المحتملة، لا «الأرجح» فقط |
| ٢ | **حصر الأدلة** | ما يدعم وما يعارض كل فرضية، مع الافتراضات والاستنتاجات |
| ٣ | **التشخيص** | مصفوفة أدلة × فرضيات، وتُقرأ **بالعرض** (دليل واحد أمام كل الفرضيات) لا بالطول |
| ٤ | **التحسين** | سدّ الفجوات وجمع ما يدحض الفرضيات الباقية |
| ٥ | **التعارض** | الفرضية الأقل اتساقًا مع الأدلة هي الأضعف |
| ٦ | **الحساسية** | اختبار: لو كان الدليل الأساسي خاطئًا، هل يتغير الحكم؟ |
| ٧ | **الاستنتاج والتقييم** | عرض الحكم + البدائل التي رُفضت ولماذا + مؤشرات للمراجعة لاحقًا |

**القوة:** قابل للتدقيق وإعادة التتبع. **الضعف:** مستهلك للوقت، ويصبح مرهقًا في المسائل المعقدة، ولقطة جامدة في الزمن.

## ٨) المبحث السادس: الاستخبارات التحذيرية ومؤشرات التحذير (I&W)

| المصطلح | المعنى |
|---|---|
| **المؤشر** (Indicator) | تطوّر يستحق المراقبة |
| **الدلالة** (Indication) | دليل على أن التطوّر يحدث فعلًا |
| **التحذير** (Warning) | تنبيه صاحب القرار قبل وقوع الحدث |

**كيف تُبنى قائمة مؤشرات عملية:** تُشتق المؤشرات من مسار الحدث نفسه (تجهيزات، تحركات، تصريحات، تغيّرات سلوكية)، ولكل مؤشر: **ما يؤكده** و**ما ينفيه**، ومَن يرصده، وكم مرة يُحدَّث.

## ٩) المبحث السابع: تقييم المخاطر في المجال البحري

**المعادلة المؤسسية:** الخطر = **التهديد × الثغرة × النتيجة**، مقيسًا باحتمال الوقوع × حجم الأثر.

| العنصر | السؤال |
|---|---|
| **تحديد التهديد** | مَن يهدّد؟ وبماذا؟ (قرصنة · استهداف · سطو مسلح · مسيّرات · صواريخ · تشويش) |
| **تحليل الثغرة** | ما نقاط ضعف السفينة أو الممر أو الاتصال؟ |
| **تقييم الأثر** | ما النتيجة المحتملة؟ (أرواح · حمولة · بيئة · إمداد · كلفة) |
| **تقييم الاحتمال** | ما فرصة تحقّق التهديد؟ (موقع · تاريخ الحوادث · البيئة الجيوسياسية) |
| **مصفوفة المخاطر** | ترتيب المخاطر بالأولوية: احتمال × أثر |
| **الإجراءات** | وقائية (مراقبة، تحكم بالوصول، تدريب، أمن سيبراني) + ردّ فعلية (خطط استجابة، تواصل، بحث وإنقاذ) |

**الأطر المرجعية الملحقة:** كود ISPS لمنظمة الملاحة الدولية · إرشادات BMP MS · الوعي بالمجال البحري (MDA) · وتُستخدم معها أطر تحليل بيئة العمليات **PMESII** (سياسي · عسكري · اقتصادي · اجتماعي · معلوماتي · بنى تحتية) و**ASCOPE** (مناطق · بنى تحتية · قدرات · منظمات · أشخاص · أحداث) ضمن عملية **JIPOE**.

## ١٠) المبحث الثامن: الاتجاهات الحديثة في التحليل

| الاتجاه | الجوهر |
|---|---|
| **التحقق المفتوح (OSINT Verification)** | التحقق من الوسائط: تحديد الموقع (Geolocation) والزمن (Chronolocation) وفحص الأصالة قبل الاستشهاد |
| **تحليل الشبكات والروابط** | رسم علاقات الفاعلين والوسطاء والسفن والشركات لكشف الأنماط |
| **التحديث البايزي** | تعديل الاحتمال كلما وصل دليل جديد، بدل التمسك بحكم قديم |
| **التنبؤ المعاير** | برنامج ACE التابع لـIARPA و«مشروع الحكم الجيد» أنتجا ملايين التوقعات لقياس دقة التقدير ومعايرته |
| **الذكاء الاصطناعي التحليلي** | كشف الشواذ والأنماط والربط الآلي بين المصادر — أداة مساندة لا بديل عن المحلل |

## ١٢) الخلاصة

التحليل الاستخباري الدولي يقوم على أربع ركائز: **أنواع محددة للمنتج** (وصفي · جاري · تقديري · تحذيري · بحثي)، و**أساليب منظمة** في ثلاث عائلات (تشخيصية · معارضة · إبداعية)، و**لغة موحّدة لعدم اليقين** (احتمال + ثقة)، و**معايير حرفة مكتوبة تُدقَّق** (ICD 203 · PHIA · NATO AltA).

وبالمقارنة مع تقريرنا اليومي الحالي:

| الركيزة | وضعنا اليوم | الفجوة |
|---|---|---|
| أنواع المنتج | وقائع جارية + تحذيرات | لا تقدير ولا تحذير مبكر |
| الأساليب | بعض ACH مصغّر في «الاحتمالات والإسناد» | لا فحص افتراضات · لا مؤشرات · لا تحدٍّ منهجي |
| لغة عدم اليقين | «عالية/متوسطة/منخفضة» فقط | لا سلّم احتمالي سبعي ولا فصل صريح بين الاحتمال والثقة |
| المعايير المكتوبة | قواعد تحقق وتدقيق لغوي | لا معايير حرفة تحليلية ولا مراجعة نظيرة مستقلة |
| موثوقية المصادر | سلّم A–F / ١–٦ مطبَّق ✔ | يحتاج ربطه الصريح بكل تقدير |

---

## ١٣) التوصيات

**أ) فوري (يُدمج مع قسم «التحليل الاستخباري» المقترح):**

1. **اعتماد لغة الاحتمال الموحدة** (سلّم ICD 203 السبعي) + **درجة ثقة منفصلة** عن الاحتمال، ومنع العبارات المبهمة («قد»، «ربما»).
2. **ربط كل تقدير بسلّم الموثوقية A–F / ١–٦** المطبَّق لدينا، وذكر الأساس.
3. **تطبيق أربعة أساليب** في التقرير اليومي: فحص الافتراضات الأساسية · مؤشرات التغيّر · ACH مصغّر للإسناد · تقييم دقة تقديرات الأمس.
4. **بند ثابت لمؤشرات التحذير المبكر** (٣–٥ مؤشرات، لكل مؤشر ما يؤكده وما ينفيه).

**ب) قريب (شهر):**

5. **تحدي دوري للخط التحليلي**: فريق معارض/قبعة حمراء مرة شهريًا على أهم تقدير.
6. **توسيع تقييم المخاطر** لكل ممر ملاحي بمعادلة (تهديد × ثغرة × نتيجة) بمصفوفة احتمال/أثر.
7. **اعتماد التحقق المفتوح للوسائط** (تحديد الموقع والزمن) عند أي وسيط مشكوك فيه.

**ج) لاحق (ربع سنوي):**

8. **قياس دقة التقديرات** بأثر موثّق: كم تقديرًا تحقق؟ وما سبب الأخطاء؟
9. **إنشاء وثيقة مرجعية داخل العقل** `sections/55-intelligence.md` تضم هذه الأساليب ولغتها المعتمدة، وتُربط بمهارة `marine-news-brain`، ويُدرج في كل تقرير **وسم الأسلوب التحليلي المستخدم**.
10. **مراجعة نظيرة مستقلة** للتقرير (دور شبيه بأمين المظالم التحليلي) لضمان الموضوعية ومنع التسييس.
