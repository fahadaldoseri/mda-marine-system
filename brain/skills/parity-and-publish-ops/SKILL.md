# التماثل والنشر والتحقق الحي

## الغرض والحدود
اختر اتجاهًا واحدًا للتماثل، قِس قبل/بعد، ابنِ المخرج، انشر بقرار صريح، ثم تحقق من المسارات الحية والبصمات. هذه المهارة لا تدير تدوير الأسرار أو إغلاق الأعطال أو تأليف البوابات؛ استخدم `secret-rotation-ops` للأسرار، و`fault-closure-and-learning-ops` للإغلاق، و`gate-lifecycle-ops` للحواجز.

## الأدوار المحفوظة
- `server-repo-parity-ops`: جذور صريحة، قياس قبل/بعد، نسخة جافة، اتجاه واحد، بصمات، منع الزوائد، وفرع/طلب دمج بدل الدفع المباشر.
- `site-publish-live-verify-ops`: بناء `dist/`، فحوص HTML/بيانات/PDF/أسطح، قرار النشر، مسارات الموقع، انتشار الإصدار، ومقارنة المحلي بالحي.

## المسار الإلزامي
1. ثبّت `BRAIN_DIR`, `SITE_DIR`, `REPO_DIR`, `SKILLS_DIR` والتاريخ؛ لا تعتمد جذرًا مستنتجًا خطأً.
2. افحص قابلية النقل والأسرار والجذور، ثم قِس أعداد الملفات والزوائد والمفقود والانحرافات قبل التغيير.
3. اختر اتجاهًا واحدًا؛ نفّذ نسخة جافة وراجع خطة الجديد/المحدّث/المحذوف قبل التطبيق.
4. ابنِ من المصدر، وشغّل بوابات المحتوى والطباعة والأسطح، واحفظ المخرج والبصمة.
5. اطلب قرارًا صريحًا بالنشر؛ لا تعتبر نجاح الأمر انتشارًا.
6. بعد النشر افحص `/`, صفحة التقرير، الإضافات، المصادر، التغذية، اللوحات والمسارات المطلوبة مع إعادة المحاولة المحددة.
7. طابق النص المرئي/الإصدار/البصمات المحلية والحيّة؛ فرق البايتات الناتج عن المنصة لا يكفي وحده لإثبات فرق محتوى.

## الدليل المقيس المطلوب
سلّم أعداد الشجرتين، المفقود والزايد والانحراف والروابط، رمز كل تشغيل، بصمة المخرج المحلي، سجل التحقق الحي، زمن الانتشار، وحالة كل مسار. مثال الجولة الأخيرة: `gate-audit-*.json` و`perf-budget.json` يحفظان مخرجات البوابات والأداء؛ مسار حي بلا سجل/بصمة = وعْد غير مقيس.

## الحواجز
- `outside_scope` أو حذف يتجاوز السقف = منع.
- جذر يحتوي `.git`/أسرار/`state` أو شجرة غير صالحة = منع قبل النسخ.
- مسار حي ناقص، HTTP غير سليم، إصدار غير ظاهر، أو اختلاف نص مرئي = رمز 2.
- لا تُدخل ملفات مولّدة/كاشًا في مقارنة الكود؛ صنّفها عبر `generated-artifact-boundary-ops`.

## حلقة التعلم الذاتي
بعد كل انحراف أو فشل انتشار: **عطل** (اتجاه/مسار/بصمة/رمز) ← **درس** (جذر أو نطاق أو ترتيب بناء) ← **حاجز** (فحص مسار/استثناء/بوابة حيّة) ← **اختبار** (نسخة سليمة تمر، ملف زائد أو مسار حي قديم يمنع، ثم قياس بعدي). مثال: نجاح نشر مع صفحة `/reports/<date>.html` قديمة؛ الدرس أن فحص الجذر لا يثبت الإصدار؛ الحاجز مقارنة مؤشر الإصدار والنص المرئي؛ الاختبار يحقن صفحة قديمة ويتطلب رمز 2.

## أخطاء ممنوعة
- تشغيل اتجاهي التماثل في الأمر نفسه.
- أخذ دليل التماثل من داخل المرآة فقط.
- نشر تلقائي بلا قرار.
- اعتبار `git push` أو رسالة الاستضافة دليل انتشار حي.
- حذف الزوائد دون نسخة جافة وأرشيف وخطة.

## التسليم
سلّم خطة النسخة الجافة، القياسين قبل/بعد، البصمات، قرار النشر، سجل المسارات الحية، ومحضر الفرق. التفاصيل الموروثة محفوظة في `references/legacy/<old-skill>/`.

## الحد الفاصل مع المهارات المجاورة

> **الحد الفاصل:** هذه المهارة تدير تماثل الشجرة والمستودع والدفع؛ أما قياس ما يخدمه القارئ فعلًا (كود · حجم · نوع محتوى · بصمة) وإغلاق صف العطل بدليل، فمرجعه `rerun-step-to-live-parity-ops`.
