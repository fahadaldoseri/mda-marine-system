## الحالة الأولى: مانع «قالب جملة متكرر» كان معرّفًا لا صياغة

**العَرَض:** بوابة تغطية الأسلوب منعت تسليم سطحين، ورسالتها «قالب جملة متكرر أكثر من مرتين». النص المخالف الوحيد المتكرر أربع مرات كان المقطع:

```

```

وبعد إصلاح لغوي لاحق ظهر القالب نفسه في صورة إسناد:

```
·· MN-2026-11-03-06؛ MN-2026-11-03-04؛
·· MN-2026-11-03-06؛ MN-2026-11-03-05؛
·· MN-2026-11-03-06؛ MN-2026-11-03-06؛
```

**القياس المُميِّز:** المقطع بعد إزالة الأكواد والفواصل لا يحمل حرفًا واحدًا؛ وتطبيع الأرقام يحوّل رموزًا مختلفة إلى `- - -`، فيبدو نصًّا متكررًا وهو ليس كذلك.

**الإصلاح:** دالة الكشف لا تُدرج مقطعًا في عدّ القوالب إلا إذا حمل حرف لغة بعد تجريد الأكواد والفواصل والأرقام.

