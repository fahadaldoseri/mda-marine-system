# حلقة التعلم ومنع التكرار

تُنفّذ هذه الحلقة في نهاية **كل جولة** استُدعيت فيها المهارة، سواء مرّت البوابات أو مُنعت. لا يُغلق العطل بالتوثيق وحده.

## التسلسل الإلزامي

1. **سجّل العطل وأثره** في `audit/سجل-الأعطال-والثغرات.md`: رمز، تاريخ، السطح، العرض، السبب الجذري، الأثر، الإصلاح، والمانع الآلي. لا تكتب «مُغلق» قبل وجود المانع.
2. **أضف الدرس** إلى `memory/learning-log.jsonl` عبر الأداة القائمة، مع التصنيف والمصدر والدليل والحالة:

   ```bash
   python3 memory/record_learning.py \
     --lesson "إثبات البصمة قبل الاعتماد ومنع إعلان النجاح بلا مخرج" \
     --category operational --origin validator \
     --evidence "logs/approved-output-evidence-YYYY-MM-DD/evidence.json" \
     --status confirmed
   ```

3. **أعد بناء الفهرس.** شغّل أمر فهرسة الأعطال الموجود في نسخة المشروع واحفظ مخرجه. في هذه الشجرة، `audit/faults-index.jsonl` و`audit/فهرس-الأعطال.json` مخرجان مشتقان؛ لا تُعدّل أحدهما يدويًا. إذا لم يوجد سكربت فهرسة مستقل، أنشئ/شغّل سكربتًا مؤقتًا موثقًا يقرأ Markdown، يثبت مخطط JSONL، ويكتب الملفين، ثم سجّل الأمر في الدليل. لا تدّع أن الفهرسة تمت دون مخرج.
4. **شدّد آليًا.** أضف اختبارًا أو بوابة تمنع الشرط نفسه: مثال تعارض CSS ⇒ اختبار يكشف القاعدة المكررة، اختلاف بصمة ⇒ بوابة مطابقة، خروج 0 كاذب ⇒ عدّاد يفحص الأمر والمخرج معًا، تعارض قاموس ⇒ `check_registry_conflicts.py`.
5. **أثبت التراجع.** شغّل الاختبار الجديد على حالة فشل مصطنعة وحالة سليمة، واحفظ النتيجتين. لا تستخدم `|| true` لإخفاء فشل التشديد.
6. **أعد البوابات** وأرفق دليل الجولة الجديدة، ثم اكتب حالة العطل «مُغلق» مع اسم المانع وأمره.

## أدوات المشروع ذات الصلة

بعد تسجيل الدرس، يمكن تشغيل:

```bash
python3 memory/record_learning.py ...
python3 tools/reports_index.py --today YYYY-MM-DD
python3 tools/self_improve.py --date YYYY-MM-DD
```

`tools/skill_lessons.py --date YYYY-MM-DD` يسجل ملخص جولة البوابة في المشاريع التي تفعّله. لا يَستبدل تسجيل العطل والدرس أو إعادة بناء فهرس الأعطال أو إضافة المانع.

## قاعدة الإغلاق

إذا تعذر تسجيل السجل، أو لم يُعاد بناء الفهرس، أو لم يوجد اختبار/بوابة يمنع التكرار، فالحالة **مفتوحة** مهما كانت نتيجة PDF. الدليل يثبت ما حدث؛ المانع يثبت أن الدرس تعلّمه النظام.


## إعادة بناء فهرس الأعطال (أمر فعلي)

```bash
python3 /home/ubuntu/skills/approved-output-change-ops/scripts/rebuild_fault_index.py --brain "$BRAIN"
```

يُخرج `audit/faults-index.jsonl` و`audit/فهرس-الأعطال.json` من سجل الأعطال، ويُشغَّل بعد كل إدخال عطل، ويُختبر بـ`--brain` وحده في مجلد مؤقت قبل الاعتماد. غياب ملف القفل أو الـprofile لا يمنع الفهرسة: يُطبع تنبيه ويمضي، حتى لا تتعطل حلقة التعلم بسبب نقص سياق الإصدار.
