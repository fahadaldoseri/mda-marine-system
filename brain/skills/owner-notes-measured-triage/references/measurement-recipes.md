# وصفات القياس

كل وصفة: ما تُثبته · الأمر · كيف يُقرأ المخرج · الفخّ الشائع.

## 1) وجود نص أو غيابه

```bash
python3 scripts/probe_terms.py --root dist "العبارة" --context 80
```

- المخرج: المجموع + الملفات + سياق.
- الفخّ: البحث في المصدر (`generator/`) لا يُثبت ما يراه القارئ؛ فالقالب قد يُبنى بشرط. اقِس المخرج.

## 2) تكرار لفظ أو عنصر

```bash
python3 scripts/probe_terms.py --root dist "مستوى التهديد" "ما تغيّر"
```

- المخرج: عدد الظهور في كل صفحة.
- الفخّ: التكرار قد يكون مقصودًا في سطحين مختلفين؛ فافصل الصفحات بـ`--pages`.

## 3) صيغة الأمر مقابل أسلوب الغائب

```bash
python3 scripts/probe_terms.py --root dist --regex --pages "reports/*.html" "أوامر"
```

نمط عملي لكشف صيغة الأمر في العربية: انتهاء الفعل بواو الجماعة أو نون الأمر:

```
(ارفعوا|اطلبوا|أبقوا|أبلغوا|راقبوا|حافظوا|افصلوا|أعيدوا|لا تتخذوا|لا تفيدوا|لا تُنفذوا|سجّلوا|تحقّقوا)
```

- الفخّ: الكلمة نفسها قد تكون اسمًا («التوجيهات») لا فعلًا؛ فاقرأ السياق لا العدّ وحده.

## 4) تباين لوني

```python
def lum(h):  # #rrggbb
    c = [int(h[i:i+2], 16) / 255 for i in (1, 3, 5)]
    c = [x / 12.92 if x <= .03928 else ((x + .055) / 1.055) ** 2.4 for x in c]
    return .2126 * c[0] + .7152 * c[1] + .0722 * c[2]

def ratio(a, b):
    la, lb = sorted((lum(a), lum(b)), reverse=True)
    return round((la + .05) / (lb + .05), 2)
```

- المعيار: ≥ 4.5:1 للنص العادي · ≥ 3:1 للعناصر الكبيرة والحدود.
- الفخّ: قِس من **متغيّرات الأنماط الفعلية** في المخرج لا من صورة اللقطة.

## 5) الروابط والمعرّفات

```bash
python3 scripts/audit_links.py --root dist --strict --json /tmp/links.json
```

- تُثبت: روابط داخلية مكسورة · أهداف نسبية مفقودة · روابط فارغة · روابط `http` · جرد خارجي.
- علامة تشخيصية مهمة: **صفر رابط داخلي مع وجود معرّفات** = الربط معدوم لا مكسور.

## 6) مطابقة ما يراه القارئ للمخرج

```bash
curl -sSL -o /tmp/live.html -w "%{http_code} %{content_type} %{size_download}\n" "$URL"
sha256sum /tmp/live.html dist/index.html
```

- الفخّ: بعض المستضيفات تُعيد **308** لمسار `.html` وتنجح بلا امتداد؛ فتبِّع التحويل قبل الحكم بالفشل.
- الفخّ: نوع محتوى غير `text/html` يعني قناة عرض غير صالحة حتى لو أعادت 200.

## 7) عمر اللقطة مقابل البناء الحالي

```bash
git log -1 --format='%h %ad %s' --date=short -- dist/index.html
stat -c '%s %y' dist/index.html
```

- إن كان آخر تغيير للملف أحدث من اللقطة، فالأرجح أن ما تراه العين نسخة قديمة (ذاكرة متصفح أو نشر سابق).
- الفخّ: الاختلاف في **أسماء الوسوم** («ما نُشر» مقابل «ما تغيّر») دليل قاطع على أن اللقطة لبناء أقدم.

## 8) الأرقام

- خذ الرقم من ملف المخرج أو من المصدر الحاكم، لا من نص سابق ولا من ذاكرة.
- ارفض الرقم غير المؤرخ أو المتناقض مع مصدره؛ وسجّل ذلك سببًا لا استثناءً.
- الفخّ: رقم صحيح من تاريخ آخر لا يصلح لتاريخ اليوم.

## 9) الفحص الشبكي للروابط الخارجية

- **403** من مواقع مثل UKMTO وCENTCOM وMaritime.dot.gov = حجب الطلبات الآلية، لا رابط مكسور. لا تُعلن كسرًا بناءً عليه.
- أعلن ما قِيس: عدد ما ردّ 200 وعدد ما حُجب، وسمِّ النطاقات.

## 10) تماثل سطحين بلغتين

- اقِس: هل بقي نص باللغة المصدر داخل سطح اللغة الهدف؟ وهل عدد الوحدات المترجمة يطابق المصدر؟
- الفخّ: تطبيع المفاتيح (تشكيل · مسافات · أرقام) يجعل وحدتين متطابقتين تبدوان مختلفتين؛ طبّع قبل المقارنة.

## 11) قاعدة العرض النهائية

اجمع كل قياس في جدول واحد: **البند · ما ظهر في اللقطة · ما أثبته القياس · الحالة**. الجدول نفسه هو الجرد.
