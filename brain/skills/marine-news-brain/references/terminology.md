# قاموس Marine News Brain

| لا تستخدم | استخدم |
|---|---|
| هجمات جديدة عند عدم ثبوت كل الوقائع | وقائع أمنية جديدة |
| إشعارات استشارية | نشرات استشارية |
| تحذير هجومي | تحذير أمني بحري أو تحذير UKMTO |
| ضربات بأجسام مجهولة | إصابات بمقذوفات غير محددة المصدر |
| الصورة الجغرافية | التوزيع الجغرافي |
| الاختناق المرصود | التكدس الملاحي المرصود |
| يقظة تشغيلية فورية | رفع مستوى المراقبة فورًا |
| الجهة الفاعلة | الطرف المسؤول أو الجهة المنفذة |
| المراجعة المعارضة الذاتية | اختبار الفرضية المضادة |
| ما يعنينا | الأثر التشغيلي |

- `Warning`: تحذير أمني بحري أو تحذير للملاحة حسب المحتوى.
- `Advisory`: نشرة استشارية.
- `Incident`: حادث بحري أو واقعة بحرية.
- `Attack`: هجوم مؤكد فقط عند ثبوت الهجوم.
- `Unknown projectile`: مقذوف غير محدد المصدر.
- `Military interaction`: تفاعل عسكري؛ لا ترفعه إلى مواجهة أو احتكاك بلا دليل.
- `Maritime traffic`: الحركة الملاحية.
- `Congestion`: التكدس الملاحي.
- `Threat assessment`: تقدير مستوى التهديد.
- `Confidence`: درجة الثقة.
- `Competing hypotheses`: الفرضيات المتنافسة.
- `Adversarial challenge`: اختبار الفرضية المضادة.
- استخدم «أفادت» للنقل الإعلامي و«أعلنت/أكدت» للمصدر المباشر.
- استخدم «حالتهم مستقرة»، «الجانب الأيسر، أي جانب الميناء»، «الناقلات المغادرة للمضيق»، و«بحارة من جنسيات آسيوية».
