# عقد القياس وفرز الإخفاقات

## 1) شكل القياس الصالح

| العنصر | الشرط |
|---|---|
| الأمر | قابل لإعادة التشغيل حرفيًا، مكتوب في التقرير |
| المحيط | متغيرات الجذر مُمرَّرة (`SITE_DIR` · `BRAIN_DIR` · `BACKUP_REPO_DIR`) |
| المخرج | مقتطف حرفي (لا وصف) |
| رمز الخروج | مذكور · و`rc=0` وحده يعني «سليم» |
| التاريخ | مؤرَّخ بيوم القياس |
| الأثر | **قراءة فقط** — لا كتابة ولا نشر ولا إرسال |

**مرفوض:** «قِستُ سابقًا» · «يبدو أن» · «من الذاكرة» · رقم بلا أمر · رقم بلا تاريخ.

## 2) فرز إخفاقات البوابة

قائمة الإخفاقات ليست قائمة عيوب. لكل إخفاق أربع حالات:

| الحالة | كيف تعرفها | العلاج |
|---|---|---|
| **كاذب — محيط** | ينجح عند تمرير متغيرات الجذر | أصلح **اشتقاق الجذر** لا المحتوى |
| **حقيقي — عيب بيانات** | يفشل بعد تصحيح المحيط، والمصدر أقدم من المشتق | أعد التوليد بالمولّد الحاكم |
| **حقيقي — عيب شيفرة** | يفشل مع traceback أو شرط غير محقق | أصلح السبب الجذري + اختبار موجب وسالب |
| **نائم** | يمرّ دائمًا حتى مع مدخل مخالف | اكتب له مدخلًا مخالفًا يُثبت أنه يعمل |

### إصلاح اشتقاق الجذر (نمط الفشل المغلق)

```bash
if [ -z "${SITE:-}" ]; then
  for c in "${SITE_DIR:-}" "$B/../seawatch" "/home/ubuntu/seawatch"; do
    [ -n "$c" ] && [ -d "$c/dist" ] && SITE="$(cd "$c" && pwd)" && break
  done
fi
if [ -z "${SITE:-}" ] || [ ! -d "$SITE/dist" ]; then
  printf '  ✘ محيط البوابة: جذر الموقع غير محدد — فشل مغلق\n'; exit 2
fi
export SITE_DIR="$SITE"
```

المطلوب: **مرشّحون بشرط وجود المخرج** + **فشل مغلق برسالة صريحة** — لا سقوط صامت إلى مسار مُخمَّن يُنتج إخفاقات كاذبة.

## 3) الملفات المشتقة

الملف المشتق (معجم · مصفوفة تتبع · فهرس · قاموس) يُولَّد ولا يُحرَّر:

1. حرّره يدويًا ⇒ بصمته تتأخر عن مصادره ⇒ البوابة تكشفه بعد جولات.
2. العلاج: المولّد الحاكم (`build_lexicon_corpus.py --apply` …) ثم إعادة القياس.
3. الحارس المطلوب: مقارنة **البصمة المحسوبة** بالمخزّنة، وإبلاغ عدد الكلمات/الصفوف في الرسالة.

## 4) تصحيح ادّعاءاتك

كل جملة في تقريرك فيها رقم أو «صفر» أو «تم» تُفحص على المخرج:

```bash
python3 scripts/verify_claims.py --target <output-dir> --claim "<نص>" --expect absent
```

الادّعاء المخالف يُسجَّل عيبًا باسمك (`خ-xx`)، ويُصحَّح في التقرير، ويُضاف بندًا في الخطة. العبرة: العيب الذي تكتشفه أنت أرخص من العيب الذي يكتشفه المالك.

## 5) الدليل في دفتر القرارات

- `kind=file` ⇒ المسار يُحلّ فعليًا من جذر الحارس (استعمل `../../seawatch/...` عند اختلاف الجذور).
- `kind=measurement` ⇒ الأمر + الناتج الرقمي في `note`.
- قرار «منفَّذ» بلا دليل = رفض من الحارس. وقرار غير منفَّذ بلا خطوة تالية = رفض أيضًا.
