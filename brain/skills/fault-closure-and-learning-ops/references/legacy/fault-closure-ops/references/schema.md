# المخطط والمفردات — مرجع

## 1) صف السجل القياسي (12 عمودًا)

| # | العمود | المعنى |
|---|---|---|
| 0 | المعرّف | `ك-NNN` (ظاهر=ع، كامن=ك، ثغرة إجراء=ث، ملاحظة=م) |
| 1 | التاريخ | `YYYY-MM-DD` أو `—` للصفوف الموروثة |
| 2 | المحور | system · data · process · print · language · security |
| 3 | العَرَض | ما ظهر فعليًا (وقد يبدأ بتصنيف قصير) |
| 4 | السبب الجذري | لماذا حدث |
| 5 | الإصلاح | ما نُفِّذ — يجب أن يحمل `منفَّذ` أو `جزئي` أو `لم يبدأ` |
| 6 | الحاجز | قاعدة المنع + **دليل النتيجة** |
| 7 | الحالة الأصلية | النصّ كما ورد — **لا يُبنى عليه حكم** |
| 8 | قاعدة الإصلاح | `منفَّذ` \| `قيد التنفيذ` \| `لم يبدأ` |
| 9 | قاعدة التحقق | `تحقق تشغيلي ناجح` \| `تحقق أولي` \| `غير متحقق` |
| 10 | قاعدة الحاجز | `فعّال` \| `مطبَّق` \| `غير موثَّق` |
| 11 | الحالة المشتقة | `مغلق` \| `مفتوح` \| `بانتظار التحقق` \| `موروث غير مثبت` |

> المحرّك يقرأ النصّ الحرّ من الأعمدة 1–7 (بعد المعرّف) ويشتقّ الأعمدة 8–11.

## 2) نمط النتيجة المقبول (OUTCOME)

يُقبل الدليل فقط إذا احتوى علامة نتيجة قابلة لإعادة التشغيل:

```
خرج\s*0 | exit\s*0 | رمز\s*2 | نجح\s*\d+\s*·?\s*فشل\s*0 | \d+\s*/\s*\d+ | مطابق( تمامًا)? | بصمة\s*[0-9a-f]{6,}
```

**مرفوض:** «مُصلح» · «مرور كاذب» · «تم» · «يعمل» · نصّ وصفي بلا رقم أو رمز.
**مقبول:** `تحقق حي 2026-10-28: python3 validators/check_portable_paths.py → خرج 0`
**مقبول:** `تحقق حي 2026-10-28: preflight_check.py → خرج 0 · نجح 39 · فشل 0`

## 3) قواعد الاشتقاق

```
state = مغلق          إن كان الإصلاح منفَّذًا والحاجز (مطبَّق|فعّال) والتحقق ناجحًا
      = مفتوح          إن دلّ النصّ على مفتوح|لم يُصلح|بانتظار قرار
      = موروث غير مثبت إن كان التاريخ = —
      = بانتظار التحقق في غير ذلك
```
الدليل (blob) = `الإصلاح + الحاجز` فقط — لذلك **يجب أن يحمل أحدهما دليل النتيجة** (خرج/رمز/نجح…فشل 0/n من n/بصمة).

## 4) ملف الاستثناءات

```json
{"fault_id": "ك-118", "owner": "—", "reason": "موروث بلا أثر تشغيل", "expiry": "2026-12-27", "evidence": "بلا أثر"}
```
- بلا `expiry` = الاستثناء غير صالح.
- الاستثناء **لا يمنح إغلاقًا**؛ يمنح فقط عدم المنع عند غياب الدليل.

## 5) مصفوفة التتبع (Traceability)

لكل صف: `fault_id · lesson_id · fix_applied · verify_ok · barrier_active · state · run_evidence`.
- `lesson_id` يُطبَّع قبل المقارنة: البادئة + العدد بلا أصفار بادئة (`ك-09` ⇒ `ك-9`).
- المطابقة على الأساس **وعلى** المعرّف قبل اللاحقة (`ك-122/ب` ⇒ `ك-122`).
- `run_evidence` = **مقتطف يحتوي نتيجته** (≈ 95 حرفًا حول المطابقة) لا بادئة المقطع.

## 6) الثبات

تمريرتان متتاليتان بلا `--write`-only يجب أن تعطيا:
`ثبات كامل (سجل + تعلم): نعم` و`دروس مشتقة: 0`.
ظهور دروس مشتقة في التمريرة الثانية = عطل في مطابقة المعرّفات أو في بناء السجل.
