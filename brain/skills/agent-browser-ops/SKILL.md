# agent-browser — قراءة صفحة عامة

المصدر المثبت: `vercel-labs/agent-browser` عند `3f43a2a`. الأداة المثبتة: `agent-browser` 0.45.0.

## الفرق عن المهارات المجاورة

| المهارة | الحد |
|---|---|
| `source-route-triage-ops` | تقرر مسار المصدر وتمنع تجاوز التحقق البشري. هذه تقرأ الصفحة بعد اختيار المسار. |
| `source-ingest-ops` | تجمع التغذية الرسمية وتحفظ الأصل. هذه لا تحفظ أصلًا ولا تعدّل عدّادًا. |
| `parity-and-publish-ops` | تطابق النشر. هذه تقرأ فقط. |

## متى تُستدعى

للتحقق من صفحة حية أو مصدر عام. بعد القراءة: `agent-browser close`.

## الأمر

```bash
agent-browser open URL
agent-browser snapshot -i
agent-browser close
```
