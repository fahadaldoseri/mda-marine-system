# الأسرار

قرار المالك (24 أكتوبر 2026): تُحفظ الأسرار نصًّا صريحًا في هذا المستودع الخاص كي يستعملها أي محرك ذكاء اصطناعي يعمل عليه دون اعتماد على الخادم.

## أين وكيف
- الملف الوحيد: `brain/secrets/secrets.env` بصيغة `NAME=value` سطرًا لكل سر. الأسماء المعتمدة في `secrets.env.example`.
- `tools/telegram_send.py` يقرؤه تلقائيًا إن غاب المتغير من البيئة (البيئة تتقدم عليه). أي أداة جديدة تقرأ الأسرار من متغير بيئة أولًا ثم من هذا الملف.
- نسخ الخادم الاحتياطي يضمّه إلى المستودع كبقية البيانات.

## حدود لا تُكسر (لأن النص صريح)
1. المستودع يبقى **خاصًّا** وبلا فروع (forks) ولا متعاونين غير موثوقين. قبل أي تغيير في ذلك: تدوير كل الأسرار.
2. لا يُطبع سر في سجل أو مخرج أو تعليق طلب دمج أو رسالة التزام. لا يُنسخ إلى `docs/` ولا إلى ملف عام.
3. سير عمل GitHub لا يقرأ هذا الملف.
4. إن حجب GitHub دفعًا بسبب «حماية الدفع من الأسرار» فالقرار للمالك (السماح من رابط الحجب أو التشفير)؛ لا يُلتفّ عليه.
5. عند أي شك في تسرّب: تدوير الرمز من مزوّده أولًا (BotFather للتلغرام)، ثم تحديث هذا الملف.
