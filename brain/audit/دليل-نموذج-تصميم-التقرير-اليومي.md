# دليل نموذج تصميم «التقرير اليومي لأمن الملاحة» — ملف مرجعي للمستشار

> **الغرض:** هذا الملف يسلّمك كود نموذج التصميم كما هو في الإنتاج، بلا اختصار ولا تجميل، مع شرح كل طبقة: الرموز، الألوان، الأحجام، الطبقات، الطباعة، الخريطة، بنية الصفحة، وتصدير PDF وWord.
> **الجمهور:** مستشار أكواد/تصميم يريد أن يفهم النظام ليقدّم مقترحات تحسين.
> **آخر تحديث:** 22 أكتوبر 2026 — مبني على الكود المدفوع: الموقع `dec246e` والنظام `caa8b6a`.

## ما المطلوب منك تحديدًا

1. **مراجعة قواعد الطباعة** في `STYLE` (القسم 5) — فيها قواعد متعارضة أشرت إليها صريحًا في القسم 6، وأريد رأيك في ترتيبها وتنظيفها.
2. **التحقّق من منظومة القياس**: هل الطريقة الصحيحة لضمان مطابقة الشاشة/الورق هي البناء بوحدات `pt`/`mm` من الأساس؟
3. **الخريطة SVG** (القسم 8): وضع التسميات والشارات يحتاج خوارزمية منع تصادم.
4. **الأداء والحجم**: ملف PDF الحالي 821 ك.ب و10 صفحات، والخط العربي مُدمج كـType 3 (القسم 7) — ما البديل الأفضل.
5. **أي مقترح يُغيّر الشكل النهائي يحتاج موافقة صاحب القرار** (الشكل v3 مُجمَّد)، لذا رتّب مقترحاتك إلى: (أ) ما لا يغيّر الشكل، (ب) ما يغيّره.

**تعريف سريع بالمصطلحات:** في هذا النظام **الفترة** تعني النافذة الزمنية للتقرير (لا تُستخدم كلمة «نافذة»)، **العلم** هي راية السفينة، **التوجيهات التشغيلية** هو قسم الإجراءات (لا «ما يعنينا»)، والأرقام تُكتب لاتينية 0–9 دائمًا حتى داخل النص العربي.

## 2) هوية التصميم

- **الحركة الفنية:** «غرفة عمليات بحرية» — داكن عملياتي، لون فيروزي واحد، بلا زخرفة ولا تدرّجات.
- **المبادئ الأربعة:** (1) المعلومة قبل الزينة، (2) فصل وظيفي بالألوان لا بالزخرفة، (3) كثافة مقروءة على الشاشة وعلى الورق، (4) وسم لفظي مرافق لكل لون (لا يُعرف المستوى باللون وحده).
- **فلسفة الألوان:** خلفية شبه سوداء `#050a12` تُبرز النص بلا إجهاد؛ لون الفيروزي `#22c3b6` للهوية والتفاعل؛ الأحمر `#ff5d52` للخطر، والبرتقالي `#ffb02e` للتحذير، والأخضر `#33d07a` للمؤكد. وفي الطباعة تُقلب المنظومة إلى ورق أبيض وحِبر داكن مع تخفيف الألوان لتبقى قابلة للقراءة على ورق عادي (انظر القسم 5).
- **البصمة والتمييز:** كل لون حالة يقابله نص: «مؤكد» · «مرجّح» · «ممكن» · «غير حاسم»؛ و«مرتفع جدًا» للتهديد.
- **الشعار والاسم:** نص «مركز الوعي بالمجال البحري · MDA.BH» في التذييل، والاختصار المعتمد «و ب» في الترويسة.

## 4) بنية المكوّنات (HTML) — القالب الكامل

المصدر: `generator/build_report.py` — دالة `build()` (يتولّد منها HTML الصفحة كاملة).

```python
def build(md_path: Path, out_path: Path, meta: dict, doc_mode: bool = False):
    md = md_path.read_text(encoding="utf-8")
    defs = parse_ref_defs(md)
    sections = parse_sections(md)
    if not sections:
        raise BuildError(
            "لم يُعثر على أي قسم بعنوان من المستوى الثاني (##) في الملف المصدر. "
            "تأكد من حفظ التقرير بأقسام بصيغة Markdown صحيحة."
        )
    validate_meta(meta)
    # سياسة عرض الرموز (2+5): كامل مرة واحدة في «الوقائع الجديدة»، ومختصر مدموج برقم البلاغ الرسمي في بقية المواضع
    _mdate = re.search(r"(\d{4}-\d{2}-\d{2})", md_path.name)
    report_date = _mdate.group(1) if _mdate else ""
    official = codes.official_map(meta)
    BLK.set_code_context(report_date, official)
    try:
        import map_gulf as _mg
        _mg.REPORT_DATE = report_date
    except Exception:
        pass

    # ترتيب الأقسام بالأهمية: القرار والصورة ← الوقائع ← التحليل ← الدعم
    # (الترتيب مستقر، والأقسام غير المعروفة تبقى في آخرها)
    order = [
        "ما تغيّر",         "الخلاصة",         "بطاقة القرار",         "التوزيع الجغرافي للوقائع",
        "مؤشرات الموقف",         "مستوى التهديد",         "التوجيهات التشغيلية",         "الوقائع الجديدة",
        "التحذيرات والنشرات",         "سجل IMO",         "التحليل الاستخباري",         "الاحتمالات",         "الحركة الملاحية والتكدس",
        "ما لم يُحسم",         "المراقبة المستمرة",         "الخلفية القائمة",         "المصادر والمراجع",

    ]

    def _order_key(sec):
        for i, k in enumerate(order):
            if k in sec["title"]:
                return i
        return len(order)

    sections = [x for x in sections if not _hidden(x["title"])]
    sections = sorted(sections, key=_order_key)

    # كتل خاصة بكل قسم: خريطة عنوان القسم إلى اسم الكتلة
    blocks_map = meta.get("blocks") or {}
    block_data = {k: meta.get(k) for k in ("indicators", "hypotheses", "gaps", "event_keys", "timeline", "source_reliability", "vessel_identity", "report_classes", "intel_analysis")}
    if not isinstance(blocks_map, dict):
        blocks_map = {}

    # خريطة الوقائع: تُبنى من إحداثيات معلَنة في ملف الواجهة فقط
    map_html = ""
    mp = meta.get("map") or {}
    if isinstance(mp, dict) and mp.get("points"):
        try:
            from map_gulf import build_map

            map_html = build_map(mp["points"], mp.get("caption"), mp.get("inset"))
        except Exception as e:  # لا يُسقط فشل الخريطة بناء التقرير
            print(f"تنبيه: تعذر توليد الخريطة ({e})", file=sys.stderr)
            map_html = ""

    # شريط المؤشرات
    kpi_html = ""
    kpis = meta.get("hero_kpis", [])
    if kpis:
        tiles = []
        for k in kpis:
            acc = k.get("accent", "ok")
            if acc not in ("ok", "info", "warn", "danger"):
                acc = "ok"
            tiles.append(
                f'<div class="kpi acc-{acc} reveal"><em></em>'
                f'<div class="k-l">{inline(k.get("label", ""))}</div>'
                f'<div class="k-v bidi">{esc(k.get("value", ""))}</div>'
                + (f'<div class="k-d">{BLK.trend_html(k.get("delta"))}</div>' if k.get("delta") else "")
                + f'<div class="k-n">{inline(k.get("note", ""))}</div></div>'
            )
        kpi_html = '<div class="kpis">' + "".join(tiles) + "</div>"

    threat = meta.get("threat_level", "")
    tcls = threat_class(threat) if threat else ""

    # قاموس الرموز والمصطلحات: يُطبع قسمًا مستقلًا بعد الخلاصة.
    # عطل ك-36: كان في تذييل الصفحة، وأنماط الطباعة تخفي التذييل، فغاب عن PDF تمامًا.
    glossary_html = ("" if _hidden("قاموس الرموز والمصطلحات")
                     else BLK.glossary(meta.get("glossary")))

    # قائمة الأقسام المخفية تُطبع للسجل مرة واحدة (تتبّع القرار لا التخمين)
    _hid = sorted(HIDDEN_SECTIONS)
    print("أقسام مُخفاة من الإصدار: " + " · ".join(_hid), file=sys.stderr)

    body = []
    for idx, sec in enumerate(sections):
        t = sec["title"]
        ic = SECTION_ICONS.get(t, "source")
        pri = " pri" if any(p in t for p in PRIORITY_SECTIONS) else ""
        body.append(f'<section class="doc{pri} reveal" id="sec-{idx + 1:02d}" aria-labelledby="h-{idx + 1:02d}">')
        body.append(
            f'<h2 id="h-{idx + 1:02d}"><span class="ico">{icon(ic)}</span>{inline(t, defs)}</h2>'
            '<div class="h-rule"></div>'
            + (f'<p class="sec-lede">{esc(SECTION_HINTS[t])}</p>' if SECTION_HINTS.get(t) else "")
        )
        section_html = render_section_body(t, sec["lines"], defs, doc_mode)
        if not codes.is_primary(t):
            section_html = codes.demote(section_html, report_date, official)
        if map_html and "التوزيع الجغرافي للوقائع" in t:
            # جدول التوزيع أولًا ثم الخريطة: الجدول يمتدّ فيمتلئ الفراغ، والخريطة تأخذ مساحتها كاملة
            section_html = section_html + map_html
        for key, bname in blocks_map.items():
            if key in t:
                for _bn in str(bname).split('+'):
                    if _bn in HIDDEN_BLOCKS:
                        continue
                    if block_data.get(_bn):
                        section_html += BLK.render_block(_bn, block_data[_bn], inline)
        # عطل ك-72: تنبيه القسم كان داخل حلقة كتل المؤشرات فيتكرر بعددها (6 مرات في إصدار 20 أكتوبر).
        # القاعدة: تنبيه القسم يُكتب مرة واحدة في مستوى القسم لا داخل حلقة عناصره.
        if "الحركة" in t:
            section_html += '<p class="src-note">قراءة اتجاه من منصة رصد — تُراعى مهلة التحديث واحتمال انقطاع الإرسال أو spoofing.</p>'
        if "التوزيع الجغرافي" in t:
            section_html += '<p class="src-note">تحذيرات IHO/NAVAREA تُربط بإحداثياتها عند توفرها؛ والويب لا يستبدل البث الملاحي المعتمد.</p>'
        body.append(section_html)
        body.append("</section>")
        if "الخلاصة" in t and glossary_html:
            body.append(
                '<section class="doc reveal" id="sec-glossary" aria-labelledby="h-glossary">'
                '<h2 id="h-glossary"><span class="ico">' + icon("source") + '</span>قاموس الرموز والمصطلحات</h2>'
                '<div class="h-rule"></div>'
                '<p class="sec-lede">تعريفات الرموز والمصطلحات المستخدمة في هذا التقرير.</p>'
                + glossary_html + "</section>")

    title = meta.get("title") or DAILY_TITLE
    sub = meta.get("subtitle") or ""
    generated = meta.get("generated_label") or datetime.now(timezone.utc).strftime("%Y-%m-%d %H:%M UTC")

    chips = []
    if meta.get("version"):
        chips.append(f'<span class="chip">رقم النسخة <b>{esc(meta["version"])}</b></span>')
    if generated:
        chips.append(f'<span class="chip">آخر تحديث <b class="bidi">{esc(generated)}</b></span>')
    if meta.get("window"):
        chips.append(f'<span class="chip">فترة التغطية <b>{esc(meta["window"])}</b></span>')
    if meta.get("sources_checked") not in (None, ""):
        chips.append(f'<span class="chip">مصادر مفحوصة <b class="bidi">{esc(meta["sources_checked"])}</b></span>')
    if meta.get("sources_cited") not in (None, ""):
        chips.append(f'<span class="chip">مصادر مستشهد بها <b class="bidi">{esc(meta["sources_cited"])}</b></span>')

    notice_html = ""
    if meta.get("notice"):
        notice_html = f'<div class="notice">{icon("shield")}<div>{inline(meta["notice"], defs)}</div></div>'

    threat_html = ""
    if threat:
        threat_html = (
            f'<div class="threat {tcls}"><div class="lbl">مستوى التهديد</div>'
            f'<div class="val">{esc(threat)}</div></div>'
        )

    date_label = meta.get("date_label") or ""
    cls_html = BLK.classification_banner(meta.get("classification"))
    decision_html = BLK.decision_card(meta.get("decision_card"), inline)
    rkey_html = BLK.reading_key() if any("[" in l and "]" in l for l in md.split("\n")) else ""
    changes_html = BLK.changes_block(meta.get("changes"), inline)
    ledger_html = (
        f'<div class="glossary">السجل التراكمي: '
        f'<a class="bidi" href="{esc(meta["ledger_url"])}" target="_blank" rel="noopener noreferrer">{esc(meta["ledger_url"])}</a></div>'
        if meta.get("ledger_url") else ""
    )
    doc = f"""<!DOCTYPE html>

<head>

    <div class="brand">

      </div>

      {f'<span class="chip">{esc(date_label)}</span>' if date_label else ''}

<div class="wrap">

LTR_PATTERNS = [
    r"\b\d{4,6}Z(?:\s+[A-Z]{3}\s*\d{2})?\b",                       # DTG: 180400Z OCT 26
    r"\b\d{1,3}[-°]\d{1,2}(?:\.\d+)?['′]?\s*[NS]\b",               # 26-16.8N
    r"\b[NS]\s?\d{1,3}[°-]\d{1,2}(?:\.\d+)?['′]?",                  # N 057°40.65′
    r"\b\d{1,3}[-°]\d{1,2}(?:\.\d+)?['′]?\s*[EW]\b",               # 056-08.6E
    r"\b[EW]\s?\d{1,3}[°-]\d{1,2}(?:\.\d+)?['′]?",                  # E 21.48°
    r"\b(?:MN|EST)-\d{4}-\d{2}-\d{2}-\d{2}\b",  # رمز واقعة أو تقدير كاملًا في كتلة LTR واحدة
    r"\bIMO\s?\d{6,7}\b", r"\bMMSI\s?\d{8,9}\b",
    r"\bUKMTO\s?\d{2,3}\s?[-–]\s?\d{2}\b", r"\bNAVAREA\s+[IVX]+\s+\d{2,3}/\d{2}\b",
    r"\b\d{2,3}/\d{2}\b", r"\b[A-Z][A-Z0-9]{2,}(?:\s+[A-Z0-9]{2,})*\b",
]
_LTR_RE = None


def isolate_ltr(html: str) -> str:
    """يغلّف المعرّفات والأوقات والإحداثيات والأسماء اللاتينية بكتلة LTR معزولة.

    يمنع انقلاب ترتيب الإحداثيات والرموز عند العرض في سياق عربي RTL.
    """
    global _LTR_RE
    if _LTR_RE is None:
        _LTR_RE = re.compile("|".join(f"(?:{p})" for p in LTR_PATTERNS))
    parts = re.split(r"(<[^>]+>)", html)
    for k, part in enumerate(parts):
        if not part or part.startswith("<"):
            continue
        parts[k] = _LTR_RE.sub(lambda m: f'<span class="ltr">{m.group(0)}</span>', part)
```

## 6) قواعد متعارضة مرصودة في أنماط الطباعة (أولوية للمراجعة)

هذه ملاحظات موضوعية على الأنماط نفسها، أوردها بصراحة لأنها تؤثر في الناتج:

| # | الموضع | النص | الأثر |
|---|---|---|---|
| 1 | آخر `@media print` | `*{break-inside:auto !important}` في سطر، ثم `tr,.kpi,.map-legend li…{break-inside:avoid !important}` | تعمل بالتعاقب، لكن الاعتماد على `!important` المتعارض يجعل السلوك هشًّا: أي إضافة لاحقة تُلغي ما قبلها بلا إنذار |
| 2 | تشخيص متروك في الإنتاج | `*{break-after:auto !important;break-before:auto !important}` | يُلغي فعليًا قواعد `break-after:avoid` المعلنة قبله (ومنها منع العنوان اليتيم) — مصدر أعطال متكررة |
| 3 | تشخيص متروك | `body,p,li,td,th{line-height:1.36 !important}` | الأسطر في الطباعة 1.36 مقابل معيار مقترح سابقًا 1.65؛ يُقرأ كثيفًا ويؤثر في قياسات التعبئة |
| 4 | حجم المتن | `body{font-size:10.8pt}` ثم `section.doc{font-size:10.2pt!important}` | حجم المتن الفعلي 10.2pt لا 10.8pt ولا 11.5pt المقترح من المختصين |
| 5 | تشخيص متروك | `*{overflow:visible !important}` | يفتح كل الحاويات (مقصود لتمكين الانقسام) لكنه يمنع أي قصّ مقصود لاحقًا |
| 6 | الخريطة | `max-height:145mm` مكرّر ثلاث مرات | تكرار يُصعّب التتبّع |
| 7 | قوس زائد | إغلاق `}` عند السطر 619 بعد إغلاق `@media print` | احتمال كتلة فارغة/خطأ بنيوي؛ يستحق التحقق بمحلّل CSS |

**سؤال للمستشار:** ما الطريقة الأنظف لإدارة سلوك الكسر بين الصفحات في Chromium: محرّك واحد بأولويات واضحة، أم إعادة كتابة الطباعة بالكامل على أساس «كل كتلة قابلة للانقسام إلا ما نُصّ عليه»؟

```python
    global BBOX, MID_LAT, ASPECT, HEIGHT, BOX, _SX, _SY, WIDTH
    WIDTH = width
    BBOX = bbox
    MID_LAT = (bbox[1] + bbox[3]) / 2.0
    ASPECT = math.cos(math.radians(MID_LAT))
    HEIGHT = WIDTH * (bbox[3] - bbox[1]) / ((bbox[2] - bbox[0]) * ASPECT)
    BOX = box(*bbox)
    _SX = WIDTH / ((bbox[2] - bbox[0]) * ASPECT)
    _SY = HEIGHT / (bbox[3] - bbox[1])


_set_bbox(MAIN_BBOX)


def pt(lon, lat):
    return (lon - BBOX[0]) * ASPECT * _SX, (BBOX[3] - lat) * _SY


def _load(name):
    p = DATA / f"{name}.geojson"
    return json.loads(p.read_text(encoding="utf-8")) if p.exists() else None


def _ring_d(ring):
    pts = " ".join(f"{x:.1f},{y:.1f}" for x, y in (pt(c[0], c[1]) for c in ring.coords))
    return f"M{pts}Z"


def _geom_paths(geom):
    if geom.is_empty:
        return []
    geoms = [geom] if isinstance(geom, Polygon) else (list(geom.geoms) if isinstance(geom, MultiPolygon) else [])
    out = []
    for g in geoms:
        if not isinstance(g, Polygon):
            continue
        d = _ring_d(g.exterior)
        for hole in g.interiors:
            d += _ring_d(hole)
        if d:
            out.append(d)
    return out


_LAND_CACHE = {}
_BORDER_CACHE = {}


def _land_paths():
    key = BBOX
    if key in _LAND_CACHE:
        return _LAND_CACHE[key]
    land = _load("ne_50m_land")
    paths = []
    if land:
        for feat in land["features"]:
            g = feat.get("geometry") or {}
            t = g.get("type")
            geoms = []
            if t == "Polygon":
                geoms = [Polygon(g["coordinates"][0], g["coordinates"][1:])]
            elif t == "MultiPolygon":
                geoms = [Polygon(p[0], p[1:]) for p in g["coordinates"]]
            for poly in geoms:
                if not poly.is_valid:
                    poly = poly.buffer(0)
                if poly.is_empty or not poly.intersects(BOX):
                    continue
                paths.extend(_geom_paths(poly.intersection(BOX).simplify(TOLERANCE, preserve_topology=True)))
    _LAND_CACHE[key] = paths
    return paths


def _border_paths():
    key = BBOX
    if key in _BORDER_CACHE:
        return _BORDER_CACHE[key]
    borders = _load("ne_50m_admin_0_boundary_lines_land")
    paths = []
    if borders:
        for feat in borders["features"]:
            g = feat.get("geometry") or {}
            t = g.get("type")
            lines = [g["coordinates"]] if t == "LineString" else (g["coordinates"] if t == "MultiLineString" else [])
            for line in lines:
                ls = LineString(line)
                if not ls.intersects(BOX):
                    continue
                piece = ls.intersection(BOX).simplify(TOLERANCE)
                parts = [piece] if piece.geom_type == "LineString" else list(getattr(piece, "geoms", []))
                for part in parts:
                    if len(part.coords) < 2:
                        continue
                    coords = [pt(c[0], c[1]) for c in part.coords]
                    paths.append("M" + "L".join(f"{x:.1f},{y:.1f}" for x, y in coords))
    _BORDER_CACHE[key] = paths
    return paths
```

```python
class Raw(str):
    """خلية HTML جاهزة: تُدرج كما هي ولا يعاد معالجتها في _table (وإلا ظهرت الوسوم نصًّا)."""


def _table(headers, rows, inline, num_cols=()):
    if not rows:
        return ""
    head = "".join(
        f'<th scope="col"{" class=\"num\"" if i in num_cols else ""}>{esc(h)}</th>'
        for i, h in enumerate(headers)
    )
    body = []
    for r in rows:
        tds = []
        for i, c in enumerate(r):
            s = c if isinstance(c, str) else ""
            # خلية جاهزة بـHTML (مثل <bdi> أو شارة حالة) لا تُعاد معالجتها، وإلا ظهرت الوسوم نصًّا للقارئ
            # خلية تحتوي وسومًا HTML جاهزة لا تُعاد معالجتها، وإلا ظهرت الوسوم نصًّا للقارئ
            ready = isinstance(c, Raw) or ("<" in s and ">" in s)
            cell = s if i in num_cols else (s if ready else inline(s))
            cls = ' class="num"' if i in num_cols else ""
            tds.append(f"<td{cls}>{cell}</td>")
        body.append(f"<tr>{''.join(tds)}</tr>")
    return (
        '<div class="tbl-wrap"><table><thead><tr>' + head + "</tr></thead><tbody>"
        + "".join(body) + "</tbody></table></div>"
```

```python
def _drop_stray_braces(css: str):
    """يحذف الأقواس المغلقة التي لا يقابلها فتح، فلا تُسقط ما بعدها."""
    out, depth, i, removed = [], 0, 0, 0
    in_str, in_com = None, False
    while i < len(css):
        c, nxt = css[i], css[i:i + 2]
        if in_com:
            out.append(c)
            if nxt == "*/":
                out.append("/")
                i += 2
                in_com = False
                continue
        elif in_str:
            out.append(c)
            if c == "\\":
                out.append(css[i + 1:i + 2])
                i += 2
                continue
            if c == in_str:
                in_str = None
        elif nxt == "/*":
            out.append(nxt)
            i += 2
            in_com = True
            continue
        elif c in "\"'":
            in_str = c
            out.append(c)
        elif c == "{":
            depth += 1
            out.append(c)
        elif c == "}":
            if depth == 0:
                removed += 1
            else:
                depth -= 1
                out.append(c)
        else:
            out.append(c)
        i += 1
    return "".join(out), removed


def _merge_ltr(part: str) -> str:
    """يدمج وسوم الاتجاه المقطّعة في وسم واحد يلفّ الرمز كاملًا."""
    prev = None
    while prev != part:
        prev = part
        part = re.sub(r'</span>([/\-.:])<span class="ltr">', r"\1", part)
        part = re.sub(r'<span class="ltr">([^<]*)</span>((?:[/\-.:]' + LATIN_PIECE + r')+)',
                      r'<span class="ltr">\1\2</span>', part)
        part = re.sub(r'((?<![A-Za-z0-9])(?:' + LATIN_PIECE + r'[/\-.:])+)<span class="ltr">([^<]*)</span>',
                      r'<span class="ltr">\1\2</span>', part)
    return part


def _tables(part: str) -> str:
    """يضيف معلم وصول ومفاتيح لكل حاوية جدول قابلة للتمرير.

    الحاوية نفسها هي منطقة التمرير، فيجب أن تقبل التركيز بلوحة المفاتيح.
    والتلميح يُضاف للجداول العريضة فقط (أكثر من 5 أعمدة).
    """
    def one(m):
        holder = m.group(0)
        tbl = re.search(r"<table.*?</table>", holder, re.S).group(0)
        wide = len(re.findall(r"<th\b", tbl)) > 5
        label = "جدول يحتاج تمريرًا أفقيًا" if wide else "جدول"
        if 'tabindex=' not in holder.split(">", 1)[0]:
            holder = re.sub(r'<div class="(tbl-wrap|tbl-scroll)"',
                            lambda x: f'<div class="{x.group(1)}" tabindex="0" role="region" aria-label="{label}"',
                            holder, count=1)
        if wide and 'class="tbl-hint"' not in holder:
            holder = ('<span class="tbl-hint">اسحب الجدول أفقيًا لرؤية بقية الأعمدة</span>'
                      + holder)
        return holder
    return re.sub(r'<div class="(?:tbl-wrap|tbl-scroll)"[^>]*>\s*<table.*?</table>', one, part, flags=re.S)

    def one(m):
        tbl = m.group(0)
        heads = [html_mod.unescape(re.sub(r"<[^>]+>", "", h)).strip()
                 for h in re.findall(r"<th\b[^>]*>(.*?)</th>", tbl, re.S)]
        if not heads:
            return tbl

        def row(mr):
            idx = [0]

            def cell(mc):
                i = idx[0]
                idx[0] += 1
                lab = heads[i] if i < len(heads) else ""
                if not lab or "data-label" in mc.group(0):
                    return mc.group(0)
                return mc.group(1) + f' data-label="{lab}"' + mc.group(2)
            return re.sub(r"(<td\b[^>]*)(>)", cell, mr.group(0))

        tbl = re.sub(r"<tr\b[^>]*>.*?</tr>", row, tbl, flags=re.S)
        head_tag = tbl.split(">", 1)[0]
        if 'class="' in head_tag:
            tbl = re.sub(r'^(<table\b[^>]*?)class="([^"]*)"', r'\1class="\2 cardified"', tbl, count=1)
        else:
            tbl = re.sub(r"^<table\b", '<table class="cardified"', tbl, count=1)
        return tbl

    return re.sub(r"<table\b[^>]*>.*?</table>", one, part, flags=re.S)


def _stars(part: str) -> str:
    part = re.sub(r"\*\*([^*<>]{1,120}?)\*\*", r"<strong>\1</strong>", part)
    part = re.sub(r"<strong>\*\*([؛.\s]*)</strong>", r"\1", part)
    return part.replace("**", "")


def _trust(part: str) -> str:
    for en, ar in TRUST_AR.items():
        part = part.replace(f"<td>{en}</td>", f"<td>{ar}</td>")
    return part


def _empty_tags(part: str) -> str:
    part = re.sub(r'\s*<span class="sp-tag sp-code"></span>', "", part)
    part = re.sub(r'\s*<div class="sp-meta">\s*<span></span>\s*</div>', "", part)
    return re.sub(r'<span class="tag[^"]*"></span>', "", part)


def sanitize(html: str) -> str:
    """يطبّق كل إصلاحات المخرجات على صفحة واحدة."""
    removed = 0

    def css_fix(css: str) -> str:
        nonlocal removed
        css, n = _drop_stray_braces(css)
        removed += n
        return css

    html = STYLE.sub(lambda m: m.group(1) + css_fix(m.group(2)) + m.group(3), html)

    def body_fix(part: str) -> str:
        part = _merge_ltr(part)
        part = _stars(part)
        part = _trust(part)
        part = _tables(part)
        part = _cardify(part)
        return _empty_tags(part)

    html = _outside_code(html, body_fix)

    # قاعدة الاتجاه + ألوان الشارات النهارية تُضاف مرة واحدة قبل نهاية آخر كتلة أنماط
    def inject_rules(css: str) -> str:
        add = ""
        if not re.search(r"\.ltr\s*\{", css):
            add += LTR_RULE
        if ".st-badge.s-stable" not in css and "daylight" in css:
            add += DAYLIGHT_BADGES
        if ".lg-num" not in css:
            add += LEGEND_NUM
        if "table.cardified" not in css:
            add += EXTRA_CSS
        return css + add

    blocks = list(STYLE.finditer(html))
    if blocks:
        last = blocks[-1]
        html = html[:last.start(2)] + inject_rules(last.group(2)) + html[last.end(2):]

    if removed:
        html = html.replace("<!-- postprocess:stray-braces -->", "", 1)
    return html


def run(dist_root) -> dict:
    """يطبّق الإصلاح على كل صفحات مجلد النشر. يعيد إحصاءً مختصرًا."""
    from pathlib import Path

    dist = Path(dist_root)
    stats = {"pages": 0, "changed": 0}
    for p in sorted(dist.rglob("*.html")):
        t = p.read_text(encoding="utf-8")
        n = sanitize(t)
        stats["pages"] += 1
        if n != t:
            p.write_text(n, encoding="utf-8")
            stats["changed"] += 1
    return stats
```

## 16) أسئلة محدّدة أطلب جوابك فيها

4. خوارزمية منع تصادم التسميات والشارات على الخريطة: أي طريقة تختار؟
5. أفضل مسار لخط عربي عالي الجودة في PDF مطبوع دون Type 3؟
6. كيف نقيس «العناصر المتداخلة» برمجيًا قبل التصدير (حاجز يمنع الأعطال البصرية)؟
7. هل الأنسب نقل الطباعة إلى محرّك مخصّص للطباعة (Typst/LaTeX/InDesign) مع إبقاء الشاشة HTML؟ ما كلفة ذلك؟
