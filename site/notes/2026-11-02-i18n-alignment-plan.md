# خطة إصلاح مواءمة المتن الإنجليزي — 2026-11-02

## المطلوب
إعادة مواءمة `sources/i18n/en/2026-11-02-sectioned.en.md` مع المتن العربي الحاكم سطرًا بسطر، بحيث يتساوى عدد الأسطر غير الفارغة ويطابق كل سطر مقابله نوعه البنيوي، مع حفظ المعنى والمعرّفات والأرقام.

## الملفات المتأثرة
- `sources/i18n/en/2026-11-02-sectioned.en.md`: ترجمة إنجليزية فقط؛ لا تعديل للمتن العربي.
- `generator/i18n_en.py`: إضافة تحقق فشل مغلق لنوع السطر بعد تحقق العدد.
- `tests/test_i18n_alignment.py`: اختبار موجب، اختبار حذف سطر في نسخة مؤقتة، واختبار اختلاف نوع مع تساوي العدد.
- `audit/سجل-الأعطال-والثغرات.md`: صف عطل 12 عمودًا بعد آخر رقم موجود.
- `memory/learning-log.jsonl`: درس مطابق مع حاجز الاختبار.
- `logs/` أو `/tmp/`: أدلة أوامر التحقق إن لزم.

## معايير القبول
1. `build_tm('2026-11-02')` ينجح ويطبع مفتاحًا نموذجيًا.
2. القياس المستقل: 150/150 سطرًا غير فارغ، و0 اختلافات نوع، و0 اختلافات عدد أعمدة جدول.
3. `python3 generator/en_missing_report.py --date 2026-11-02` يخرج صفرًا ورمز 0.
4. `python3 generator/build_report_en.py --date 2026-11-02` يخرج رمز 0.
5. لا توجد كتلة عربية مرئية في `dist/reports/en/2026-11-02.html` بعد استثناء script/style/hidden/aria-hidden.
6. الاختبار الدائم يمر بالموجب ويفشل مغلقًا في نسخ مؤقتة عند حذف سطر أو تغيير نوعه.
7. `closure_round.py --apply` ثم `validators/check_closure.py` يخرجان أعداد مفحوص/مغلق/مستثنى/فاشلًا فعليًا، دون تشغيل runbook أو نشر أو طباعة/PDF/Word.

## الأثر والرجوع
الرجوع يقتصر على الملفات المذكورة أعلاه عبر النسخ الاحتياطية التي تنشئها أدوات الإغلاق أو نسخ `/tmp`؛ لا Git ولا تعديل `runbook/runbook.json` ولا تشغيل `runbook.py run`.
