# مركز الوعي البحري — الموقع الدائم

موقع دائم لتقارير أمن الملاحة: إصدار يومي، ولوحة شهرية، وسجل تراكمي.

## التشغيل

```bash
python3 generator/build_site.py --check          # بناء dist/ كاملًا والتحقق
python3 generator/sync_from_brain.py --date 2026-10-12   # تحديث يومي من مساحة Brain
```

النشر: يُلتزم مجلد `dist/` في المستودع ثم يُنشر الموقع. لا يحتاج البناء إلى بيئة Python.

## البنية

- `generator/` أدوات البناء، وتضم نسخة المولّد المعتمد من مساحة Brain.
- `sources/` مصادر التقارير ودفتر الأحداث.
- `dist/` مخرجات النشر الجاهزة.

## القواعد الملزمة

تصنيف الإصدار عام. الإصدار المقيّد أو الحساس لا يُنشر على هذا الموقع.
كل إصدار يحفظ رموزه المرجعية الثابتة، ويفصل الحقيقة عن التقدير.
