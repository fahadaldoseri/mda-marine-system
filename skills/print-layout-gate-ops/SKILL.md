# تشغيل بوابات الطباعة وإصلاح انحراف التخطيط

## متى تُستدعى

- فشل `check_pdf_format` أو `check_print_quality` (تعبئة، فراغ، خريطة، ترقيم، بصمة مقفلة).
- شكوى من فراغ كبير في صفحة مطبوعة أو صفحة أخيرة شبه فارغة أو مفتاح خريطة منقسم.
- الحاجة إلى تغيير بصري في الطباعة يستلزم إعادة تجميد البصمة المقفلة.
- الحاجة إلى نشر PDF والتأكد أن النسخة الحيّة مطابقة للمحلية.

## القاعدة الحاكمة

لا تصلح شيئًا قبل قياسه، ولا تعلن نجاحًا قبل إعادة القياس على المخرج نفسه.
كل تغيير بصري = قياس قبل + تغيير واحد + قياس بعد + معاينة بصرية للصفحة المعنية.

## المسار الإلزامي

1. **قياس الحالة**: `scripts/measure_pdf_pages.py --pdf <pdf>` لمعرفة التعبئة والفراغات لكل صفحة.
2. **تشغيل البوابتين** كما هي معرَّفة في المشروع (لا تخفّض عتبة أبدًا):
   `check_pdf_format.py --pdf <pdf>` و`check_print_quality.py --pdf <pdf>`.
3. **تصنيف الفشل** حسب جدول التشخيص في `references/playbook.md`.
4. **قياس الكتلة المشتبهة** قبل التعديل: `scripts/measure_block.py --html <page.html> --selector ".print-map"` (يقيس الارتفاع الفعلي في وضع الطباعة).
5. **إصلاح واحد** في كل جولة (قاعدة CSS واحدة أو موضع واحد)، ثم إعادة البناء والتصدير.
6. **إعادة القياس** حتى تمرّ البوابتان، مع معاينة بصرية للصفحة المتأثرة.
7. **إعادة تجميد البصمة**: `scripts/refreeze_print_css.py` مع سبب ودليل قابل لإعادة التشغيل.
8. **التماثل والنشر**: مزامنة الشجرة، ثم فحص التماثل، ثم نشر النسخة المعتمدة، ثم إثبات أن بصمة الملف الحيّ = بصمة الملف المحلي.

## جدول التشخيص السريع

| العَرَض | السبب الجذري الشائع | الإصلاح |
|---|---|---|
| صفحة أخيرة بتعبئة < 15% | فقرة أو مقطع تجاوز حدّ الصفحة بقليل | ضغط تباعد المقطع أو إعادة ترتيب الكتل |
| فراغ داخلي ≥ 45 مم | كتلة لا تنقسم أكبر من المساحة المتبقية | تصغير الكتلة أو نقلها إلى موضع يمتلئ ما قبله |
| مفتاح خريطة منقسم بين صفحتين | قاعدة `break-inside` على العنصر الخطأ | اجعل الحاوية تنقسم والمفتاح لا ينقسم |
| قاعدة لا تُنفّذ رغم وجودها | قاعدتان لمحدِّد واحد، اللاحقة تلغي الأولى | وحّد القاعدة واحذف المنافسة |
| عرض الخريطة أقل من الحد | تقييد الارتفاع على عنصر SVG يحفظ النسبة | ألغِ تقييد الارتفاع واضبط العرض |
| «نمط الطباعة تغيّر عن المعتمد» | تغيير مشروع في CSS الطباعة | أعِد التجميد بتوثيق السبب والدليل |

التفاصيل والتفاسير في `references/playbook.md`.

## الأدوات

- `scripts/measure_pdf_pages.py --pdf <pdf> [--json]` — كتل الحبر لكل صفحة، التعبئة، الفراغات ≥ 45 مم.
- `scripts/measure_block.py --html <file.html> --selector <css> [--viewport 900]` — ارتفاع الكتلة بالمليمترات في وضع الطباعة.
- `scripts/refreeze_print_css.py --brain <dir> [--validator <path>] --reason "..." --evidence "..." [--dry-run]` — تجميد نمط الطباعة وتحديث البروفايل المعتمد بسجل تغيير موثق.

## التشديد الذاتي بعد كل جولة

سجّل كل عطل جديد في سجل الأعطال بسببه الجذري وحاجزه ودليله، وأضف درسًا مطابقًا، ثم شغّل حارس الإغلاق. إن تكرر عطل من الصنف نفسه، شدّد الحاجز (بوابة أو اختبار) قبل إغلاق الجولة — ولا تُغلق عطلًا بلا دليل تشغيل.

## الحدود

- لا تخفّض عتبة بوابة ولا تعتمد بصمة بلا سبب مكتوب ودليل قياس.
- لا تعدّل هيئة الغلاف أو الألوان أو الخطوط ضمن إصلاح التخطيط.
- إن كان القرار المطلوب يمسّ محتوى أو تصميمًا معتمدًا، اعرض الخيارات على المالك قبل التنفيذ.
