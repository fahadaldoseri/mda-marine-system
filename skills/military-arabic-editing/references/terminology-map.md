# خريطة الاستبدالات

| الصياغة الصعبة | الصياغة العسكرية الأوضح |
|---|---|
| هجمات جديدة | وقائع أمنية جديدة، أو هجمات مؤكدة إذا ثبتت |
| إشعارات استشارية | تنبيهات إرشادية |
| ضربات بأجسام مجهولة | إصابات بمقذوفات من جهة غير معلومة |
| يقظة تشغيلية فورية | رفع مستوى المراقبة فورًا |
| الصورة الجغرافية | التوزيع الجغرافي |
| الاختناق المرصود | التكدس الملاحي المرصود |
| مؤشر طمأنة تشغيلي جزئي | عامل مطمئن على المستوى التشغيلي، لكنه محدود |
| يُحسب لفرق الإنقاذ | يعكس سرعة استجابة فرق الإنقاذ |
| الجهة الفاعلة | الطرف المسؤول أو الجهة المنفذة |
| مرشحة تحليليًا | مرشح تحليلي أو احتمال قائم |
| محتفظ بها دائمًا | تظل قائمة كاحتمال |
| المراجعة المعارضة الذاتية | اختبار الفرضية المضادة |
| المحور البحري المباشر | النطاق البحري المباشر |
| ما يعنينا | الأثر على العمل |

صحح أيضًا: «حالتهم مستقرة»، «الجانب الأيسر، أي جانب الميناء»، «الناقلات المغادرة للمضيق»، «بحارة من جنسيات آسيوية»، و«اندلع حريق».
