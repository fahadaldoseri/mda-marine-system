# فرز مرشحات التدقيق

مخرجات أي أداة فحص بنيوي **ليست عيوبًا**، بل **مرشحات تحتاج حكمًا**. الغرض: تحويل قائمة طويلة إلى قرارات مُسنَدة بالدليل.

## قاعدة الانضباط

> **لا تُصنّف بقراءة اسم الملف. افتح الشيفرة، واقرأ السياق، وقِس.**

الاسم يُشبه العطل، والسياق يحدّد الحقيقة. أغلب «الأعطال» في القوائم البنيوية تنكشف عند فتح السياق.

## الحُكم بأربع حالات — لا أكثر

| الحكم | متى | الإثبات المطلوب |
|---|---|---|
| **عطل مؤكد** | الشيفرة تنتج أثرًا خاطئًا فعليًا | قياس حي يُظهر الأثر (مخرج أمر أو ملف أو سلوك) |
| **إنذار كاذب للأداة** | الشيفرة سليمة والأداة أساءت التقدير | شرح لماذا هو سليم (سياق محكوم بشرط/ثابت) + تعديل الكاشف ليمنع التكرار |
| **سلوك مقصود موثَّق** | مكتوب بقرار أو عقد أنه مقصود | مرجع القرار أو العقد بالاسم |
| **غير قابل للحكم آليًا** | يحتاج قياسًا حيًا أو متصفحًا أو حكمًا بشريًا | تسجيله كبند مفتوح بسببه، لا تحويله إلى «سليم» صامتًا |

**ممنوع:** حكم خامس مثل «يُتجاهل» أو «مقبول مؤقتًا» بلا سند. القائمة إما تُغلق بدليل أو تُسجَّل مفتوحة بسبب.

## مسار العمل

1. **اجمع المرشحات بمصدرها**: كل بند يُربط بأداة الفحص ورقم السطر — لا بند بلا مصدر.
2. **افرزها بالمجموعات** لا فردًا فردًا: البنود التي تشترك في السبب تُحكم مرة واحدة (مثل «40 حلقة بلا سقف» قد تكون خمسة أنماط لا أربعين عطلًا).
3. **افتح السياق وقِس** لكل مجموعة: اقرأ الدالة كاملة، واختبر الشرط المحيط.
4. **أصلح المؤكد** بالجذر + اختبارين (أحمر قبل · أخضر بعد) + سالب.
5. **ضيّق الكاشف عند الإنذار الكاذب**: عدّل شرط المطابقة ليمنع التكرار، **ولا تحذف البند من التقرير ولا تُعطّل الفحص**.
6. **سجّل النتيجة رقمية**: كم عطلًا مؤكدًا · كم إنذارًا كاذبًا · كم بندًا مفتوحًا بسببه.
7. **أعد تشغيل الأداة** بعد الإصلاح: العدد يجب أن ينقص **للسبب الصحيح** (إصلاح أو تضييق مبرَّر)، لا بتخفيف العتبة.
8. **سجّل الدروس**: كل عطل مؤكد ← درس + حاجز يمنع رجوعه.

## قواعد الحكم عند الشك

- **إن كان الشرط ثابتًا في السياق** (نطاق محدود، مدخل محكوم، حلقة على قائمة ثابتة) فالغالب إنذار كاذب — أثبت الثبات بقراءة الشرط لا بالافتراض.
- **إن كان المدخل من مصدر خارجي أو متغير** فالغالب عطل مؤكد — اختبره بمدخل شاذ.
- **إن تعلّق الحكم بسلوك متصفح أو جلسة** فليس قابلًا للحكم آليًا؛ قِسه بسياق مستخدم حقيقي أو سجّله مفتوحًا.
