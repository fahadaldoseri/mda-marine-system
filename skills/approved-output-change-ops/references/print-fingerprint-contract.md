# عقد بصمة المخرج وقرار التغيير

## الملكية والنطاق

هذا هو العقد الوحيد المشترك لأي تغيير يمس مخرجًا مقفلًا أو معتمدًا. تملك `approved-output-change-ops` دورة القياس والقرار والبصمة؛ وتبقى `print-freeze-verify-ops` مالكةً لبوابة PDF النهائية `B030`، وتبقى `print-layout-gate-ops` مالكةً لتشخيص تدفق الصفحات والكتل والفراغات. لا تعيد المهارتان المتخصصتان تعريف هذه الدورة.

## دورة الإثبات الواحدة

نفّذ دورة واحدة مرتبة، واحفظ مخرج كل خطوة:

1. **قبل:** حدّد المخرج المقفل وملفات القفل (`print-css-frozen.css` و`print-profile.json` عند وجودهما) وPDF الفعلي؛ احسب بصمة `sha256` أو `sha16` وسجّل عدد الصفحات، التعبئة، الفجوات، قياس الخريطة، تصفير المتن، وحالة السطوح.
2. **التغيير المحدود:** طبّق إصلاحًا واحدًا للسبب، ولا تغيّر حدًا أو نطاقًا أو سياسةً لتعويض عطل.
3. **بعد:** قِس PDF النهائي نفسه بالحقول نفسها، وأعد تشغيل البوابات الخاصة بالمخرج، واحتفظ بالمخرج الحرفي ورمز الخروج.
4. **المقارنة:** قارن بصمة CSS المقفل و`profile` وPDF، وسجّل `from` و`to` وأي اختلاف في الصفحات أو السطوح.
5. **القرار:** إن تغيّرت البصمة أو حدّ أو نطاق أو سياسة، أوقف التسليم واطلب قرار المالك؛ لا تستخدم `--allow-css-change` لإخفاء الاختلاف. إن لم يتغير القفل ومرت البوابات، يمكن توثيق الجولة دون اعتماد بصمة جديدة.
6. **الاعتماد والسجل:** بعد القرار الصريح فقط شغّل أداة الاعتماد المناسبة، واحفظ `reason` و`approved_by` و`evidence` و`date`، واحفظ النسخة السابقة باسم `SUPERSEDED-<old_sha>.css` عند تغير CSS.

هذه هي صيغة «قياس قبل → تغيير واحد → قياس بعد → بوابات → مقارنة بصمة → قرار مالك»؛ لا تُنسخ كدورة ثانية في مهارة التجميد أو مهارة التخطيط.

## عقد القرار

| الحالة | الإجراء المسموح | المانع |
|---|---|---|
| اختلاف بصمة أو حد أو نطاق أو سياسة | جمع الدليل وطلب قرار مالك موثق | لا تسليم ولا تجميد جديد |
| بوابة PDF أو الجودة تفشل | إحالة السبب إلى مالك التشخيص، ثم إعادة القياس | لا تخفيف للعتبة |
| البوابات تمر والقفل ثابت | توثيق الدليل دون اعتماد بصمة جديدة | لا تعديل للـprofile |
| قرار مالك موثق مع دليل حي | اعتماد البصمة وتسجيل `from/to/reason/approved_by/evidence/date` | لا اعتماد من نص قديم أو رمز خروج وحده |

## الحد الأدنى لحزمة الدليل

احفظ الأمر الكامل، المخرج الحرفي، `return_code`، بصمات CSS و`profile` وPDF، قياسات قبل/بعد، قرار المالك إن لزم، ومسار ملف الدليل. لا تعدّ هذه الجولة إعادة تجميد؛ لا تُشغّل `freeze_adopt.py` أو `refreeze_print_css.py` ما لم يطلب المالك ذلك صراحةً.
