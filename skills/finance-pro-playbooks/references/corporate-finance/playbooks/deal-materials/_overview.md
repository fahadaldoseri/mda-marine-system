# Deal Materials & Decision Support

Playbooks for sell-side marketing, capital markets, investment committee, and daily deal support documents. Load `formats/document_standards.md` when producing docx/pptx; `formats/excel_standards.md` for Excel buyer lists.

## Contents

| Task | File | Use when |
|---|---|---|
| Deal Teaser | [`deal-teaser.md`](deal-teaser.md) | Drafting a sell-side investment teaser (blind or named) |
| CIM Executive Summary | [`cim-executive-summary.md`](cim-executive-summary.md) | Building the opening executive summary / investment highlights section of a sell-side CIM or CIP |
| Buyer List Development | [`buyer-list-development.md`](buyer-list-development.md) | Building a sell-side / sponsor-exit buyer universe for a target |
| Cross-Holder Analysis | [`cross-holder-analysis.md`](cross-holder-analysis.md) | Identifying actionable institutional investors for an equity offering (follow-on or IPO) by mapping cross-ownership across a peer set |
| Initiating Coverage Report | [`initiating-coverage-report.md`](initiating-coverage-report.md) | Drafting a sell-side initiation-of-coverage report on a new ticker |
| Business Quality Scorecard | [`business-quality-scorecard.md`](business-quality-scorecard.md) | A PE deal requires a one-page due diligence diagnostic for IC presentation |
| Project Overview | [`project-overview.md`](project-overview.md) | A project is opened and a deal-team-facing overview must be auto-generated from uploaded project materials |
| ECM Company Profile | [`ecm-company-profile.md`](ecm-company-profile.md) | Producing a pre-meeting ECM company profile for capital markets teams |
| Research Materials Pack | [`research-materials-pack.md`](research-materials-pack.md) | Turning research conclusions into roadshow / distribution materials |
| Deal Screening Scorecard | [`deal-screening-scorecard.md`](deal-screening-scorecard.md) | Screening and scoring user-provided equity/credit/M&A/LP opportunity documents with red-flag output (audience-adaptive) |
