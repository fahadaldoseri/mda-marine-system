# Vocabulary Guard Ops — تشغيل وإغلاق حارس المفردات

## الفكرة الجوهرية

مصدر حقيقة **واحد** للحُكم اللغوي (سجل حاكم)، وكل ما عداه **مُولَّد** منه:

```
appendices/simplified-vocabulary.json   ← السجل الحاكم: {term, plain[], status, since, reason, source}
appendices/forbidden-coinages.json      ← مُولَّد آليًا من حالات approved فقط (لا يُحرَّر يدويًا)
validators/check_vocabulary.py          ← البوابة التي تنفّذ المُولَّد على الأسطح
tools/build_vocab_gate.py               ← بناء المُولَّد + فحص التطابق + كشف التعديل اليدوي
tools/audit_style_coverage.py           ← قياس تغطية كل سطح يُقرأه القارئ
tests/test_vocab_registry.py            ← إغلاق الحارس: فحوص لا تجتاز إلا بشرط
```

## المسار الإلزامي (لا تتجاوزه)

1. **حصر الألفاظ** الجديدة (من ملاحظات المالك أو مسح الأسطح)، ولكل بند سبب ومصدر مكتوبان.
2. **إدراج الاعتماد في السجل الحاكم فقط** — لا تُعدّل ملف القائمة المُولَّدة، ولا تستبدل نصًّا داخل ملفّي الحُكم.
3. **إعادة البناء والفحص:** `python3 tools/build_vocab_gate.py --apply` ثم التحقق من التطابق.
4. **الاستبدال على الأسطح** بمرشّح **يستثني ملفّي الحُكم**، ونطاقه: المتن · ملف الواجهة · أقسام النظام · قوالب الكتيب · مولّد الموقع · بنّاءات `tools/` و`validators/`.
5. **إعادة بناء الأسطح المشتقة** (الموقع ثم PDF ثم ملخص المراسلة) قبل أي فحص عليها — لا تُحكم على ملف قديم.
6. **قياس التغطية:** الأسطح غير المغطاة = 0، والمانعة = 0.
7. **إغلاق الحارس:** اختبار السجل والبوابة = 0 فشل، ويُعاد تشغيله من **نسخة المستودع** لا من الخادم فقط.
8. **التسجيل ثم الدفع:** عطل جديد (سبب جذري + إصلاح) في سجل الأعطال، ودرس مطابق في سجل التعلم، ثم فرع + طلب دمج — لا دفع مباشر إلى main.

## خطوط حمراء (كل واحدة أفلتت مرة وأوقفت التسليم)

| الخطأ | الأثر | القاعدة |
|---|---|---|
| الكتابة على ملفّي الحُكم | البديل يصبح لفظًا مانعًا ⇒ التقرير يمنع نفسه | مرشّح الاستبدال يستثني `simplified-vocabulary.json` و`forbidden-coinages.json` |
| بند بلا `plain` أو ببديل يساوي اللفظ | السجل غير صالح فلا يُبنى شيء | كل بند يحتاج `plain` غير فارغة، و`term != plain` |
| بديل يساوي لفظًا مانعًا آخر | تناقض داخلي | فحص تقاطعي: `term` لا يساوي أي `plain` في السجل |
| بنّاءات `tools/` خارج نطاق المرشّح | ألفاظ قديمة تظهر في مخرجات مشتقة | النطاق يشمل البنّاءات لا المحتوى فقط |
| الحكم على نثر مستخرج من HTML/PDF | مسافات وحروف زائدة يخلقها الاستخراج تُحسب مخالفة | تطبيع NFKC + إزالة الكشيدة وعلامات الاتجاه وتصحيح مواضع الترقيم قبل البوابة |
| الحكم على PDF بالاستخراج العربي | عكس الحروف ⇒ نتائج كاذبة | يُثبت إسناد PDF برموز البلاغ `MN-…` والمصطلحات اللاتينية، لا بتشابه النص |
| الحكم على سطح مشتق من نسخة قديمة | مانع كاذب في ملخص اليوم | يُبنى السطح المشتق من مصدره لحظة الفحص |

التفصيل والأمثلة: [references/root-causes.md](references/root-causes.md)

## الأسطح الواجب قياسها

متن الإصدار · ملف الواجهة (JSON) · السطح المشتق (ملخص المراسلة) · صفحة الإصدار · صفحة المصادر · الصفحة الرئيسية · PDF (بالإسناد).
قائمة الأسطح وطريقة تنفيذ كل نوع: [references/surface-inventory.md](references/surface-inventory.md)

## حلقة التعلم الذاتي (إلزامية)

بعد كل فشل أو ملاحظة مالك:

```bash
python3 scripts/learn_from_failure.py --log <مسار learning-log.jsonl> \
  --surface "<السطح>" --symptom "<ما ظهر>" --cause "<السبب الجذري>" \
  --action "<التشديد الذي مُنع به التكرار>" --evidence "<الأمر ومخرجه>"
```

الأداة تُلحق المدخل وتطبع **تشديدًا مقترحًا** بحسب تصنيف السبب. لا يُغلق عطل قبل أن يقابله منع آلي أو قاعدة مكتوبة.

## أدوات المهارة

- `scripts/check_registry.py` — صحة السجل والمُولَّد: بنود ناقصة · بديل يساوي لفظه · تقاطع بين أسماء المنع وبدائلها · عدم تطابق المُولَّد · تكرار بحالتين.
- `scripts/check_surfaces.py` — مسح الأسطح بألفاظ المنع، بتطبيع النص المشتق وبإسناد PDF، ويُخرج جدولًا ويرجع برمز فشل عند أي سطح مانع.
- `scripts/status_report.py` — تقرير حالة شامل: عدد البنود وتوزيع الحالات والبصمة لكل سجل (Markdown + Excel).
- `scripts/learn_from_failure.py` — تسجيل الدرس واقتراح تشديد.

## أمثلة تشغيل سريعة

```bash
python3 scripts/check_registry.py --registry brain/appendices/simplified-vocabulary.json \
                                  --generated brain/appendices/forbidden-coinages.json
python3 scripts/check_surfaces.py --registry brain/appendices/simplified-vocabulary.json \
                                  --surfaces surfaces.json --json
python3 scripts/status_report.py --scan brain/appendices brain/memory \
                                 --out تقرير-حالة-السجلات.md --xlsx تقرير-حالة-السجلات.xlsx
```

## معيار الإغلاق

لا يُقال «أُغلق» إلا بثلاثة مخرجات معًا من **نسخة المستودع**: `check_registry` بلا خلل، `check_surfaces` بصفر سطح مانع، واختبار المشروع (مثال: `tests/test_vocab_registry.py`) بصفر فشل، مع بصمة الملفات في تقرير الحالة.


## حدود المهارة
هذه المهارة لا تحكم صدق الواقعة أو مصدرها؛ المهارة الجارة `marine-news-brain` تفعل ذلك.
