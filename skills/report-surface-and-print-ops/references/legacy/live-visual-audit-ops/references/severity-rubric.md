# معيار شدة الملاحظات

استخدم أعلى شدة تنطبق، واربطها بدليل قابل لإعادة القياس.

## مانع

أوقف التسليم أو الإصدار. استخدمه عندما يفسد البند القراءة أو المعنى أو الوصول إلى سطح أساسي، مثل صفحة مفقودة، عنوان فهرس يشير إلى صفحة خاطئة، قصّ يخفي معلومة، أو انعكاس رقمي يغيّر نطاقًا أو نسبة. لا يُغلق المانع بالادعاء؛ يجب إعادة القياس بعد الإصلاح، مع لقطة عند الحاجة.

## مهم

أصلحه قبل التسليم العادي، لكنه لا يمنع المعاينة الطارئة إذا وُسم بوضوح. أمثلته هدف لمس أصغر من 44px في مسار أساسي، overflow داخلي يحجب جزءًا من جدول، خلية/بطاقة فارغة تغيّر فهم البنية، أو رابط/سطح رئيسي لا يعمل. أثبت الإغلاق بقياس جديد ولقطة.

## تحذير

لا يمنع التسليم وحده، لكنه يستحق قرارًا موثقًا ومراجعة في الإصدار التالي. استخدمه لملاحظة محدودة الأثر أو دليل ناقص يحتاج تحققًا مركّزًا. إذا لم يستطع التدقيق إعادة إنتاجه، فصنّفه `مرفوض` بدل إبقائه تحذيرًا مؤكدًا.

## تجميلي

تحسين بصري أو اتساقي لا يغيّر المعنى أو الوصول أو الاستخدام. لا تسمّه تجميليًا إذا كان الفراغ أو المحاذاة يخفي محتوى أو يربك ترتيبًا RTL؛ عندها ارفع الشدة إلى مانع أو مهم.

## متى يُعدّ البند «لم يتحقق»؟

اكتب `لم يتحقق` ولا تُصدر حكمًا نهائيًا في أي من الحالات التالية:

1. غابت اللقطة أو القياس الرقمي أو الأمر القابل لإعادة التشغيل.
2. اعتمدت الملاحظة على قول وكيل ولم تُعد القياس.
3. اختلف عدد عناصر المصدر عن طبقة PDF أو تعذر محاذاتها.
4. كان الحكم عن الاتجاه أو الترتيب أو القص البصري بينما لم تُعاين صورة الصفحة.
5. فشل تحميل السطح أو تعذر الوصول إلى الملف، حتى لو بدا التخطيط سليمًا من مصدر آخر.

سجّل سبب عدم التحقق وخطوة الإكمال المطلوبة. لا تحوّل `لم يتحقق` إلى `سليم`.
