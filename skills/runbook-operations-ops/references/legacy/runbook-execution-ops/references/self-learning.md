# حلقة التعلم الذاتي لهذه المهارة

هذه الحلقة تخص تحسين تشغيل الكتيب، وليست سجل أعطال بديلًا. عند وجود عطل أو ملاحظة تشغيلية، أحِل تسجيل العطل وإغلاقه إلى `fault-closure-ops`، وأحِل دورة الإغلاق الكاملة إلى `self-learning-loop-ops`.

## الدورة بعد كل تشغيل

1. **سجّل الدرس:** اكتب صفًا واحدًا في `memory/learning-log.jsonl` عبر `scripts/record_lesson.py`. يجب أن يحتوي الصف على `ts`, `entry_kind`, `cls`, `status`, `symptom`, `cause`, `fix`, `barrier`.
2. **اقترح حاجزًا:** اجعل قيمة `barrier` أمرًا أو شرطًا قابلًا للتحقق، لا وعدًا وصفيًا. السكربت يطبع كائنًا بصيغة قابلة للإدراج يحوي `barrier_id` وشرط المنع.
3. **تحقّق من قيام الحاجز:** لا تعتبر الدرس مغلقًا لمجرد كتابته. شغّل الاختبار أو البوابة التي يحددها الحاجز، وسجّل رمز الخروج ونتيجته في نظام المشروع المناسب. إذا كان الحاجز نصًا فقط، فهذه ملاحظة غير مكتملة وليست إغلاقًا.
4. **امنع التكرار:** يتحقق السكربت من صحة كل سطر قبل الإضافة، ويحسب بصمة نصية ثابتة من `entry_kind`, `cls`, `status`, `symptom`, `cause`, `fix`, `barrier` (دون `ts`). إذا كانت البصمة موجودة، يطبع «لم يُكرّر الإدخال» ولا يضيف سطرًا ثانيًا.
5. **افشل مغلقًا:** JSON غير صالح، أو حقل ناقص، أو قيمة غير نصية/فارغة يمنع الكتابة بالكامل. لا تُصلح سجلًا مكسورًا بصمت ولا تتخطى السطر التالف.

## التشغيل

```bash
python3 scripts/record_lesson.py \
  --brain <BRAIN> --entry-kind runbook --cls process --status observed \
  --symptom "..." --cause "..." --fix "..." --barrier "تحقق حي: ... → خرج 0"
```

للاختبار أو لسجل بديل استخدم `--learning <PATH>`. السكربت يعمل ببايثون 3 ومكتبات النظام فقط، بلا شبكة. لا يكتب إلى مشروع غير المسار الذي تعطيه صراحة، ولا يرسل أو ينشر شيئًا.
