# ترقية قسم الخريطة مع إغلاق البوابات

## القاعدة الأولى: البوابة تقرأ نصًّا مُسطَّحًا لا ملفًا

بوابة تغطية الأسلوب (`tools/audit_style_coverage.py`) لا تفحص ملف الواجهة `web/meta/<date>.json` كما هو، بل تُسطّح قيم JSON إلى نص ثم تشغّل `validators/check_prose_defects.py --md` عليه. النتيجة: أي لفظ ممنوع أو جملة مكرّرة داخل **مرجع بيانات** (مثل `appendices/area-coordinates.json`) يظهر مانعًا على سطح الواجهة، ولو لم يظهر في الصفحة المطبوعة.

لذلك عند تشخيص مانع على سطح JSON لا تفحص الملف الخام، بل أعد إنتاج ما تراه البوابة:

```bash
python3 scripts/check_surface_extraction.py --date <YYYY-MM-DD> --surface meta
```

السكربت يسطّح قيم ملف الواجهة كما تفعل الأداة، ويشغّل بوابة الصياغة، ويطبع الأسطر المانعة. شغّله قبل أي محاولة نشر وبعد كل تعديل على مراجع المناطق.

## مسار العمل

1. **قياس قبل التعديل** — اقرأ بنية القسم من المولّد (`generator/map_gulf.py` في موقع seawatch) وسجّل الناقص: مقياس رسم · سهم شمال · مفتاح طبقات · وصف للقارئ الشاشي · لوحة تكبير · إفصاح مصادر.
2. **ترقية القسم** — أضف الناقص في المولّد، واجعل كل نص ظاهر يمرّ على مترجم الواجهة `generator/i18n_en.py` (البناء يفشل مغلقًا على أي نص عربي بلا ترجمة).
3. **إغلاق بوابات المحتوى** — شغّل تدقيق التغطية وافحص كل سطح مانع بمنطق «النص المُسطَّح» أعلاه.
4. **البناء** — `generator/sync_from_brain.py --date <date>` ثم `generator/build_site.py`، وتأكد من `rc=0` ومن «0 نصوص عربية بلا ترجمة».
5. **الكتيب** — لا تنشر خارج خطوات المانيفست: `tools/runbook.py run --date <date> --redo "<STEP>"`. الرمز 10 = نفّذ نص الخطوة ثم `complete` ثم أعد التشغيل · الرمز 2 = توقف ولا نشر.
6. **التحقق الحي** — بعد النشر قِس المسارات فعليًا (HTTP + وجود عناصر الترقية في HTML) على العربية والإنجليزية، ولا تدّع انتشارًا بلا هذا القياس.

## أعطال متكرّرة وحلولها المقيسة

| العَرَض | السبب الجذري | الإصلاح |
|---|---|---|
| سطح «ملف الواجهة» مانع والملف يبدو نظيفًا | لفظ ممنوع داخل حقل `basis` في مرجع المناطق يظهر بعد التسطيح | استبدال اللفظ في المرجع نفسه ثم إعادة توليد ملف الواجهة |
| «قالب جملة متكرر أكثر من مرتين» | مِرساة واحدة تخدم عدة وقائع فيتكرر نص مسند الموضع حرفيًا | اجعل مسند كل نقطة جملة فريدة تحمل عنوان واقعتها، لا لاحقة بعد فاصل |
| CSS ميت أو خطوط خريطة مفقودة | معالج نص عام يقصّ محتوى داخل وسم الأنماط | ضع الأنماط داخل العنصر أو احمِ الوسم من المعالج |
| اقتطاع نسخ المهارات الحاكمة | نسخ نسخ الجلسة فوق النسخ الكاملة دون مقارنة | قارن عدد الأسطر أولًا، واستعد النسخة الكاملة من تاريخ المرآة، وانشرها في المواضع الثلاثة |
| فشل خطوة النسخة الاحتياطية (شجرة غير نظيفة) | تغييرات غير مُلتزَمة في مستودع المرآة | التزم التغييرات عبر فرع ثم طلب دمج، وأبقِ الشجرة نظيفة قبل الخطوة |
| انحراف تماثل ضخم بعد تنظيف | استثناء مجلد مُعلَن في عقد التماثل (`.gitignore`) | لا تستثنِ مسارات مُعلَنة في عقد التماثل؛ نظّف بملف مرجعي واحد لا بمجلد |

## قواعد لا تُخالَف

- لا نشر ولا دفع خارج خطوات المانيفست، ولا دفع مباشر إلى `main` في أي مستودع — فرع ثم طلب دمج.
- لا تُعدّل رقمًا في بطاقة أو مسند موضع إلا من مصدره الحاكم، مع إثبات قبل/بعد.
- كل عطل يُغلق بسلسلة واحدة: تشخيص → إصلاح مُثبت → صف في سجل الأعطال (12 عمودًا) → درس → تشديد آلي → دفع.

## الموارد

- `scripts/check_surface_extraction.py` — إعادة إنتاج ما تراه بوابة تغطية الأسلوب على سطح JSON أو المتن.
- `references/gate-surface-contract.md` — عقد الأسطح الثمانية ورموز الخروج وموضع كل سطح.
