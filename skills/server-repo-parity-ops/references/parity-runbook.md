# دليل جولة التماثل

## متغيرات الجولة

```bash
export BRAIN=/path/to/brain-marine-news
export SITE=/path/to/seawatch
export REPO=/path/to/mda-marine-system
export SKILLS=/path/to/skills
```

## قياس قبل وبعد

نفّذ المدقق في `advisory` قبل النسخ وفي `strict` بعده. سجّل الشجرة المحلية والمستودع والزوائد وعدد الروابط ورمز الخروج. افحص المسارات المحمولة من الجذر نفسه، ثم شغّل نسخة جافة للاتجاه المقصود.

## اتجاه الخادم إلى المستودع

استخدم `sync_to_repo.py` عندما تكون الوجهة مجلدًا واحدًا، أو `github_backup.py` عندما تبني المرآة الكاملة. تحفظ القواعد مجلد الحالة وملفات البيئة والسر، وتستثني المخلفات والمخرجات المولّدة. راجع سجل الاستثناءات قبل فتح طلب الدمج.

## اتجاه المستودع إلى الخادم

استخدم `apply_from_github.py --dry-run`، ثم راجع التعارضات. لا تستخدم `--accept-repo` إلا بعد قرار موثق. الأداة تطبق المسارات المصنفة `code` فقط، تؤرشف النسخ المستبدلة، وتستعيدها عند فشل التحقق.

## التسليم

أنشئ فرعًا مثل `sync/server-to-repo-YYYYMMDD` أو `sync/repo-to-server-YYYYMMDD`. شغّل الفحوص على الفرع، ادفع الفرع وافتح طلب دمج، ثم أعد القياس بعد الدمج. امنع الدفع المباشر إلى `main`.

## إغلاق الجولة

لا تغلق الجولة إذا بقي انحراف غير مفسر أو زائدة غير مسموحة أو مسار مطلق أو فرق في نوع العنصر. سجّل السبب الجذري والقاعدة والاختبار السلبي وشغّل `scripts/propose_tightening.py`.
