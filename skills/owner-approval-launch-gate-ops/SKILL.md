# بوابة الانطلاق المحكوم: اعتماد ← جاهزية ← انطلاق بلا توقف

الانطلاق بلا هذه البوابة ينتج أحد ثلاثة: عمل بلا سند (لا قرار يحفظ الاعتماد)، أو انطلاق بند غير مسنَد إلى مرحلة (يُنسى)، أو توقف صامت عند أول عائق.

## 1. سجّل الموافقة قبل أن تعمل

الموافقة الشفهية لا تكفي: تُقيَّد قرارًا مرقّمًا بنصّ المالك الحرفي، وحالة تُطابق الواقع، وأدلة ملفية (جرد البنود + الخطة). **بلا قرار، الاعتماد غير موجود في السجل.**

| الحالة | ما يُكتب |
|---|---|
| المالك قال «انطلق» أو «اعتمد» | `منفَّذ` + نصّه الحرفي + أدلة الجرد والخطة |
| الاعتماد جزئي أو مشروط | `منفَّذ جزئيًّا` + البنود المستثناة صريحةً |
| لم يُقل بعد | `يحتاج قرارًا` — ولا يبدأ تنفيذ |

## 2. قِس الجاهزية قبل الانطلاق

شغّل `scripts/check_launch_readiness.py --plan <الخطة> --registry <الدفتر> --inventory <الجرد>`.

يقيس أربعة:

1. **تغطية البنود**: كل معرّف في الجرد له مرجع في الخطة؛ والناقص يُطبع باسمه. وإن تبيّن أن معرّفًا «ناقص» **مدموج** في آخر، فاكتب الدمج صراحةً في الجرد ولا تعتبره فجوة.
2. **تداخل الخطة**: يستدعي أداة المهارة الجارة `pre-execution-plan-audit-ops/scripts/audit_plan_duplication.py` — بند أو ملف في مرحلتين = مانع.
3. **قرار الاعتماد**: قرار في الدفتر يذكر الجرد أو نطاق المعرّفات؛ غيابه مانع.
4. **البنود المعلّقة**: قسم معلن (مثل «ما ينتظر») يسمّي كل بند معلّق وحالته؛ البند المعلّق المخفي مانع.

rc=0 جاهز · rc=2 مانع يمنع الانطلاق.

## 3. الأمران الإلزاميان — كيف يُنفَّذان لا كيف يُقالان

| الأمر | التطبيق الفعلي |
|---|---|
| **ممنوع التوقف** | كل عائق يُعالج بمسارين: إصلاح جذري، أو **بديل معلن** يعمل فعلًا؛ ثم يُسجَّل بـ`scripts/record_obstacle.py` (سبب + إجراء + حالة). الأداة ترفض تسجيل عائق بلا إجراء — فلا يُقبل «توقفنا» كحالة. |
| **قراءة كل شيء** | لا حكم على ملف من عنوانه أو أوله: اقرأه كاملًا، وقِس ما تدّعيه بسكربت، وسجّل عدد الأسطر أو البصمة التي قرأتها. أي ادّعاء بلا قياس = ادّعاء غير مسنَد. |

## 4. الانطلاق بالمراحل

مرحلة ← بوابة ← مرحلة. لا انتقال قبل `rc=0`، ولا نشر أو إرسال خارج خطوات المانيفست. وعند اكتمال مرحلة: ثبّت الدليل (أمر + مخرج + بصمة) في سجل الأعطال أو القرارات، ثم انتقل.

## 5. حلقة التعلّم الذاتي

بعد كل عائق: **عطل** (العرض ورمز الخروج) ← **درس** (السبب الجذري) ← **حاجز** (قاعدة أو فحص قابل للتنفيذ) ← **اختبار** (حالة سليمة تمر وحالة مخالفة تمنع). وأضف:

1. **عائق بلا إجراء = عائق لم يُغلق**؛ لا تنتقل لمرحلة تالية وعائق مفتوح في سجل العوائق.
2. **راجع البوابة عند تغيّر شكل الخطة**: إضافة مرحلة أو معرّف جديد تُعاد معها قياس التغطية والتداخل.
3. **إن تكرر عائق في مرحلتين**، فالحاجز ناقص: شدّده بدل تكرار الإصلاح.

## الحدود

- لا تبدأ تنفيذًا بلا موافقة صريحة مقيَّدة في الدفتر.
- لا تُعِدّ حارسًا أو تخفّفه لتُمرِّر مرحلة؛ المهارة الجارة `gate-strictness-hardening-ops` تُصلح الحراس.
- لا تُنشئ أو تعتمد مهارة؛ ذلك `skill-creator` ثم `skill-adoption-governance-ops`.

### حدّ عدم التداخل مع المهارات المجاورة

| المهارة المجاورة | الحد الفاصل |
|---|---|
| `pre-execution-plan-audit-ops` | تلك تدقّق الخطة والادعاءات وتُنتج قياسًا؛ وهذه تحوّل الموافقة إلى قرار ثم **تفتح التنفيذ** وتضبط عدم التوقف. |
| `owner-notes-measured-triage` | تلك تفرز الملاحظات بالقياس قبل التنفيذ؛ وهذه تبدأ بعد الفرز والاعتماد. |
| `runbook-execution-ops` | تلك تشغّل الكتيب اليومي بخطواته؛ وهذه تحكم لحظة الانطلاق على خطة متعددة المراحل. |
| `fault-closure-ops` | تلك تُغلق عطلًا بأدلة؛ وهذه تسجّل العائق أثناء التنفيذ وتمنع التوقف الصامت. |
