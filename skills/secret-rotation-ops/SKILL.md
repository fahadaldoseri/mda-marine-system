# تشغيل تدوير السر وإغلاق ملفه الأمني

اعتبر التدوير عملية تغيير منسّقة بين المستهلكين والجهة الخارجية والمخزن المحلي. لا تطبع السر القديم أو الجديد أو التوكن أو diff يحتويها؛ استخدم البصمات والأطوال وعدّادات المسارات فقط.

## التسلسل الإلزامي

1. حدّد جذر المشروع بوسيط `--brain` أو `BRAIN_DIR`. مرّر `--env` و`--state` و`--docs` و`--backup-dir` عندما تختلف البنية.
2. اقرأ المخزن الحالي، واكتشف المستهلكين قبل التغيير، وسجّل عددهم ومساراتهم الآمنة فقط.
3. افحص تاريخ Git للقيمة القديمة. أخرج عدد المواضع لا commit diff ولا السطر الذي يحمل القيمة.
4. نفّذ تجربة جافة أولًا، وتأكد من أن الأداة لا تكتب ملفًا ولا تحدث الويب هوك.
5. أنشئ نسخة احتياطية بصلاحيات المجلد `0700` والملفات `0600` قبل الكتابة، واحتفظ بختم زمني وبمسار الاستعادة.
6. ولّد قيمة جديدة، وسجّل بصمتها فقط. حدّث المستهلك الخارجي ثم المخزن المحلي، أو استعد النسخة المحلية إذا فشل التسجيل الخارجي.
7. نفّذ `getWebhookInfo` بعد `setWebhook`، وطابق الرابط والحالة الحية. لا تعتبر التحديث المحلي نجاحًا إذا تعذر الإثبات الحي، إلا مع `--allow-local-only` وسبب موثق.
8. افحص بقايا القيمة القديمة في الشجرة مع استثناء مجلد النسخ المقفلة، وحدّث الوثيقة الأمنية بوقت العملية والبصمات والعدادات فقط.
9. شغّل مدقق قابلية النقل، ثم راجع أن سجل Git والوثيقة والمخرجات لا تحتوي قيمة السر.

## أوامر التشغيل

نفّذ تجربة آمنة على مشروع حقيقي دون تغيير:

```bash
python3 scripts/tools/rotate_webhook_secret.py \
  --brain "$BRAIN" --repo "$BRAIN" --dry-run --skip-telegram
python3 scripts/validators/check_portable_paths.py --brain "$BRAIN" --site "$SITE"
```

نفّذ التدوير الفعلي فقط بعد موافقة تشغيلية صريحة:

```bash
python3 scripts/tools/rotate_webhook_secret.py \
  --brain "$BRAIN" --repo "$BRAIN" \
  --env "$BRAIN/secrets/secrets.env" \
  --state "$BRAIN/state/webhook-secret.txt" \
  --docs "$BRAIN/appendices/security-notes.md"
```

لا تستخدم `--skip-telegram` في إغلاق أمني مكتمل. إذا كانت الجهة الخارجية تدار خارج الأداة، استخدم `--allow-local-only` فقط بعد توثيق المالك لسبب غياب التحقق الحي، وابقِ الحالة مفتوحة للمراجعة الحية.

## الجرد والنسخة الاحتياطية

اعتبر كل كود أو إعداد أو خدمة تستخدم `TELEGRAM_WEBHOOK_SECRET` مستهلكًا. افحص الاسم والمعرّفات الوظيفية مثل `WEBHOOK_SECRET` و`secret_token`، لكن لا تعرض المحتوى. افحص ملفات البيئة وملف الحالة ومخزن النشر وأي موصل خارجي قبل التدوير.

أنشئ نسخة احتياطية قبل الكتابة في مجلد منفصل مقفول. لا تضع النسخة الاحتياطية في المستودع ولا في تقرير عام. اذكر عدد الملفات ومكان النسخة وختم العملية فقط. اختبر الاستعادة في بيئة معزولة عند أول استخدام للأداة.

## فحص التسرب وتحديث الوثائق

افحص تاريخ Git للقيمة القديمة بطريقة لا تطبع diff. بعد التدوير افحص الشجرة وسجل Git والنسخة المنشورة عن القيمة القديمة، وسجّل العدد فقط. لا تسجل السر في سجل الأعطال أو الذاكرة أو رسالة commit أو طلب الدمج.

حدّث `appendices/security-notes.md` أو مسار الوثيقة الذي يمرر عبر `--docs` بمدخل آمن يذكر التاريخ، بصمة القيمة السابقة والجديدة، عدد المستهلكين، عدد مواضع التاريخ، وعدد نجاح التحقق الحي. لا تكتب القيمة أو التوكن أو رابطًا يحمل اعتمادًا.

## التحقق بعد التدوير

لا تعلن الإغلاق إلا إذا تحققت الشروط الآتية معًا

- المخزن المحلي وملف الحالة يطابقان البصمة الجديدة.
- الجهة الخارجية تقبل التحديث، ويثبت الاستعلام الحي الرابط والحالة بعد التدوير.
- لا تظهر القيمة القديمة في الشجرة خارج النسخة المقفلة، ولا توجد مواضع تسرب جديدة في Git.
- الوثيقة محدثة دون قيمة سرية، ومدقق قابلية النقل يخرج بالرمز صفر.
- مخرجات الأداة تخلو من السر القديم والجديد والتوكن، ويثبت ذلك باختبار التقاط مخرجات سلبي.

## حلقة التحسين الذاتي

سجّل كل ثغرة في سجل الأعطال بهذه السلسلة

1. اكتب العرض والسبب الجذري، مثل غياب مستهلك من الجرد أو طبع قيمة في رسالة خطأ.
2. شدّد قاعدة قابلة للتنفيذ، مثل عدّ المستهلكين قبل التدوير أو حجب القيم في الاستثناءات أو إلزام التحقق الحي.
3. أضف اختبارًا سلبيًا يكسر القاعدة، مثل إدخال قيمة وهمية والتأكد من أنها لا تظهر في المخرجات أو حذف مستهلك والتأكد من فشل الجرد.
4. شغّل أداة الاقتراح بعد كل جولة:

```bash
python3 scripts/propose_tightening.py --brain "$BRAIN"
```

تقرأ الأداة سجلات JSONL وسجل Markdown، وتستخرج أصناف جرد المستهلكين والنسخ الاحتياطية والتسرب التاريخي وحجب المخرجات والتحقق الحي والتوثيق والمسارات المحمولة، ثم تقترح لكل صنف قاعدة واختبارًا سلبيًا. لا تعتبر الصنف غير المعروف مغلقًا؛ أضف له تصنيفًا وحاجزًا.

## الملفات المرفقة

- `scripts/tools/rotate_webhook_secret.py` للتدوير الآمن دون طباعة قيمة.
- `scripts/validators/check_portable_paths.py` لمنع المسارات المطلقة.
- `scripts/propose_tightening.py` لحلقة التحسين الذاتي.
- `references/rotation-runbook.md` لتسلسل الجرد والنسخ والتدوير والتحقق.
