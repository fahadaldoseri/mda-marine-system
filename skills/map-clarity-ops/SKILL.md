# وضوح الخريطة وترقية القسم

## الغرض والحدود
قِس خريطة التقرير على سطح مبني/منشور، ثم أصلح الحيز والوسوم والمفتاح والوصف وقابلية الوصول من المصدر. هذه المهارة لا تدير بقية أسطح التقرير أو الطباعة العامة أو إغلاق العطل؛ استخدم `report-surface-and-print-ops` للسطوح/PDF و`fault-closure-and-learning-ops` للإغلاق.

## الأدوار المحفوظة
- `map-readability-ops`: حد أدنى 12px، فصل العلامات 22px، معرّف لكل واقعة، صفر overflow أفقي غير مقصود، وتباين AA.
- `map-section-upgrade-ops`: مقياس رسم، سهم شمال، مفتاح طبقات، وصف قارئ الشاشة، لوحة تكبير، إفصاح مصادر، وربط البوابات والنشر والتحقق الحي.

## معايير القبول المقيسة
- النص المرئي ≥12px في المكتب والجوال.
- العلامات المتجاورة ≥22px أو عنقود واحد بعدّاد ومعرّفات.
- كل علامة تعود إلى `incident_id` ومصدر مؤرخ.
- لا تمرير أفقي على مستوى الصفحة؛ يسمح بإطار خريطة مضبوط عند الحاجة.
- التباين AA، وعدم الاعتماد على اللون وحده.
- المقياس/الشمال/المفتاح/وصف القارئ الشاشي/لوحة التكبير/إفصاح المصدر موجودة عند اشتراطها.

## المسار الإلزامي
1. اقرأ مولّد الخريطة وCSS ومعايير القياس؛ طابق أصناف HTML مع محدداتها.
2. قِس المكتب والجوال بأداة المتصفح واحفظ JSON واللقطات.
3. افصل العلامات أو كوّن عنقودًا يحفظ كل المعرّفات؛ لا تغيّر الإسقاط لإخفاء التزاحم.
4. أضف عناصر الترقية في المولد، ومرّر النص الجديد على قاموس الترجمة.
5. أعد البناء، شغّل بوابة التغطية، ثم تحقق من الرابط المنشور مع كسر التخزين المؤقت.
6. سجّل قبل/بعد ورمز الخروج؛ المنع لا يتحول إلى تحذير.

## الدليل المقيس
أثبت أمر القياس، viewport، `font_px`, `marker_distance_px`, `scroll_width`, عدد المعرّفات، التباين، وجود العناصر، ورمز الخروج. مثال الجولة الأخيرة: فحص الخريطة الجوالة يمنع نصًا تحت 12px أو تراكبًا، ويثبت المخرج في JSON واللقطة. إذا لم يُقَس الرابط الحي، اكتب «لم أختبره».

## حلقة التعلم الذاتي
بعد كل خلل: **عطل** (وسم/عنصر/viewport ورمز) ← **درس** (حيز/تسمية/ترجمة/مولد) ← **حاجز** (معيار أو بوابة) ← **اختبار** (خريطة سليمة تمر، نص 10px أو marker متداخل يمنع، ثم قياس حي). مثال: صنف HTML `hmap` لم يطابق CSS `hmap-panel`؛ الدرس أن القياس كان يقرأ عنصرًا غير موجود؛ الحاجز فحص وجود selector قبل القياس؛ الاختبار يحذف الصنف ويتطلب رمز 2.

## أخطاء ممنوعة
- رفع دقة الصورة بدل إصلاح حجم النص والحيز.
- حذف واقعة للتخلص من تراكب العلامات.
- إضافة طبقة بلا مصدر رسمي مؤرخ.
- كتابة نص عربي جديد في JSON دون ترجمة مقابلة.

## التسليم
سلّم JSON واللقطات قبل/بعد، رابط السطح، viewport، الأوامر والرموز، قائمة العناصر والمعرّفات، وحالة الترجمة. التفاصيل القديمة محفوظة في `references/legacy/<old-skill>/`.
