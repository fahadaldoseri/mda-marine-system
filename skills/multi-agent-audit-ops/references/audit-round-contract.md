# عقد جولة التدقيق المشتركة

هذا العقد هو البروتوكول المشترك بين منسق التدقيق ومالكي المحاور. لا ينقل ملكية بوابة أو حكم مجال؛ يحدد فقط كيف تُقاس الادعاءات وتُسجّل الأدلة قبل الإصلاح وبعده.

## سؤال الجولة

هل أعاد قياس مستقل قابل لإعادة التشغيل إنتاج الادعاء أو نفيه، وهل بقيت نتيجة الجولة الثانية قابلة للمقارنة؟ لا تُستبدل إجابة السؤال بقول وكيل أو بسلامة ظاهرية.

## التسلسل الملزم

1. **ثبّت المدخلات:** سجّل النسخة، وقت الجولة، المسارات أو الروابط، والمالك والمحور. لا تعدّل المدخل أثناء القياس.
2. **قِس قبل الإصلاح:** حوّل كل ادعاء إلى أمر حقيقي قابل لإعادة التشغيل، وسجّل الأمر كاملًا، ورمز الخروج أو القيمة، والعتبة، ووقت القياس. القياس قد يكون مدققًا أو اختبارًا أو طلب HTTP أو رقمًا رقميًا.
3. **صنّف مستوى الدليل:**
   - **مؤكد بقياس:** أمر صالح أعاد النتيجة المتوقعة ورمز/قيمة قابلة للفحص.
   - **مؤكد بالوكيل:** ملاحظة وكيل لم تُعد بقياس مستقل؛ لا تُغلق ولا تُعرض كنجاح.
   - **مرفوض بقياس:** القياس الصالح لم يُعد إنتاج الادعاء أو خالفه.
   - **لم يُتحقق:** غاب القياس أو اللقطة أو تعذر الحكم أو تعارضت الأدلة؛ لا يُستنتج منه «سليم».
4. **امنع الادعاء بلا قياس:** لا تسجّل «سليم» أو «مؤكد» أو «أُصلح» في التقرير النهائي بلا أمر ومخرج صالحين. إذا حمل صف `confirmed` قياسًا مفقودًا أو غير صالح، يجب أن يعيد `claims_table.py` الرمز `2` ويوقف التقرير.
5. **أصلح المؤكد بقياس فقط:** سجّل العيب المؤكد مع السبب الجذري والقاعدة المشددة والاختبار السلبي، ثم أصلح موضعه عند مالك المحور. لا تحوّل المرفوض أو غير المتحقق إلى عيب.
6. **قِس بعد الإصلاح:** أعد الأمر نفسه على النسخة المعدّلة، وسجّل القيمة أو الرمز الجديد والفرق قبل/بعد. لا تقبل عبارة «تم الإصلاح» بلا هذه المقارنة.
7. **نفّذ الجولة الثانية:** بعد الإصلاح والاختبار السلبي، أعد تدقيق المحاور بالقياسات نفسها، وقارن الصفوف والأوامر والرموز والأرقام واللقطات عند الحاجة. أغلق البند فقط إذا تغيّر الدليل إلى نتيجة مقبولة؛ أبقِ غير المتحقق معلّقًا.
8. **احفظ الأثر:** لكل بند معرّف فريد، محور ومالك واحد، ادعاء، أمر، مخرج أو مسار لقطة، رمز/قيمة، حالة، ووقت. أحِل حدود الدليل إلى المالك المختص بدل توسيع نطاق البوابة.

## واجهة المنسق

يستخدم `multi-agent-audit-ops` هذا العقد لتنسيق الملفات المنفصلة، ويظل `references/claim-measurement.md` مرجع مخطط JSON فقط. يملك كل محور بوابته وأمره؛ لا يعلن المنسق سلامة محور مالك آخر ولا يستبدل المعاينة البصرية أو فحص أمانة المحتوى أو قرار سياسة الأسطح.
