# أفضل الممارسات في صياغة الأوامر

## مقدمة

هذا الملف يوفر نصائح متقدمة وأفضل الممارسات لصياغة أوامر فعالة عند التعامل مع Manus.

---

## 1. التخطيط قبل الكتابة

### اسأل نفسك هذه الأسئلة:
- **ما هو الهدف بالضبط؟** - كن محدداً جداً
- **ما المعلومات التي أحتاجها؟** - اذكر جميع التفاصيل
- **ما الصيغة المطلوبة؟** - نص، كود، جدول، إلخ
- **هل هناك قيود؟** - وقت، حجم، متطلبات تقنية

---

## 2. هيكلة الأمر الفعال

### الترتيب الموصى به:
1. **الهدف الرئيسي** - اذكره في البداية
2. **السياق والخلفية** - معلومات تساعد على الفهم
3. **التفاصيل المحددة** - ما تريده بالضبط
4. **الصيغة المطلوبة** - كيف تريد النتيجة
5. **القيود والمتطلبات** - أي قيود خاصة

### مثال على الهيكلة:
```
أنا [الدور/السياق]. أحتاج [الهدف الرئيسي].
[السياق الإضافي والخلفية].
يرجى [التفاصيل المحددة].
الصيغة المطلوبة: [نوع الإخراج].
القيود: [أي متطلبات خاصة].
```

---

## 3. تجنب الأخطاء الشائعة

### ❌ الأخطاء الشائعة:

| الخطأ | المثال | الحل |
|------|--------|------|
| **الغموض** | "ساعدني في المشروع" | "أحتاج إلى إنشاء موقع ويب للتجارة الإلكترونية" |
| **الطلب المفرط** | "اكتب كل شيء" | "ركز على الخطوات الثلاث الأولى" |
| **عدم الوضوح** | "أريد شيئاً جميلاً" | "أريد تصميماً حديثاً بألوان زاهية" |
| **نقص السياق** | "أصلح الخطأ" | "أصلح الخطأ: [رسالة الخطأ]" |
| **عدم تحديد الصيغة** | "أخبرني" | "اكتب 3 فقرات بصيغة أكاديمية" |

---

## 4. استراتيجيات متقدمة

### استراتيجية "التفكير بصوت عالي"
اشرح عملية التفكير الخاصة بك:
```
أنا أفكر في المشكلة بهذه الطريقة:
1. [الخطوة الأولى من التفكير]
2. [الخطوة الثانية]
3. [حيث أعلق]

هل يمكنك مساعدتي في [النقطة المحددة]؟
```

### استراتيجية "الأمثلة"
قدم أمثلة لما تريده:
```
أريد محتوى بهذا الأسلوب:
[مثال 1]
[مثال 2]

هل يمكنك إنشاء محتوى مشابه لـ [الموضوع]؟
```

### استراتيجية "الأدوار"
حدد الدور الذي تريده:
```
تصرف كـ [دور محدد] وقم بـ [المهمة].
```

---

## 5. التعامل مع الأخطاء والتصحيحات

### عندما لا تحصل على النتيجة المطلوبة:

1. **حدد ما هو خاطئ بالضبط**
   ```
   النتيجة قريبة لكن:
   - [المشكلة 1]
   - [المشكلة 2]
   ```

2. **قدم تعليقات محددة**
   ```
   يرجى تعديل [الجزء المحدد] ليكون أكثر [الخاصية المطلوبة].
   ```

3. **جرب نهجاً مختلفاً**
   ```
   دعنا نحاول بطريقة أخرى: [الطريقة الجديدة]
   ```

---

## 6. نصائح لأنواع مختلفة من الطلبات

### عند طلب كود:
- حدد لغة البرمجة والإصدار
- اذكر المكتبات المفضلة
- اشرح الحالات الاستخدام
- اطلب تعليقات في الكود
- اطلب معالجة الأخطاء

### عند طلب كتابة:
- حدد الجمهور المستهدف
- اذكر النبرة المطلوبة
- حدد الطول المطلوب
- اطلب هيكلة محددة
- اذكر أي معايير خاصة

### عند طلب تحليل:
- قدم البيانات الكاملة
- اشرح ما تريد معرفته
- اذكر السياق المهم
- اطلب تصور بياني إن أمكن
- اطلب توصيات واضحة

---

## 7. الأوامر الفعالة للعمل المتكرر

### أوامر "القالب" المفيدة:

#### للبحث والتحليل:
```
ابحث عن [الموضوع] وقدم:
1. ملخص في 3 نقاط رئيسية
2. الإحصائيات الرئيسية
3. الاتجاهات الحالية
4. التوصيات
```

#### للكتابة:
```
اكتب [نوع المحتوى] حول [الموضوع]:
- الجمهور: [من]
- الطول: [كم]
- النبرة: [أي نبرة]
- الهيكل: [كيف]
```

#### لحل المشاكل:
```
أواجه مشكلة في [المجال]:
- الخطأ: [الخطأ المحدد]
- السياق: [المعلومات الخلفية]
- ما حاولت: [المحاولات السابقة]
- ما أريده: [الحل المطلوب]
```

### الانتقال بين المواضيع:
```
بناءً على [الجزء السابق]، الآن أريد التركيز على [الموضوع الجديد].
```

## 10. أمثلة متقدمة

### مثال 1: طلب معقد
```
أنا أعمل على مشروع تطبيق ويب للإدارة. أحتاج إلى:

1. تصميم قاعدة بيانات لـ:
   - جداول المستخدمين
   - جداول المشاريع
   - جداول المهام

2. API endpoints لـ:
   - إنشاء/قراءة/تحديث/حذف المشاريع
   - إدارة المهام

3. معالجة الأخطاء والتحقق من الصحة

يرجى استخدام:
- Node.js + Express
- MongoDB
- RESTful API

ركز على الأمان والأداء.
```

### مثال 2: طلب متكرر
```
أريد تحديث المحتوى السابق بـ:
- إضافة معلومات عن [الموضوع الجديد]
- تحديث الإحصائيات
- تحسين الصيغة

الحفاظ على النبرة والهيكل الأصليين.
```
