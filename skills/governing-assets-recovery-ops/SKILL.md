# استعادة الأصول الحاكمة وإغلاق أثر التلف

استخدم هذا المسار عندما يظهر فقد شاهد أو ملف، أو تُلمس مهارة بلا تصريح، أو تنقل مزامنة حذفًا، أو يُشتبه في اختصار ملف حاكم. اعتبر عبارة «قراءة فقط» وصفًا للنية لا حماية للقرص.

## الحدود والإحالات

- املك هنا **الكشف الكمي، الاستعادة من مصدر موثوق، وإثبات ما قبل/بعد**.
- أحِل قرار تداخل الملكية وجرد المهارات إلى `skill-ownership-merge-ops`، ولا تنشئ مهارة مكررة.
- أحِل مخطط الأعطال، 12 عمودًا، مصفوفة التتبع، الدرس، الثبات المزدوج، والاختبار العدائي إلى `fault-closure-ops`.
- أحِل عقد `--help` والمجهول والآثار الجانبية ورموز الخروج إلى `side-effects-interface-audit-ops` و`tool-contract-check-ops`.
- لا تعِد تعريف هذه الآليات؛ سجّل الأمر والمخرج والرمز الفعلي.

## متى تُستدعى

استدعِ المهارة عند:

- فشل حارس يكشف شواهد أو ملفات مفقودة.
- جولة وكيل لمست ملفات لم يُصرّح لها.
- مزامنة حذفت ملفات أو استعملت `--allow-delete`.
- شك في اختصار `SKILL.md` أو ملف مرجع حاكم.

## المسار الإلزامي

1. **جمّد النطاق وقِس قبلًا.** سجّل الجذرين، `git status --short`، والوقت. لا تشغّل مزامنة أو استعادة قبل حفظ القياس. افحص كل الأصول الحاكمة، لا الملف المشكوك فقط، عبر:
   ```bash
   python3 scripts/compare_governing_assets.py /home/ubuntu/skills /home/ubuntu/mda-marine-system/skills
   ```
   قارِن اتحاد الملفات كاملًا: عدد الأسطر، بصمة SHA-256، والملفات الناقصة في كل طرف. اعتبر أي فرق مانعًا، واحفظ الجدول والرمز.

2. **أثبت الأثر على المستهلكين.** ابحث في `SKILL.md` والـ`references/` والبوابات والمانيفست والاختبارات عن المسارات والشواهد المفقودة. اربط كل شاهد بالسكربت أو البوابة أو الإحالة التي تستهلكه. لا تكتفِ بعدّ ملفات الدليل.

3. **شخّص السبب دون إخفاء التلف.** افصل بين اختصار المحتوى، حذف الملف، انتشار نسخة ناقصة إلى المرآة، وخطأ في الحارس. احفظ المخرج الحرفي للحارس. لا تُحوّل رمزًا غير صفري إلى تحذير.

4. **استعد قبل أي تعديل يدوي.** استخدم المرآة أولًا، ثم تاريخ Git عند كون الملف مضافًا في دمج:
   ```bash
   bash /home/ubuntu/brain-marine-news/tools/restore_skills.sh --check
   git show <merge>^:<path> > <isolated-recovery-copy>
   ```
   طبّق الاستعادة فقط بعد مراجعة الخطة والتفويض. لا تعِد بناء فقرة أو شاهد من الذاكرة، ولا تشغّل استعادة يدوية بالتخمين. لا تستخدم `sync_to_repo.py` أو نشرًا أو Telegram في هذه الجولة.

5. **أعد القياس حتى الصفر.** بعد الاستعادة أعد المقارنة الشاملة، ثم شغّل:
   ```bash
   python3 /home/ubuntu/brain-marine-news/validators/check_skills_integrity.py
   ```
   اقبل فقط مخرجًا يثبت كل الشواهد ورمز خروج `0`. قِس البصمة والطول والملفات الناقصة؛ لا تعتبر نجاحًا بصريًا أو `git diff` وحده دليلًا.

6. **وثّق فورًا وأغلق الحلقة.** أضف العطل إلى `audit/سجل-الأعطال-والثغرات.md` بالأعمدة الـ12: `المعرّف · التاريخ · المحور · العَرَض · السبب الجذري · الإصلاح · التشديد والحالة · الحالة الأصلية · حالة الإصلاح · حالة التحقق · حالة الحاجز · الحالة التشغيلية`. اربطه بدرس واحد في `memory/learning-log.jsonl` وبمصفوفة التتبع. ثم نفّذ:
   ```bash
   python3 tools/closure_round.py --apply
   python3 validators/check_closure.py
   python3 validators/check_closure.py
   ```
   سجّل المخرج والرمز لكل أمر. لا تعلن الإغلاق بلا تشغيل حي اليوم، واثبات ثبات الحارس مرتين. استخدم `fault-closure-ops` إذا احتجت إدخالًا أو اختبارًا عدائيًا وفق مخططها.

7. **حصّن المستقبل واختبر المنع.** طبّق قاعدة تمنع التكرار: امنع `init_skill.py` على أسماء المهارات الحاكمة القائمة؛ شغّل `check_skills_integrity` بعد كل جولة تلمس المهارات؛ راجع قائمة الحذف ومساراتها قبل السماح بـ`--allow-delete`، واجعل الوضع الافتراضي بلا حذف. أثبت الحاجز باختبار سلبي، ثم أعد المقارنة.

## القواعد الحاكمة

- قدّم المرآة، ثم تاريخ Git، على أي إصلاح يدوي.
- لا تستعد بالتخمين، ولا تخفِ التلف، ولا تُسقط أصلًا غير مشكوك فيه من المقارنة.
- اجعل كل استعادة قابلة للقياس بحارس؛ لا تجعل العين أو تساوي عدد الملفات دليلًا كافيًا.
- وثّق فورًا: الإصلاح وحده لا يغلق الحلقة؛ الدرس والحاجز ومصفوفة التتبع جزء من الإغلاق.
- لا تعتبر «قراءة فقط» حمايةً؛ أثبت الأثر قبل/بعد، واعزل أي تجربة غير مؤكدة.

## التعلم الذاتي الإلزامي

سجّل كل تلف في السجل الحاكم، واربطه بالدرس ومصفوفة التتبع ودليل التشغيل. عند تكرار نمط جديد، حدّث هذه المهارة بدرس مدمج وحاجز أو اختبار سلبي يمنع عودته. إذا أفلت عطل من الحارس، شدّد الحارس ولا تُخفّف القاعدة لتمريره.

## أخطاء شائعة يجب منعها

- تعليمات «قراءة فقط» لا تمنع وكيلًا من الكتابة على القرص.
- المزامنة بـ`--allow-delete` تنقل التلف إلى المرآة وتحوّلها إلى مصدر مضلل.
- حارس يقيس 16 شاهدًا فقط لا يكشف تلف الأصول الحاكمة كافة.
- استعادة ملف بلا إعادة قياس تترك حلقة التعلم مفتوحة.
- فحص ملف واحد أو عدد الملفات فقط يخفي اختصار `SKILL.md` واختلاف البصمة.

## الأداة المرفقة

شغّل `scripts/compare_governing_assets.py` للقراءة فقط. يقارن مجلدين على اتحاد الملفات، ويطبع جدول الفروق مع طول الأسطر والبصمة والملفات الناقصة، ويعيد `0` عند التطابق، و`1` عند أي نقص أو انحراف، و`2` عند وسيط غير معروف أو جذر غير صالح. يجب أن يخرج `--help` بـ`0` قبل قراءة أي جذر.
