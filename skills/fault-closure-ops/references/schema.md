# المخطط والمفردات — إحالة توافقية

العقد الحاكم لمخطط سجل الأعطال ذي 12 عمودًا، ومفردات الحالة، ودليل النتيجة، والاستثناءات، ومصفوفة التتبع، والثبات، ورموز الفشل المغلق موجود مرة واحدة في [عقد الإغلاق المشترك](closure-contract.md).

أُبقي هذا المسار للتوافق مع الأدوات والروابط القائمة؛ لا يُعرّف عقدًا ثانيًا ولا يُعدّل أوامر `scripts/` أو بوابات المشروع.
