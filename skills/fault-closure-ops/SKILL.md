# تشغيل إغلاق الأعطال والدروس (Fail-Closed Closure Ops)

حوّل سجل الأعطال من «نصوص تُصدَّق» إلى «حالات مُشتقّة وأدلة قابلة لإعادة التشغيل».

## القواعد الخمس الحاكمة (لا تُخالَف)

1. **الحالة تُشتقّ لا تُعلن.** لا تُقرأ خانة «الحالة» من الملف؛ تُشتقّ من الإصلاح + التحقق + الحاجز + التاريخ. أي صف نصّه «مغلق» ولا يُشتقّ له ذلك **يُخفَّض** آليًا.
2. **الدليل قطعة تحتوي نتيجتها.** «خرج 0» · «رمز 2» · «نجح 39 · فشل 0» · «n/n» · «مطابق تمامًا» · «بصمة …». لا تُقبل نصوص وصفية مثل «مُصلح» أو «مرور كاذب».
3. **الفشل مغلق.** انهيار مدقق = منع. دليل فارغ = منع. معرّف غير معروف = منع. حالة غير معروفة = منع. رمز انهيار مخصّص (70) يمنع ولو لم يظهر نصّ.
4. **ثبات مزدوج.** تمريرتان متتاليتان على السجل + سجل التعلم تُنتجان الملف نفسه، وصفر دروس مشتقة جديدة.
5. **لا إغلاق بلا تشغيل حي اليوم.** لا استشهاد بذاكرة أو سجل قديم. لكل عطل: أمر يُشغَّل الآن + رمز خروجه.

## المسار القياسي (8 خطوات)

### 1) اجمع الواقع
```bash
python3 scripts/closure_round.py --brain <BRAIN> --dry-run   # ما ستُغيَّره
python3 scripts/check_closure.py --brain <BRAIN>             # الحالة الآن (متوقّع: منع)
```
اقرأ الملفين فعليًا: `audit/سجل-الأعطال-والثغرات.md` و`memory/learning-log.jsonl`. لا تعتمد أرقامًا من ملاحظة قديمة.

### 2) وحّد المخطط
كل صف إلى **12 عمودًا**: `المعرّف · التاريخ · المحور · العَرَض · السبب الجذري · الإصلاح · الحاجز · الحالة الأصلية · قاعدة الإصلاح · قاعدة التحقق · قاعدة الحاجز · الحالة المشتقة`.
- المخططات القديمة (7 · 10 · 11 عمودًا) تُحوَّل بلا فقد نصّ.
- **فخّ:** الصف ذو 12 عمودًا يجب أن **يعيد اشتقاق** حقوله الأربعة الأخيرة، لا أن يأخذ `cells[7:11]`؛ وإلا سقطت خلية الحالة ونزل رمز الحاجز مكانها (حالة «فعّال»).

### 3) اشتقّ الحالة
```
منفَّذ + (مطبَّق|فعّال) + تحقق تشغيلي ناجح  →  مغلق
مفتوح|لم يُصلح|بانتظار قرار                 →  مفتوح
التاريخ = —                                  →  موروث غير مثبت
غير ذلك                                      →  بانتظار التحقق
```
الدليل يُبنى من **الإصلاح والحاجز فقط** — لا من خانة «الحالة الأصلية».

### 4) أضف دليلًا حيًّا لكل صف موروث أو مغلق قديم
```bash
python3 scripts/insert_live_evidence.py --brain <BRAIN> --map evidence.json
```
- شغّل لكل صف **البوابة/الأداة المسمّاة في نصّه** الآن، والتقط رمز الخروج.
- الصيغة: `تحقق حي <DATE>: <الأمر> → خرج <N> · <علامة>`.
- **الدليل يُوضع أول الخانة بلا قصّ.** قصّ الخانة إلى 160 حرفًا يفصل الدليل عن نتيجته فيمنع الصف كذبًا.
- إن ظهر أن الأداة **تفشل فعلًا** فذلك عطل حقيقي لا نقص دليل: أصلحه أولًا ثم أثبت.

### 5) استثنِ بمهلة موثّقة
الاستثناء يحتاج: `fault_id · owner · reason · expiry · evidence`. بلا مهلة = لا استثناء. راجع `references/schema.md`.

### 6) شغّل المحرّك والحارس
```bash
python3 scripts/closure_round.py --apply
python3 scripts/closure_round.py --apply            # مرة ثانية: الفرق يجب أن يكون صفرًا
python3 scripts/check_closure.py --brain <BRAIN>    # المطلوب: مجتاز
python3 scripts/test_closure_gate.py                # اختبار عدائي: المرور الكاذب يجب أن يمنع
```

### 7) أصلح الجذور لا الأعراض
لكل عطل ظهر أثناء التحقق: **عَرَض · سبب جذري · إصلاح · درس · حاجز**. سجّلها فورًا:
```bash
python3 scripts/record_fault.py --brain <BRAIN> --axis system \
  --symptom "..." --cause "..." --fix "..." --barrier "تحقق حي: <أمر> → خرج 0"
```
ثم أعد التمرير 6. **ولا تُعمّم إصلاحًا على الشيفرة دون قياس قبل/بعد.**

### 8) أعد الفحص البنيوي وادفع
- **قابلية النقل:** لا مسار جذر مطلق في أي ملف تنفيذي؛ الجذر يُستنتج من `__file__` مع تجاوز `BRAIN_DIR`/`SITE_DIR`.
- **التماثل:** الشجرة المحلية = المستودع.
- **الدفع:** فرع ثم طلب دمج ثم دمج — لا دفع مباشر إلى الفرع الرئيسي.
- أي عطل يُكتشف في هذه المرحلة يُسجَّل ويُعاد التمرير، ولا يُعلن الاجتياز قبله.

## حلقة التحسين الذاتي (إلزامية بعد كل جولة)

1. كل عطل جديد يُسجَّل بسبب جذري + درس + حاجز (`record_fault.py`).
2. كل صنف عطل جديد يُضاف له **اختبار سلبي** في `test_closure_gate.py` يثبت أن الحارس يمنعه.
3. إن أفلت عطل من الحارس: **شدّد الحارس** ولا تُخفّف القاعدة لتُمرّره.
4. بعد الجولة: أعد التمرير المزدوج + الحارس + الاختبارات، وسجّل الأرقام الفعلية (صفوف · مغلق · مستثنى · فاشل).
5. شغّل مقيّم التشديد الذاتي:
```bash
python3 scripts/propose_tightening.py --brain <BRAIN>
```
   يستخرج أصناف الثغرات القابلة للعودة ويقترح لكل صنف اختبارًا سلبيًا جاهزًا للإدراج في `test_closure_gate.py`. أضِف المقترحات كلها — لا تتجاهل صنفًا لأن حالته الحالية صفر.

## الأنماط المرفوضة (أخطاء وقعت فعلًا)

| النمط | لماذا يفشل |
|---|---|
| تصديق خانة «الحالة» كما هي | يُظهر صفوفًا مغلقة بلا أي دليل |
| نسخ الدليل من خانة «الحالة الأصلية» | دليل لا يصف النتيجة |
| قصّ الدليل إلى 160 حرفًا | يقطع علامة النتيجة فيمنع الصف |
| مطابقة الدرس على بادئة «ك» وحدها | أرقام مبطّأة (`ك-09` ≠ `ك-9`) تُسقط التغطية |
| تمرير واحد فقط | لا يكشف الدروس المشتقة المتكرّرة |
| اعتبار «الفرق صفر» نجاحًا بلا تشغيل حيّ | الثبات ≠ الصحة |
| إصلاح عام في المولّد بلا قياس | يُغيّر مخرجات لم تُطلب |
| شرطة طويلة «—» في نصّ الإصلاح | تُقرأ كقاعدة «لم يبدأ» فيُخفَّض الصف |
| صف مغلق بلا كلمة «منفَّذ» في الإصلاح | يُشتقّ «بانتظار التحقق» |
