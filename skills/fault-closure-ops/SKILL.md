# تشغيل إغلاق الأعطال والدروس (Fail-Closed Closure Ops)

حوّل سجل الأعطال من «نصوص تُصدَّق» إلى «حالات مُشتقّة وأدلة قابلة لإعادة التشغيل».

## العقد الحاكم

[عقد الإغلاق المشترك](references/closure-contract.md) هو المصدر الوحيد لمخطط 12 عمودًا، واشتقاق الحالة، ودليل النتيجة، والاستثناءات، ومصفوفة التتبع، والثبات المزدوج، ورموز الفشل المغلق؛ تملك هذه المهارة الحارس والاختبار العدائي و`G048/Q012`.

## المسار القياسي (8 خطوات)

### 1) اجمع الواقع
```bash
python3 scripts/closure_round.py --brain <BRAIN> --dry-run   # ما ستُغيَّره
python3 scripts/check_closure.py --brain <BRAIN>             # الحالة الآن (متوقّع: منع)
```
اقرأ الملفين فعليًا: `audit/سجل-الأعطال-والثغرات.md` و`memory/learning-log.jsonl`. لا تعتمد أرقامًا من ملاحظة قديمة.

### 2) وحّد المخطط
حوّل الصفوف وفق [عقد الإغلاق المشترك](references/closure-contract.md) إلى 12 عمودًا بلا فقد نصّ، ثم اترك للمحرّك اشتقاق الأعمدة الأربعة الأخيرة.

### 3) اشتقّ الحالة
طبّق قواعد الاشتقاق ودليل النتيجة في العقد؛ لا تقرأ خانة «الحالة الأصلية» للحكم.

### 4) أضف دليلًا حيًّا لكل صف موروث أو مغلق قديم
```bash
python3 scripts/insert_live_evidence.py --brain <BRAIN> --map evidence.json
```
- شغّل لكل صف البوابة/الأداة المسمّاة في نصّه الآن، والتقط رمز الخروج.
- استخدم صيغة الدليل الحي في العقد، وضع الدليل أول الخانة بلا قصّ.
- إن ظهر أن الأداة تفشل فعلًا فذلك عطل حقيقي لا نقص دليل: أصلحه أولًا ثم أثبت.

### 5) استثنِ بمهلة موثّقة
طبّق حقول الاستثناء ومدته كما في العقد؛ الاستثناء لا يمنح إغلاقًا.

### 6) شغّل المحرّك والحارس
```bash
python3 scripts/closure_round.py --brain <BRAIN> --apply
python3 scripts/closure_round.py --brain <BRAIN> --apply            # مرة ثانية: الفرق يجب أن يكون صفرًا
python3 scripts/check_closure.py --brain <BRAIN>                    # المطلوب: مجتاز
python3 scripts/test_closure_gate.py                                # الاختبار العدائي
```

### 7) أصلح الجذور لا الأعراض
لكل عطل ظهر أثناء التحقق: **عَرَض · سبب جذري · إصلاح · درس · حاجز**. سجّلها فورًا:
```bash
python3 scripts/record_fault.py --brain <BRAIN> --axis system \
  --symptom "..." --cause "..." --fix "..." --barrier "تحقق حي: <أمر> → خرج 0"
```
ثم أعد التمرير. **ولا تُعمّم إصلاحًا على الشيفرة دون قياس قبل/بعد.**

### 8) أعد الفحص البنيوي
- **قابلية النقل:** لا مسار جذر مطلق في أي ملف تنفيذي؛ الجذر يُستنتج من `__file__` مع تجاوز `BRAIN_DIR`/`SITE_DIR`.
- **التماثل:** الشجرة المحلية = المستودع.
- أي عطل يُكتشف هنا يُسجّل ويُعاد التمرير، ولا يُعلن الاجتياز قبله.

## دورة التعلم والدفع

دورة التعلم اليومية، تصنيفاتها، `close_fault/verify_closure/loop_report`، وتحويل الدرس إلى تشديد ثم فرع وطلب دمج، تملكها [مهارة حلقة التعلم الذاتي](../self-learning-loop-ops/SKILL.md) و`D050`. لا تُعاد هنا؛ تبقى `record_fault.py` والحارس والاختبار العدائي ضمن هذه المهارة.
