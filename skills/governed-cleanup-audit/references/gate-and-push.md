# تسلسل البوابات وطريق الدفع والإغلاق

مرجع تشغيلي لمهارة `governed-cleanup-audit`. يُقرأ عند إثبات أن التنظيف لم يكسر النظام.

## تسلسل التحقق المعتمد

يُشغَّل بهذا الترتيب، ويُسجَّل رمز خروج كل بوابة في جدول واحد يُدرج في التقرير:

| # | البوابة | الدلالة |
|---|---|---|
| 1 | `tools/runbook.py verify` | كل خطوة مربوطة، وكل ملف متصل بخطوة أو قسم أو وثيقة |
| 2 | `validators/check_asset_floor.py` | لا نقص ولا اختفاء في أصول حاكمة، ولا قرارات بلا سبب |
| 3 | `validators/check_project_skills.py` | مهارات المشروع متطابقة عبر الأسطح |
| 4 | `validators/check_skills_integrity.py` | نسخ المهارات على الأسطح صحيحة وغير مختصرة |
| 5 | `validators/check_closure.py` | سجل الأعطال والدروس مغلق بلا فاشل |
| 6 | `validators/check_backup_parity.py --mode strict` | المستودع يعكس الشجرة المحلية كاملة |
| 7 | `validators/check_secrets.py --root <المستودع>` | لا سرّ داخل النطاق |
| 8 | `tools/preflight_check.py <التاريخ>` | ما قبل التشغيل سليم |
| 9 | `tools/final_gate.sh` | البوابة النهائية للتقارير |
| 10 | `tests/run_checks.sh` | حزمة الاختبارات كاملة |

ترتيب التنفيذ المرِحلي: شغّل البوابات على الخادم أولًا، ثم ادفع، ثم أعد البوابات التي تعتمد على المستودع (6 تحديدًا) حتى يخرج «مطابق».

## طريق الدفع

1. فروق الشجرة تُدفع عبر **خطوة النسخة الاحتياطية داخل المانيفست**، وهي تنشئ فرعًا ثم طلب دمج. لا دفع مباشر إلى الفرع الرئيسي.
2. إذا رفضت الأداة نسخ **ملفات شيفرة** منحرفة بين الخادم والمستودع، فالمسار الصحيح: دفع الشيفرة إلى المستودع أولًا (فرع وطلب دمج)، ثم تشغيل خطوة التطبيق/المزامنة، ثم إعادة خطوة النسخة الاحتياطية.
3. بعد الدمج، أعد فحص التماثل. إن بقي «زائد في المستودع» لمسار استُثني من المقارنة، فذلك يعني أن المستودع يحمل نسخًا زائدة يجب أن تُدفع شجرة الحذف لإزالتها.
4. أغلق طلبات الدمج المتعارضة كمُستبدَلة بطلب أحدث، بلا دمج قسري.

## قالب جدول الإثبات (للنسخ في التقرير)

| البوابة | النتيجة |
|---|---|
| حاجز أرضية الأصول | سليم / منع + التفصيل |
| تطابق الوثيقة والمانيفست | رمز 0 |
| ربط المهارات | عدد العوائق |
| إغلاق الحلقة | مفحوص · مغلق · فاشل |
| تماثل النسخة الاحتياطية | مطابق / انحرافات مسمّاة |
| حزمة الاختبارات | نجح · فشل |
| خطوة النسخة الاحتياطية في المانيفست | رمز الخروج |

## قالب تقرير الجولة

1. **ما جرى قياسه:** الأسطح وأعداد الملفات والأدوات.
2. **الحصيلة الصريحة:** ميت · مشروط · لا يُحذف — بالأرقام.
3. **ما نُفِّذ:** جدول المجموعات والأعداد والأحجام، ومسار الحجر وأمر الاسترجاع.
4. **الإثبات:** جدول البوابات أعلاه + أرقام طلبات الدمج.
5. **الباقي المشروط:** سؤال قرار واحد على المالك مع توصية.
6. **ملاحظات حوكمة ظهرت:** تعارضات معلنة أو مسارات معلنة لا تعمل.
