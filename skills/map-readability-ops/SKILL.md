# ضمان وضوح الخريطة

## متى تستخدم

قبل أي نشر لتقرير يحوي خريطة، وبعد أي تعديل على مولّد الخريطة أو أنماطها، وعند شكوى «الخريطة غير واضحة». لا تُستخدم لتوليد بيانات جغرافية جديدة؛ تُستخدم لقياس سطح العرض وحدوده الدنيا.

## معايير القبول (مقيسة، لا مقدَّرة)

| المعيار | الحد | كيف يُقاس |
|---|---|---|
| أصغر نص مرئي | ≥ 12px CSS | `getComputedStyle` لكل `<text>` مرئي داخل SVG الخريطة |
| فصل العلامات | ≥ 22px على الشاشة بعد التصغير | مسافة مراكز `.mp-event` عبر `getBoundingClientRect` |
| معرّف الواقعة | كل علامة تحمل معرّفها نفسه في المفتاح | تطابق نصوص الشارات مع `.lg-num` |
| حجب عنصر تنفيذي | صفر | ارتفاع الرأس اللاصق قبل/بعد التمرير، ولا تغطية لمنتصف الخريطة |
| تمرير أفقي غير مقصود | صفر على مستوى الصفحة | `scrollWidth - clientWidth` لجذر المستند |
| تباين النص | ≥ 4.5:1 | حساب التباين لأزواج اللون الفعلية |
| قراءة على 390 بكسل | نعم | عرض SVG فعلي ≥ 640px داخل إطار بسحب أفقي معلن |

## الخطوات

1. **اقرأ البنية قبل التعديل**: مولّد الخريطة (رسم العلامات، المفتاح، اللوحة) وملف الأنماط الذي يستهلكه. تحقّق من تطابق أصناف HTML مع محددات CSS — الاختلاف الصامت (مثل `hmap` مقابل `hmap-panel`) يُلغي الحشو وقواعد الشاشة دون أي خطأ ظاهر.
2. **شغّل القياس**: `python3 scripts/measure_map_readability.py --url <رابط أو file://> --out <مجلد اللقطات>` ثم اقرأ JSON الناتج.
3. **افشل مغلقًا**: إن نزل أي نص تحت 12px، أو تقاربت العلامات تحت 22px، أو ظهر تمرير أفقي على مستوى الصفحة، أو غابت معرّفات الوقائع، فأصلح ثم أعد القياس. لا تنشر بتحذير.
4. **الجوال**: لا تُصغّر الخريطة إلى ما دون مقياس القراءة. الحل المعتمد: إطار بسحب أفقي (`overflow-x:auto`) مع `min-width` يضمن ≥640px، ورفع أحجام النص داخل `viewBox` بما يعادل ≥12px بعد التصغير، وإظهار سطر إرشادي للسحب.
5. **العناقيد**: الوقائع المتقاربة جغرافيًا تُرسم شارة واحدة بعدّاد وقائمة معرّفات، مع خط إسناد إلى مركز المنطقة — لا علامات متراكبة ولا وقائع مفقودة.
6. **الترجمة**: أي نص عربي جديد في سطح الخريطة يُضاف إلى معجم الترجمة في القاموس الصحيح (`entries` لا الجذر)، وإلا يفشل البناء مغلقًا عند مطابقة النسخة الإنجليزية.
7. **أعد القياس حيًّا** على الرابط المنشور (مع كسر التخزين المؤقت) قبل إعلان النجاح، واحفظ اللقطات كدليل.

## مبادئ ثابتة

- الإسقاط لا يُغيَّر لحل مشكلة وضوح: تحقّق أولًا من تساوي كم/بكسل أفقيًا ورأسيًا. المشكلة عادةً في الحيز والتسلسل لا في الهندسة.
- رفع دقة الصورة لا يعالج محتوى متجهيًا؛ الحل في الأحجام والحيز.
- لا طبقات بلا مصدر رسمي مؤرخ (أنابيب · كابلات · مضلعات تحذير).
- لا اعتماد على اللون وحده لحالة الواقعة؛ المعرّف والنص يحملان المعنى.
- كل عطل يُسجَّل في سجل الأعطال بصيغة أعمدة ثابتة، ويُغلق بقياس قبل/بعد، ويُمنع رجوعه بحارس آلي.

## أدوات

- `scripts/measure_map_readability.py`: قياس حاسوب وجوال (نص · علامات · تجاوز · شارة · عنقود) مع لقطات شاشة.
