# التحقق من عقد الأداة والنسخ المكررة

طبّق هذه المهارة كحاجز سابق للتشغيل. لا تعدّل ملفات المشروع؛ اقرأها، افحص عقدها، ثم شغّلها عبر قارئ الخروج الذي يحفظ المخرج الحرفي. افصل هذه المهمة عن إغلاق العطل وتوثيقه في [fault-closure-ops](../fault-closure-ops/SKILL.md)، وعن حكم أسطح التقرير والطباعة في [report-surface-policy-ops](../report-surface-policy-ops/SKILL.md).

## قاعدة الفشل المغلق

- اقرأ `--help` أو عقد `argparse` قبل تمرير أي وسيط.
- اقرأ رمز الخروج **مع المخرج الحرفي**؛ لا تستنتج المعنى من الرمز وحده.
- اعتبر رمزًا غير متوقع سببًا للتوقف: اقرأ المخرج، ثم أعد فحص العقد، ولا تتابع التسليم.
- لا تعتبر رمز `2` منعًا قبل التحقق من أن الاستدعاء صحيح وأن الوسائط معروفة؛ قد يكون خطأ استخدام.
- لا تُصلح عيبًا في ملف المشروع ضمن هذه المهارة؛ سجّل المسار ورقم السطر في التقرير، وأحِل الإصلاح إلى مالك المشروع.

## المسار الإلزامي

1. حدّد الأداة والملف الذي ستقرأه، وحدّد ما إذا كان الاستدعاء للقراءة فقط.
2. افحص العقد قبل التشغيل:
   ```bash
   python3 scripts/cli_contract.py --tool /path/to/tool.py -- --known value
   ```
   يستخرج السكربت `argparse/add_argument` من AST دون تشغيل العملية. إذا تعذر الاستخراج، يستعمل `--help` فقط بمهلة قصيرة.
3. شغّل الأمر عبر قارئ الخروج:
   ```bash
   python3 scripts/exit_code_read.py \
     --contract-tool /path/to/tool.py -- \
     python3 /path/to/tool.py --known value
   ```
   اترك الفاصل `--` واضحًا، ولا تمرر الأمر عبر shell غير مطلوب.
4. افحص الملف قبل/بعد النسخ أو الترقيع:
   ```bash
   python3 scripts/duplicate_scan.py /path/to/copied_or_patched.py
   ```
   أوقف العملية إذا وجدت تعريفًا أو كتلة أو استيرادًا مكررًا، أو إذا سبق التطبيع تقسيم الأسطر.
5. اقرأ آخر 30 سطرًا كما طبعها القارئ، وطابقها مع العقد. سجّل النتيجة الخام، لا تلخّصها بدلًا منها.
6. بعد الاستخدام، أضف درسًا إلى `memory/learning-log.jsonl`، واقترح حاجزًا، وشغّل الحاجز مرة أخرى لإثبات أنه قائم.

## قرار رمز الخروج

استخدم التصنيف المقترح فقط كإشارة تشغيلية: `0` نجاح، `2` منع/استخدام خاطئ، `10` يحتاج تدخلًا، وأي قيمة أخرى عطل. لا يغيّر التصنيف قاعدة الفشل المغلق: **رمز غير متوقع = توقف واقرأ المخرج**. راجع [جدول الرموز والعقود](references/exit-codes-and-contracts.md) عند التعامل مع بوابات المشروع.

## النسخ والترقيع

عند نسخ ملف بين المشروع والمهارة أو ترقيع ملف قائم، نفّذ `duplicate_scan.py` قبل تشغيله وبعده. ميّز بين التعريفين في النطاق نفسه والتعريفين في نطاقين مختلفين. يطبع الفاحص التعريف الأخير الذي يغلب فعليًا في النطاق نفسه، مع التنبيه إلى أن شروط التنفيذ قد تمنع الوصول إليه. اعتبر تحذير `norm` قبل `splitlines` عيبًا بنيويًا يحتاج مراجعة؛ لا تعالجه بتطبيع يدمج حدود الأسطر.

## حلقة التعلم الذاتي ومنع التكرار

بعد **كل استخدام**:

1. أضف سطر JSONL واحدًا إلى `memory/learning-log.jsonl` بهذه الحقول الإلزامية: `ts`, `entry_kind`, `cls`, `status`, `symptom`, `cause`, `fix`, `barrier`.
2. سجّل العرض كما ظهر، والسبب المؤيد بالمخرج أو AST، والإصلاح/الإجراء، ثم اقترح حاجزًا آليًا محددًا مثل `cli_contract.py` قبل التشغيل أو `duplicate_scan.py` عند النسخ.
3. تحقّق من قيام الحاجز بتشغيله الآن، وأرفق رمز خروجه ومخرجه الحرفي في دليل العمل. إذا تعذّر التحقق، اجعل الحالة `blocked` ولا تعلن الإغلاق.
4. امنع التكرار: قبل قبول ملف جديد، أعد فحص العقد والتكرار، وطابق نمط العطل مع `cls` في السجل. إذا ظهر الصنف نفسه، أوقف التشغيل وشدّد الحاجز بدل تجاهل التحذير.

مثال سجل صحيح (استبدل القيم بما وقع فعلًا):

```json
{"ts":"2026-10-28T22:00:00+03:00","entry_kind":"lesson","cls":"contract-unknown-argument","status":"verified","symptom":"رمز 2 بعد تمرير وسيط غير معروف","cause":"الاستدعاء خالف عقد argparse","fix":"إزالة الوسيط وإعادة فحص --help","barrier":"cli_contract.py قبل كل تشغيل؛ تحقق: خرج 0"}
```

## الموارد

- `scripts/cli_contract.py`: استخرج العقد، الخيارات، المطلوبات، الرموز المعلنة، وحذّر من الوسائط غير المعروفة.
- `scripts/duplicate_scan.py`: اكشف تعريفات الدوال/الأصناف، الكتل، والاستيرادات المكررة، ونمط التطبيع قبل تقسيم الأسطر.
- `scripts/exit_code_read.py`: شغّل أمرًا محددًا، واطبع الرمز وآخر 30 سطرًا والتصنيف المقترح مع تنبيه العقد.
- `references/exit-codes-and-contracts.md`: اقرأه عند تفسير رموز المشروع؛ لا تقرأ رمزًا بلا مخرجه.
- `references/evidence.md`: راجع التشغيل الحي المثبت لهذه المهارة والبوابتين المرجعيتين.
- `memory/learning-log.jsonl`: أضف إليه بعد كل استخدام وفق حلقة التعلم أعلاه.
