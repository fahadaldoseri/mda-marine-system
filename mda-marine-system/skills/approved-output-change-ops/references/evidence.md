# بناء الدليل الحي

## الحزمة الدنيا

لكل جولة احفظ:

1. الأمر الكامل كما نُفّذ، مع التاريخ.
2. المخرج الكامل و`return_code` لكل بوابة.
3. `sha16` لـ CSS المقفل وprofile وPDF المقاس.
4. قياسات قبل/بعد: صفحات، تعبئة، فجوات، الخريطة، تصفير المتن، والأسطح المغطاة.
5. معاينة بصرية للصفحة أو PDF مع اسم الملف ومصدره.
6. قرار المالك عند تغيير بصمة أو حد، وسجل `from/to/reason/approved_by/evidence/date`.

`gate_evidence.py` يكتب `evidence.json` مع هذه البصمات والمخرجات، و`evidence.txt` بجدول `command | output | status` وتفصيل كل مخرج.

## تشغيل البوابات

```bash
python3 scripts/gate_evidence.py \
  --brain /tmp/run/brain \
  --frozen /tmp/run/brain/templates/approved-pdf/print-css-frozen.css \
  --profile /tmp/run/brain/templates/approved-pdf/print-profile.json \
  --date 2026-10-28 --pdf /tmp/run/final.pdf --page /tmp/run/report.html
```

النجاح لا يعني `rc=0` فقط؛ راجع نص `PASS`، البصمات، ووجود الملفات الناتجة. أي بوابة ناقصة أو انهيار أو مخرج فارغ = دليل غير مكتمل ومنع.

## حدود استخراج العربية

قد يعكس `pdftotext` ترتيب الحروف العربية، يفصل لام-ألف، يضيف مسافات قبل الترقيم، أو يمرر علامات اتجاه خفية. لذلك:

- لا تقارن نثر العربية في PDF مقارنة حرفية.
- استخدم `check_print_quality.py` لقياس إحداثيات PDF وكتلة الخريطة.
- استخدم `check_pdf_format.py` لمطابقة بنية الأقسام والصفحات والبصمة.
- أثبت ارتباط PDF بالمصدر عبر رموز لاتينية ثابتة أو رموز البلاغ، لا عبر إعادة بناء النثر العربي.
- سجّل `pdftotext -layout` كقرينة لا كبديل للمعاينة البصرية.

## معاينة بصرية

حوّل PDF إلى PNG بـ`pdftoppm -r 150 -png final.pdf out/page`، راجع الغلاف، صفحة الخريطة، أسوأ صفحة تعبئة، والصفحة الأخيرة، ثم اذكر أسماء PNG في الدليل. لا تستنتج من صورة قديمة؛ افحص زمن الملف أو اربطه ببصمة PDF.
