# ضبط تغيير المخرج المقفل

## ما يُقفل

اقفل كل ما يكوّن بصمة أو قرارًا مرئيًا للقارئ: `print-css-frozen.css`، `print-profile.json`، قالب PDF، سياسة ترتيب/حجب الأقسام، قاموس المفردات الحاكم، ومخطط العلامة. خزّن البصمة الحالية، تاريخ الاعتماد، هوية المعتمد، ومرجع دليل حي.

## ما يُقاس قبل/بعد

- **PDF الشكل:** عدد الصفحات، وجود الأقسام، الحجب، مفتاح الخريطة، التذييل، متوسط التعبئة، أقل تعبئة، الفجوات الداخلية، وعناوين الأقسام اليتيمة.
- **جودة الطباعة:** كتلة الخريطة هندسيًا على PDF نفسه، وتجمّع الحافة اليسرى لأسطر المتن لإثبات التصفير. لا تستبدل القياس الهندسي باستخراج عربي من `pdftotext`.
- **الأسطح:** المتن، JSON الواجهة، الرسالة، صفحات التقرير/المصادر/الرئيسية/الإضافات، وPDF بإسناد لاتيني/رموز ثابتة عند الحاجة.
- **القفل:** `sha256` مختصر 16 محرفًا قبل وبعد، بصمة PDF، وبصمة profile.

## القرار

نفّذ القياس وإصلاح العطل الداخلي والتوثيق تلقائيًا. ارفع إلى المالك أي تغيير في حد، نطاق، سياسة، قاموس، مخطط، أو CSS مع أثر قبل/بعد.

لا تفعّل `--allow-css-change` كحل. إذا تغير CSS بسبب إصلاح مشروع، أوقف الإصدار، اجمع الدليل، ثم استخدم `freeze_adopt.py` بعد موافقة المالك فقط. يجب أن توجد نسخة `SUPERSEDED-<old_sha>.css`، وأن يطابق `print_css_sha16` البصمة الجديدة، وأن يحمل `changes` التاريخ والسبب والمعتمد والدليل.

## ترتيب آمن

1. انسخ الملفات إلى مساحة مؤقتة.
2. قِس النسخة قبل التغيير.
3. طبّق أصغر إصلاح يزيل السبب.
4. قِس الناتج النهائي وأعد البوابات.
5. راجع المالك إذا تغير القفل أو قرار القارئ.
6. اعتمد البصمة وسجّلها فقط بعد القرار.
7. نفّذ حلقة التعلم والتشديد.
