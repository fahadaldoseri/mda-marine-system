# عقد أسطح بوابة تغطية الأسلوب

## الأسطح الثمانية ومواضعها

| السطح | المصدر | ملاحظة القياس |
|---|---|---|
| المتن (التقرير) | `reports/<date>-sectioned.md` | نص عربي مباشر |
| ملف الواجهة | `web/meta/<date>.json` | **تُسطّح قيمه إلى نص** قبل الفحص |
| رسالة تلغرام | `logs/tg-digest-<date>.html` | يُبنى من المتن والواجهة قبل الفحص |
| صفحة التقرير | `seawatch/dist/reports/<date>.html` | يُجرَّد HTML |
| صفحة المصادر | `seawatch/dist/sources.html` | يُجرَّد HTML |
| الصفحة الرئيسية | `seawatch/dist/index.html` | يُجرَّد HTML |
| صفحة إضافات | `seawatch/dist/additions.html` | يُجرَّد HTML |
| PDF | `seawatch/dist/reports/pdf/<date>.pdf` | مستثنى بقرار المالك عند تعطيل الطباعة |

## الحكم ورموز الخروج

- السطح مقبول إذا كان رمز بوابة الأسلوب 0 ورمز بوابة الصياغة 0 أو 1.
- رمز 2 لأي سطح = مانع، ولا يُسلَّم التقرير.
- رموز الأداة: 0 كل الأسطح مغطاة · 2 سطح غير مغطى أو مانع · 70 انهيار.

## مراجع الإصلاح السريع

- لفظ ممنوع في JSON: ابحث عنه في المراجع (`appendices/*.json`) لا في ملف الواجهة فقط.
- جملة متكررة: اجعل النص فريدًا داخل الجملة نفسها (لا بعد فاصل `؛` لأن التقسيم يقع على الفاصل).
- أرقام ورموز تُجرَّد عند التطبيع، فلا تعتمد عليها لجعل الجملة فريدة.
