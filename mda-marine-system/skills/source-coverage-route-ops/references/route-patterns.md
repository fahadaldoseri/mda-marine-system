# أنماط المسارات الآلية — مرتَّبة بترتيب التجربة

جرّب بالترتيب. لا تُسجّل مسارًا لم تختبره بمخرج أمر.

| # | النمط | مثال حقيقي | علامة النجاح | متى يفشل |
|---|---|---|---|---|
| 1 | تغذية RSS/Atom رسمية | `https://news.usni.org/feed` | `parse()` يعيد ≥3 عناصر | حجب Cloudflare (403) |
| 2 | واجهة WordPress العامة | `https://www.understandingwar.org/wp-json/wp/v2/posts?per_page=10` | 10 عناصر بعناوين وتواريخ | موقع ليس على WordPress |
| 3 | واجهة JSON رسمية | `https://shipnext.com/api/v2/fleet/public/<IMO>` | سجل واحد بحقول الاسم/الرمز | السجل مغلّف في `data` ⇒ افتح الغلاف |
| 4 | جدول Markdown رسمي | سجل حوادث IMO | ≥3 صفوف حقيقية | جدول تنقّل بصفوف قليلة |
| 5 | حساب X عبر الصفحة العامة | `https://x.com/UK_MTO` | JSON مُهرَّب داخل HTML ⇒ منشورات بتاريخها | الحساب محذوف (404) |
| 6 | تلغرام عبر العرض العام | `https://t.me/s/<channel>` | رسائل فعليّة | قناة خاصة |
| 7 | وسيط قراءة | `https://r.jina.ai/<url>` | نصّ الصفحة | الوسيط نفسه محجوب (403) |
| 8 | وسيط CORS | `https://api.allorigins.win/raw?url=<encoded>` | حمولة كاملة | `IncompleteRead` أو 522 |
| 9 | أرشيف الويب | `https://web.archive.org/web/2026/<url>` | XML للتغذية | يعيد صفحة Wayback HTML ⇒ لا لقطة |
| 10 | مسار متصفح ثابت (browser route) | تشغيل Playwright لاجتياز التحدي | HTML نهائي بعد انتظار الشبكة | التحدي لا يُجتاز |

## قواعد القياس
- لكل محاولة سجّل: الرمز · الحجم بالبايت · عدد العناصر · أول عنوان.
- «فشل» ليست كلمة واحدة: ميّز **حجب** (403/تحدي) عن **فراغ محتوى** عن **بنية غير مفهومة**. الإصلاح يختلف لكل حالة.
- قبل إعلان تعذّر مصدر: تأكد أن العدّ تمّ لكل مساراته، وأن أي واجهة لم تُرفض بسبب غلاف غير مفتوح.

## أنماط المستخرجات (الجهة الأخرى من المسار)
| الواجهة | الدالة | شرط القبول |
|---|---|---|
| RSS/Atom | `parse()` | ≥3 عناصر بعنوان ورابط |
| wp-json | `extract_wp_json` | `title.rendered` بعد تنقية HTML |
| سجل JSON | `extract_vessel_api` | يُقبل السجل الواحد بعد التحقق من حقوله |
| جدول Markdown | `extract_markdown_table` | ≥3 صفوف حقيقية |
| صفحة عامة | `extract_proxy_text` | روابط وعناوين حقيقية |

**تحذير دائم:** أي `except Exception` في المستخرجات يُخفي `NameError` و`AttributeError` فيظهر عطل برمجي كأنه «انعدام محتوى». اضيّق الاستثناء إلى `json.JSONDecodeError` ونحوه، وأضف اختبارًا سلبيًا.
