# تشغيل نزاهة فروع بطاقات التقرير

## الغاية والحدود

طبّق هذه المهارة عندما تكون البطاقة واجهة مشتقة من أقسام تقرير، ويجب أن يبقى كل فرع رابطًا إلى قسمه وعدّاده. تملك هذه المهارة **عقد فرع البطاقة** فقط؛ لا تعيد تعريف مالكي المحاور التالية:

- أمانة المصدر/السجل/المولّد/السطح: `report-content-fidelity-ops`.
- نموذج التهديد والقطاعات الأربعة: `threat-zone-card-ops`.
- عقد CLI وقراءة رموز الخروج: `tool-contract-check-ops` و`argv-tools-safe-probe-ops`.
- النشر والتحقق الحي: `site-publish-live-verify-ops`.
- تماثل الخادم/المستودع والفرع: `server-repo-parity-ops`.
- سجل العطل والحارس وحلقة التعلم: `fault-closure-ops` و`self-learning-loop-ops`.

الإحالات الإلزامية عند عبور هذه الحدود هي [server-repo-parity-ops](../server-repo-parity-ops/SKILL.md)، و[fault-closure-ops](../fault-closure-ops/SKILL.md)، و[site-publish-live-verify-ops](../site-publish-live-verify-ops/SKILL.md)، و[argv-tools-safe-probe-ops](../argv-tools-safe-probe-ops/SKILL.md). لا تعِد هذه المهارة تنفيذ ملكية أي إحالة.

لا تُسقط شرطًا لأن بيانات الأرشيف مشروعة، ولا تعدّل حالة الجولة اليومية أو ملفًا يديره المنسّق.

## العقد غير القابلة للتفاوض

1. **مصدر واحد لكل عدّاد:** قِس عدّاد كل فرع من قسمه الهدف نفسه في الإصدار الحالي. لا تستخدم قائمة وسيطة أو رقمًا مكتوبًا في المتن إذا اختلف موضع الحقيقة. سجّل مسار المصدر، المعرّف، والعدد قبل عرضه.
2. **مرساة مشتقة:** اشتق `#sec-NN` والمراسي الفرعية مثل `#sec-04-sub-02` من عنوان القسم الفعلي وترتيبه وقت البناء بعد التطبيع، لا من رقم ثابت في القالب أو رابط قديم. افحص أن هدف الرابط يطابق عنوان الفرع المشتق.
3. **فشل مغلق:** أخرج رمز `2` عند اختلاف عدّاد ومصدره، أو عدم مطابقة هدف الرابط لعنوان الفرع، أو صياغة عدد عربية غير سليمة مثل «2 صفوف»، أو وجود حروف لاتينية متصلة داخل صف بطاقة النسخة العربية. لا تحوّل المنع إلى تحذير.
4. **تضييق النطاق:** طبّق فحص الحروف اللاتينية على صفوف البطاقة العربية فقط. لا تحذف الشرط بسبب أسماء سفن لاتينية مشروعة في الأرشيف؛ ضيّق المحدِّد إلى سطح البطاقة وسجّل الاستثناء الوظيفي.
5. **مطابقة EN:** قارن عنوان النسخة الإنجليزية بخريطة `glossary.json` أو بتطبيع المسافات والترقيم وحالة الأحرف. لا تستخدم مساواة حرفية ضيقة عندما تكون الترجمة المعتمدة مختلفة نصيًا.
6. **حاجز الفرع قبل النشر:** لا تنشر تغييرات من فرع موضوعي. لا تُدخل أي تغيير إلى `main` بدفع مباشر: اعمل على فرع، افتح طلب دمج، راجع، ثم ادمج. بعد الدمج حدّث `main`، وتحقق أنه الفرع الحالي قبل النشر.
7. **قياس حي بعد النشر:** أثبت ظهور العناصر الجديدة، وتطابق بصمة PDF الحي مع المحلي، وأن `7 ≤ pages ≤ 12` حرفيًا؛ أي PDF خارج هذا المجال مانع. طبّق مصفوفة المسارات والتفاصيل من `site-publish-live-verify-ops`.
8. **رفض المعاملات المجهولة:** افحص جميع المعاملات قبل أي أثر جانبي. `--help` قراءة فقط، وكل معامل غير معروف يخرج برمز غير صفري قبل إنشاء نسخة احتياطية أو كتابة ملف أو اتصال نشر. لا تعتبر نجاح التحليل الساكن بديلًا عن اختبار حي.
9. **حلقة التعلم الذاتي:** كل عطل ينتج صف 12 عمودًا في سجل الأعطال، ودرسًا مطابقًا، وحاجزًا آليًا، واختبارًا سلبيًا. نفّذ `closure_round --apply` ثم `check_closure` مرتين، وحدّث هذه المهارة عند تكرار النمط؛ لا تقل «مغلق» بلا مخرجات ورموز خروج. تملك [fault-closure-ops](../fault-closure-ops/SKILL.md) الإغلاق ويمتلك [self-learning-loop-ops](../self-learning-loop-ops/SKILL.md) الدفع والتشديد.

## سير العمل

### 1. ثبّت النطاق والمالكية

اقرأ مصدر الأقسام، مولّد البطاقة، `glossary.json`، البوابة، واختبارات السطح. افصل أعطال البطاقة عن أمانة المحتوى العامة وعن نموذج التهديد. قِس الحالة قبل التغيير، ولا تعدّل ملفات الحالة أو السجلات التشغيلية التي يملكها المنسّق.

### 2. ابنِ بيانات الفروع

لكل فرع، خزّن بنية مماثلة:

```json
{
  "branch_id": "b-02",
  "source_section": "sections/04/sub-02",
  "heading": "العنوان الفعلي وقت البناء",
  "count": 5,
  "anchor": "#sec-04-sub-02"
}
```

اشتق `anchor` من `heading` والترتيب الحالي في خطوة البناء نفسها. بعد إعادة ترتيب قسم، أعد البناء ثم افحص الروابط؛ لا تصلح HTML النهائي يدويًا.

### 3. افحص البطاقة العربية والإنجليزية

- طابق كل `count` مع القسم المشار إليه، ثم طابق العدد الظاهر مع القيمة المشتقة.
- افحص صياغة العدد العربية بعقد اللغة المعتمد؛ ارفض «2 صفوف» بدل الصياغة العربية السليمة.
- افحص الحروف اللاتينية في صفوف البطاقة العربية فقط، مع السماح بما يحدده المعجم للرموز أو الاختصارات المعتمدة.
- افحص هدف الرابط والعنوان بعد تطبيع ثابت.
- في EN استخدم `glossary.json` أو التطبيع، ثم أثبت خريطة `heading → anchor` بدل المقارنة الحرفية.

### 4. أثبت الفشل المغلق

شغّل اختبارًا سالبًا مستقلًا لكل شرط: بدّل عدّادًا، اربط فرعًا بـ`#sec-04` مع بقاء هدفه `#sec-04-sub-02`، أدخل «2 صفوف»، وأدخل حروفًا لاتينية متصلة في صف عربي. يجب أن يخرج الحارس `2` في كل حالة. اختبر المعامل المجهول على نسخة اختبارية، وتحقق من عدم تغيّر الملفات قبل/بعد. ثم أعد الحالة السليمة وأثبت الخروج `0`.

### 5. احمِ الفرع والنشر

```bash
git branch --show-current                 # يجب أن يكون main قبل النشر فقط
git status --short
git log -1 --oneline
```

التغيير نفسه يمرّ عبر `feature/card-branch-integrity-ops` ثم طلب دمج ثم merge. بعد الدمج شغّل بناء البطاقة والبوابات، ثم تحقق من الفرع `main`. لا تجعل أمر النشر ينفذ `git push` إلى `main` تلقائيًا. بعد قرار النشر، طبّق [site-publish-live-verify-ops](../site-publish-live-verify-ops/SKILL.md) لإثبات العناصر الجديدة، `local_pdf_sha256 == live_pdf_sha256`، و`7 ≤ pages ≤ 12`؛ أي فرق أو إصدار قديم أو عدد صفحات خارج المجال يمنع التسليم.

### 6. أعد تماثل المهارات وأغلق الحلقة

أدخل المهارة إلى المرآة عبر الفرع وطلب الدمج فقط وفق [server-repo-parity-ops](../server-repo-parity-ops/SKILL.md)، ثم شغّل D070 على النسخة المدمجة. سجّل أعداد الشجرة المحلية والمستودع، المفقود والزائد والمختلف، والروابط، مع الأمر والمخرج الخام والرمز. عند عطل:

```bash
python3 <مالك-الإغلاق>/scripts/closure_round.py --brain <BRAIN> --apply
python3 <مالك-الإغلاق>/scripts/check_closure.py --brain <BRAIN>
python3 <مالك-الإغلاق>/scripts/check_closure.py --brain <BRAIN>
```

إذا تطلب عقد المالك ثباتًا إضافيًا أو اختبارًا عدائيًا، نفّذه أيضًا. حدّث المهارة بحاجز قابل للتشغيل عند تكرار الصنف، ولا تخفّض عتبة البوابة. قبل تشغيل أي CLI أو أداة ذات أثر جانبي، أحِل إلى [argv-tools-safe-probe-ops](../argv-tools-safe-probe-ops/SKILL.md) ثم [tool-contract-check-ops](../tool-contract-check-ops/SKILL.md).

## أدلة الجولة المرجعية

الأمثلة القابلة لإعادة التشغيل من جولة 2026-10-31 موجودة في [references/evidence-contract.md](references/evidence-contract.md): بطاقة عربية `6` بنود، بطاقة التحذيرات «تحذيران»، بطاقة القطاعات `5` بنود، المرساة `#sec-04-sub-02`، وPDF بين `7` و`12` صفحة. اختبار السلبية يخرج `2` عند كسر أي عقد، وتُذكر بصمة PDF دون قيمة سرية أو بيانات تشغيل حساسة.

## صيغة التسليم

أبلغ عن: اسم المهارة ومسار `SKILL.md`، الملفات المنشأة، أمر `quick_validate.py` ومخرجه الحرفي ورمزه، نتيجة فحص التداخل، رقم طلب الدمج وSHA، أمر D070 ومخرجه وأعداده ونتيجته، وكل فحص لم يُشغّل وسبب التعذر. لا تذكر «تم» أو «اجتاز» اعتمادًا على نص قديم أو رمز منفرد.


## حدود المهارة
هذه المهارة لا تنشر الموقع أو تتحقق من انتشاره؛ المهارة الجارة `parity-and-publish-ops` تفعل ذلك.
