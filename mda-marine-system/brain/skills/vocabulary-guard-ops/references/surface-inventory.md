# جرد الأسطح — ما يراه القارئ فعلًا

جدول محتويات: [قاعدة الحصر](#قاعدة-الحصر) · [الأسطح السبعة](#الأسطح-السبعة-نموذج-تقرير-يومي) · [وصف السطح](#وصف-السطح-json) · [الأسطح المشتقة](#الأسطح-المشتقة) · [PDF](#pdf)

## قاعدة الحصر
السطح = كل مخرَج يصل القارئ بنصّ عربي: متن الإصدار، ملف الواجهة، ملخص المراسلة، صفحة الإصدار، صفحة المصادر، الصفحة الرئيسية، وPDF. أي مخرَج جديد يُضاف إلى الوصف، وإلا صار «سطحًا خارج البوابة» وهو عطل لا ملاحظة.

## الأسطح السبعة (نموذج: تقرير يومي)
| السطح | النوع | الملف |
|---|---|---|
| المتن (التقرير) | text | `reports/<DATE>-sectioned.md` |
| ملف الواجهة (القاموس وبطاقة القرار) | json | `web/meta/<DATE>.json` |
| رسالة المراسلة | html (مشتق) | `logs/tg-digest-<DATE>.html` |
| صفحة الإصدار | html | `<SITE>/dist/reports/<DATE>.html` |
| صفحة المصادر | html | `<SITE>/dist/sources.html` |
| الصفحة الرئيسية | html | `<SITE>/dist/index.html` |
| PDF | pdf (إسناد) | `<SITE>/dist/reports/pdf/<DATE>.pdf` |

## وصف السطح (JSON)
```json
{
  "label": "رسالة المراسلة",
  "kind": "html",
  "path": "brain/logs/tg-digest-2026-10-27.html",
  "derive": ["brain/tools/make_tg_digest.py", "--date", "2026-10-27"]
}
```
- `kind`: `text` | `json` | `html` | `pdf`.
- `derive`: أمر البناء الذي يُشغَّل **قبل** الفحص لهذا السطح.
- `attest`: (لـPDF) مسار نص الإصدار الذي تُستخرج منه إشارات الإسناد.

## الأسطح المشتقة
كل ما يُبنى من غيره (ملخص المراسلة، صفحة إصدار، PDF) يُبنى قبل الفحص ولا يُخزَّن كحقيقة مُحكَّمة. تخزينه كحقيقة يُنتج مانعًا كاذبًا لليوم الجديد.

## PDF
لا يُقاس بتشابه النص العربي. يُقاس بـ:
1. رموز البلاغ `MN-YYYY-MM-DD-NN` من نص الإصدار.
2. المصطلحات اللاتينية (بعد استثناء ما داخل الروابط، لأن الروابط لا تُطبع).
3. الحد: مفقود ≤ 15% = مُسند؛ أكثر = غير مُسند.

## الربط ببوابة التسليم
1. مسح الأسطح → «غير مغطاة: 0 · مانعة: 0».
2. اختبار الحارس (سجل + مُولَّد + أسطح) → «0 فشل».
3. تشغيل الاختبار من **نسخة المستودع** بعد الدمج، لا من الخادم فقط.
