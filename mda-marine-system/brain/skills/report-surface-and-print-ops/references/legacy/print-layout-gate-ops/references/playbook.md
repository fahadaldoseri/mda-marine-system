# مرجع التشخيص التفصيلي — بوابات الطباعة

## ترتيب الفحص الإلزامي

1. قياس الصفحات (`measure_pdf_pages.py`) → أين الفراغ وأين قلة التعبئة بالأرقام.
2. قراءة نص الصفحة المتأثرة (`pdftotext -f N -l N -layout`) → ما الكتلة التي انتقلت.
3. قياس الكتلة في وضع الطباعة (`measure_block.py`) → حجمها الحقيقي مقابل ارتفاع الورقة.
4. قراءة CSS الطباعة الفعلي للمحدِّدات المعنية (`grep` في ملف البناء) → هل هناك قاعدتان متعارضتان.
5. الإصلاح الواحد ثم إعادة البناء والتصدير ثم إعادة 1–3.

## المصائد المتكررة (كل واحدة اكتُشفت بقياس)

### 1. الكتلة غير القابلة للانقسام
`break-inside: avoid` على كتلة أكبر من المساحة المتبقية ⇒ تُدفع إلى صفحة جديدة وتترك فراغًا.
الحدّ العملي: أي كتلة يزيد ارتفاعها على ~200 مم تُنتج فراغًا مانعًا في الصفحة السابقة.
الإصلاح: تصغير الكتلة (أعمدة أكثر، خط أصغر) أو نقلها إلى موضع يمتلئ ما قبله.

### 2. تقييد الارتفاع على عنصر SVG
SVG يحفظ نسبة الأبعاد: `max-height` يقلّص العرض تلقائيًا. في مثال واقعي، قيد ارتفاع 88 مم
أنزل عرض الخريطة إلى 130 مم (62% من عرض المتن) وهو دون حدّ 70% الذي تشترطه البوابة.
الإصلاح: ألغِ `max-height` واضبط `width: 100%` ثم قِس العرض والارتفاع معًا.

### 3. قاعدتان لمحدِّد واحد
قاعدة لاحقة (`columns: 1 !important`) تلغي قاعدة أسبق (`columns: 2`) بلا خطأ ظاهر،
فيظهر المفتاح بعمود واحد ويصير مرتفعًا. الإصلاح: وحّد القاعدة واحذف المنافسة،
وأضف اختبارًا يقيس عدد الأعمدة الفعلي في وضع الطباعة.

### 4. الانقسام بين رسم الخريطة ومفتاحها
اجعل الحاوية تنقسم (`break-inside: auto`) والمفتاح لا ينقسم (`break-inside: avoid`)،
حتى لا يُقطع مفتاح الرموز بين صفحتين.

### 5. الفقرة التي تكسر الصفحة الأخيرة
فقرة واحدة تُضاف في نهاية الملحق قد تُنشئ صفحة عاشرة بتعبئة 7%.
العلاج: ضغط تباعد الملحق (هوامش/تباعد أسطر) بمقدار محسوب، لا بتخمين.

### 6. البصمة المقفلة
تغيير مشروع في CSS الطباعة يُخرج المدقق بـ«نمط الطباعة تغيّر عن المعتمد».
لا تخفّض البوابة ولا تُمرّر `--allow-css-change` بلا سجل؛ استخدم `refreeze_print_css.py`
مع سبب ودليل قياس، وسجّل التغيير في البروفايل المعتمد.

## سلسلة الإثبات قبل التسليم

| الخطوة | الدليل المطلوب |
|---|---|
| إصلاح التخطيط | مخرج البوابتين بعد الإصلاح + أرقام التعبئة والفراغ |
| معاينة بصرية | صورة الصفحة المتأثرة (قبل/بعد) |
| التجميد | بصمة جديدة + سجل تغيير بسبب ودليل |
| التماثل | مقيّم التماثل الصارم يخرج 0 |
| النشر | بصمة الملف الحيّ = بصمة الملف المحلي، وعدد الصفحات نفسه |
| التعلم | صف عطل لكل صنف جديد + درس مطابق + حارس إغلاق يخرج 0 |

## مثال واقعي مُقاس (2026-10-28)

- العَرَض: فشل بوابة الشكل بفراغ داخلي 176–186 مم.
- السبب الجذري: كتلة «خريطة الوقائع + المفتاح» 214–248 مم غير قابلة للانقسام، مع قاعدة مفتاح مكرّرة وقيد ارتفاع يقلّص عرض الخريطة.
- الإصلاح: مفتاح بأربعة أعمدة 7pt + إلغاء قيد الارتفاع + إلحاق الخريطة آخر الملحق.
- النتيجة: 9 صفحات (كانت 10)، متوسط تعبئة 94.1% (كان 87.6%)، الخريطة 156×98 مم (74%×33%)، بلا فراغ ≥45 مم، والبوابتان مطابقتان.
