# أسطح التقرير والطباعة

## الغرض والحدود
احفظ أمانة التقرير عبر المتن والواجهة وصفحات التقرير والإضافات والمصادر والرئيسية وPDF، ثم افحص التخطيط والطباعة بصريًا وآليًا على المخرج المبني أو المنشور.

هذه المهارة لا تقيس هندسة الخريطة أو تطورها؛ استخدم `map-clarity-ops` لذلك. ولا تغلق عطلًا أو تنشره؛ استخدم `fault-closure-and-learning-ops` و`parity-and-publish-ops` عند الحاجة.

## الأدوار المحفوظة
- `report-surface-policy-ops`: سياسة السطوح المؤرخة، النقل دون حذف، وغطاء الأسطح السبعة.
- `report-content-fidelity-ops`: حفظ الأعمدة والأرقام والدرجات والادعاءات من المصدر إلى كل سطح.
- `print-freeze-verify-ops`: بصمة CSS المقفلة، عدد الصفحات، فحص 100% للغلاف/الخريطة/الأخيرة، ومنع الانحراف بلا قرار.
- `print-layout-gate-ops`: قياس التعبئة والفراغ والكتل الذرية، إصلاح واحد، إعادة قياس، ثم إعادة تجميد.
- `live-visual-audit-ops`: تدقيق حي متعدد الأسطح مع قياسات وروابط ولقطات قبل/بعد.
- `manual-visual-check-automation-ops`: تحويل البند اليدوي إلى قياس متصفح حقيقي موجب وسالب يفشل مغلقًا.

## مصدر الحقيقة والأسطح
اقرأ سياسة الأقسام المؤرخة من المصدر قبل فحص HTML أو PDF. يجب أن يبقى المحتوى المنقول في المتن ويظهر مرة واحدة على سطحه الجديد. افحص سبعة أسطح: المتن، ملف الواجهة، صفحة التقرير، صفحة الإضافات، صفحة المصادر، الرئيسية، وPDF.

## المسار الإلزامي
1. ثبّت التاريخ والجذور والنسخة المبنية ومسار PDF؛ لا تعدّل أثناء القياس.
2. قِس السطح النهائي لا المصدر فقط: النص، الجداول/الأعمدة، الأرقام، الروابط، والبصمات.
3. قارن السياسة بالمخرج، وتحقق أن النقل ليس حذفًا وأن التكرار صفر.
4. للطباعة سجّل الصفحات، التعبئة، الفراغات، CSS fingerprint، والحجم قبل أي تعديل.
5. شغّل بوابات PDF والتخطيط؛ أصلح مصدرًا واحدًا/قاعدة واحدة ثم أعد البناء والتصدير.
6. نفّذ معاينة 100% للأسطح الحرجة، وحوّل أي ملاحظة يدوية إلى قياس أو صرّح «لم يُقَس».
7. أثبت موجبًا على مخرج سليم وسالبًا بحقن قص/مرساة/جدول/فهرس مكسور.

## جدول الأقسام
| القسم | المدخل | الدليل المقيس | الحاجز |
|---|---|---|---|
| سياسة السطح | سياسة مؤرخة + سبعة أسطح | قائمة وجود/موقع/تكرار | عنوان في السطح الخطأ = 2 |
| أمانة المحتوى | MD/JSON + HTML/PDF | عدد الأعمدة والأرقام والادعاءات | إسقاط أو رقم بلا مصدر = 2 |
| تجميد الطباعة | PDF + CSS + قرار | صفحات/بصمة/لقطات | تغير البصمة بلا قرار = 2 |
| تخطيط الطباعة | PDF + قياس كتلة | تعبئة/فراغ/صفحة البداية | كتلة منقسمة أو فراغ مانع = 2 |
| تدقيق حي | روابط/لقطات/وقت | قياس كل surface ورمز | مسار ناقص/overflow/قص = 2 |
| أتمتة اليدوي | معيار JSON + متصفح | موجب وسالب ومخرج JSON | بند غير قابل للقياس = معلن لا مخمّن |

## أمثلة مقيسة محفوظة
- تدقيق حي أثبت 5 ملاحظات بقياسات أهداف لمس `30x30px`، خلية/بطاقة فارغة، overflow `180/120px`، وقص `80/20px`، ورمز 2 للحالة المخالفة.
- فحص PDF موجب استخرج 3 إدخالات وطابق الصفحات 2–4 برمز 0؛ السالب كشف فهرسًا يذكر 9 بدل الصفحة 2 برمز 2.
- قياس RTL وجد انعكاسات `12-18` و`25%` و`100-120` ومنعها بدل اعتماد استخراج مقلوب.
- لا تكتب «الصفحات مطابقة» دون `pdfinfo`/JSON/لقطات؛ وإلا فهي وعْد غير مقيس.

## حلقة التعلم الذاتي
بعد كل خلل: **عطل** (سطح/صفحة/selector ورمز) ← **درس** (سياسة أم مولد أم CSS أم أداة) ← **حاجز** (بوابة أو معيار JSON) ← **اختبار** (مخرج سليم يمر وخلل مصطنع يمنع ثم إعادة قياس). مثال: جدول ظهر كبطاقات مصادر؛ الدرس أن العارض فقد نوع القسم؛ الحاجز فحص أمانة الأعمدة؛ الاختبار يحقن بطاقة داخل جدول ويطلب رمز 2. إذا لم تُنفذ المعاينة/القياس الحقيقي، اكتب «لم أختبره».

## أخطاء ممنوعة
- تعديل `dist/` أو PDF يدويًا لإسكات الحارس.
- اعتبار رابط الإضافات دليلًا على ظهور المحتوى.
- ضغط الخط أو تخفيف profile لإخفاء الفراغ.
- اعتماد لقطة قديمة أو بصمة وحدها بدل النص المرئي.

## التسليم
سلّم أوامر القياس، المخرجات الخام، الرموز، البصمات، صفحات/سطوح المخالفة، اللقطات، ونتيجة الموجب/السالب. التفاصيل القديمة محفوظة في `references/legacy/<old-skill>/`.
