# إغلاق انحدار ب-03 وب-10 — خطة التنفيذ

> **For agentic workers:** تُنفَّذ الخطوات بالترتيب وباختبار أحمر/أخضر؛ لا تُخفَّف بوابة مانعة ولا يُدفع إلى Git.

**الهدف:** جعل فحص مراسي المصادر يثبت العناصر التي تُنشئها JavaScript في الصفحة الرسمية مع فشل مغلق عند تعذر الإثبات، وإغلاق ربط الخريطة بالبطاقات في المخرج المبني.

**المعمارية:** يبقى `tools/browser_measure.py` مالك فحص ب-03. عند فحص رابط خارجي، يفتح متصفحًا حقيقيًا ببصمة سياق قابلة للتكرار، ينتظر اكتمال DOM المولَّد، ثم يثبت وجود المعرّف وموضعه؛ أي استجابة غير قابلة للتحقق أو غياب الهدف يبقى مخالفة مانعة. يضيف `seawatch/generator/map_gulf.py` `data-event-id` مشتقًا من الرمز الحاكم لكل علامة/عنقود، بحيث يثبت المخرج علاقة الخريطة بالبطاقات بدل إضافة سمة شكلية في ملف يوم واحد.

**التقنيات:** Python 3، Playwright sync API، HTML/SVG مولّد، JSON/JSONL، `bash -lc`، أدوات runbook الحالية.

**المواصفة:** `runbook/regression-items.json` (ب-03: `tools/browser_measure.py --check anchor`؛ ب-10: وجود `id="ev-"` و`data-event-id` في `SITE/dist`).

## القيود الحاكمة

- تحقق حي سابق للحكم: `curl -sI https://www.ukmto.org/recent-incidents` وسجل `HTTP 403` الخام؛ HTML الخام لا يحتوي المعرّف، والمتصفح الحقيقي أثبت عنصر `LI` بالمعرّف والوصول إليه.
- ب-03 مانع: لا تحويل إلى `--soft` ولا قبول نجاح بلا هدف مثبت؛ عند فشل المتصفح أو عدم اكتمال DOM يعاد رمز فشل مانع.
- المصدر الحاكم للمرساة لا يُعدَّل؛ الرابط صحيح ومستقر بحسب الدليل الحي، لذلك الإصلاح في أداة القياس لا في ملف يوم واحد.
- ب-10 يُصلح في مولّد الموقع؛ لا تعديل يدوي لـ`dist` ولا تعديل استثناء مهلة.
- لا نشر، لا تلغرام، لا نسخ احتياطي، لا دفع Git.
