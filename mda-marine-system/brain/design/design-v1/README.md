# design-v1 — نموذج تصميم «التقرير اليومي لأمن الملاحة»

HTML وCSS صرف، بلا npm ولا بناء ولا CDN ولا خطوط شبكة. يعمل بفتح `index.html` مباشرة (حتى بلا اتصال)، ويُطبع إلى A4.
سكربت واحد اختياري داخل `index.html` (≈ 12 سطرًا: المظهر والطباعة) ولا يلزم للعرض ولا للطباعة.

## البنية
```
index.html            النموذج كاملًا ببيانات تقرير 21 أكتوبر 2026 (17 قسمًا)
styles/fonts.css      @font-face محلي (woff2) بنطاقات unicode-range
styles/tokens.css     كل لون وحجم وتباعد وحد ونصف قطر ومدة (المصدر الوحيد للقيم)
styles/components.css مكوّنات الشاشة (كل مكوّن بكلاس واضح)
styles/print.css      الطباعة وحدها، لكل قاعدة تعليل
fonts/ assets/        خطوط woff2 + الترخيص · أيقونات SVG مرجعية (المضمّن في index.html هو المستعمل)
fixtures/             states.html (حالات النقص والتجاوز) · long-table.html (تكرار رأس الجدول)
preview/              design-v1.pdf (11 صفحة) · design-v1-brief.pdf (10) · p-01…p-11.png بمقياس 100% (96dpi) · لقطات الشاشة
tools/                measure_gates.py (القياس) · export_pdf.py (التصدير المرجعي)
COMPONENT-MAP.md      الكلاس ↔ القسم ↔ حقول البيانات ↔ الحدود وقواعد التجاوز
CHANGES.md            ما تغيّر ولماذا، وحدود هذا التسليم
```
ترتيب التحميل في `<head>`: `fonts.css` ثم `tokens.css` ثم `components.css` ثم `print.css`. لا ترتيب آخر.

## كيف يُدرج كل مكوّن
انسخ بنية المكوّن من `index.html` (ابحث بالكلاس في COMPONENT-MAP.md) واملأ نصوصه من حقول البيانات المذكورة. القسم العام:
```html
<section class="sec" id="s-07" aria-labelledby="s-07-h">
  <header class="sec__head"><span class="sec__no">07</span><h2 class="sec__title" id="s-07-h">التوجيهات التشغيلية</h2></header>
  …محتوى القسم…
</section>
```
- كل فقرة `class="body-text"`، وكل قائمة متن `class="list-justified"`، وكل خلية `class="table-cell"` (انظر الأصناف الصريحة والمستثنى في COMPONENT-MAP.md قسم 3).
- النص اللاتيني والرموز داخل العربية: `<bdi class="ltr">UKMTO 178</bdi>`.
- الجدول: `table.tbl.tbl--cards` مع `data-label` على كل `td` (يتحول بطاقات على الجوال).
- النسبة في شريط الاحتمال: `style="--p:24"` (بيانات لا تصميم).

## الوضعان والطباعة
- الليلي افتراضي، والنهاري `data-theme="light"` على `<html>`؛ لا تبديل ملفات.
- الطباعة: `tokens.css` يعيد ربط كل رمز دلالي بقيمة الورق داخل `@media print` (أبيض مسطّح · pt/mm · بلا ظل)، فتستعمل `components.css` الأسماء نفسها بلا تكرار.
- `data-print-profile="brief"` على `<html>` يحذف `.print-optional` (قسم الخلفية) لإصدار يتجاوز 12 صفحة.
- الترقيم وتذييل الصفحة: موضع وشكل فقط (`@page` · `.toc__pg`)؛ يولّدها المُصدِّر عندكم.
